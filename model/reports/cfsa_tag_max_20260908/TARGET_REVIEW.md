# 全部显式 TAG 目标静态核查

本次只读核对指定候选、相关 curation 和本地 COBRA 原子量表；求解器、采样调用均为 **0**。目标可精确定义为 **候选全部显式 TAG 的额外需求质量通量**，保留声明的正生长下限 0.14650760568106092；不解释为零生长最大产率或正式模型接受。

完整集合为 **343 = 7³ 个有序链组合**，全部位于 C_lp，未发现其他显式 TAG 区室。另有4个泛化 TAG 节点：m1399[C_cy]、m1634[C_em]、m1640[C_lp]、m2014[C_er]；其公式含通配符或缺失，不能一起赋予确定分子量。该范围覆盖候选的显式 TAG，不代表全部生理 TAG 多样性。

343个元素式均与指定三条脂肪酸和甘油成三酯后的公式一致，只含 C/H/O，分子量为 **639.00126–891.47970 g/mol**。但 **127个物种的电荷标注存在限制**：含一、二、三条 linoleoyl 时分别继承 −4、−8、−12；计108、18、1个，另216个为0。元素式与中性三酯相符，电荷账本却未规范化为中性TAG；不能把此候选称为化学校准模型，也不得为本测试静默修正。

每个 TAG 只参与自身的 UL_R1771 合成反应和 biomass_C。343条合成反应均为 1 DAG + 1 acyl-CoA → 1 TAG + 1 CoA，边界均为 [−1000,1000]；按候选储存的元素式与电荷检查，343条全部平衡。此项内部平衡会保留上述继承电荷问题，不能独立证明化学正确性。每条单向需求只移走对应一个TAG，按 `Σ(MW_i/1000)·v_i` 加总不重复计算生物量消耗；它表示额外胞内需求，不是已有分泌途径。

SBML 定义了 mmol_per_gDW_per_hr，葡萄糖 R1070 的下限明确使用它；但6826个反应边界引用中6824个没有显式单位，TAG边界也没有。因此 **gTAG/gDW/h 是沿用全模型 mmol/gDW/h 通量约定后的单位解释**，不是已完成的全局SBML量纲验证。

葡萄糖公式 C6H12O6，本地原子量表给出180.15588 g/mol。实际输出/葡萄糖质量比可计算为 `q_TAG / [0.18015588·(−v_R1070)]`，要求实际净摄取为正，并使用同一解/样本中的摄取量。只有葡萄糖摄取固定时，最大TAG质量通量才同时最大化这一比值；否则只是该最优输出状态下的比值。存在其他碳输入时，不能把它解释为仅由葡萄糖支撑的理论产率。

覆盖：**总计7｜已审7｜支持4｜未决2｜反驳1｜未查0**。反驳项为“全部TAG物种已规范化为中性化学状态”；未决项为完整单位证明和最大质量通量与最大葡萄糖质量产率的等价性。实际执行约束、数值质量与采样诊断未在本次核查。
