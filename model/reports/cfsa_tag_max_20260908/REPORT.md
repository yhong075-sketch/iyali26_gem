# lipid-unlump：最大显式 TAG 输出测试

**已求得候选模型在原 SD-Leu／PO1f 条件、保留生长下限时的最大 TAG 质量输出，约 0.60674 g TAG·gDW⁻¹·h⁻¹。固定该最大值后，CFSA 所用 OptGP 采样器在预热中返回一次 infeasible，按预设条件停止；实际样本数为0，不能报告通量分布、收敛或工程靶点。**

质量输出的单位沿用模型 mmol·gDW⁻¹·h⁻¹ 通量约定；候选 XML 的单位标注并不完整。这里最大化的是**质量输出速率**，不是独立求解产物／底物比值的最大值，也不是培养液终点产量、实测分泌速率或零生长极限。培养基还有氨基酸、核碱基等含碳输入，因此0.33678 g/g不能解释成仅由葡萄糖供碳的理论产率。

保存的两份最优解都以三棕榈酸甘油酯（TAG 16:0/16:0/16:0，C51H98O6）的额外需求为主。其他TAG没有超过原1e-7通量容差的正需求。**这是一个自由组成优化问题中返回的解**，不是对真实细胞脂质组成的预测；没有证明所有最优解都具有该组成，也没有统计其在采样空间中的频率。各物种的原始正负小量保留在analysis.json和NPZ中。

本次支持的结论是：lipid-unlump候选允许通过显式 TAG 合成途径在维持低水平生长的同时输出 TAG；此前旧脂质伪池输出为0没有代表实际TAG合成能力。当前结果不证明拆分后模型更准确，也不能直接与旧混合脂质伪池的23.74或旧42倍通量比比较。

## 目标、条件与模型身份

用户先要求“测试最大产量条件”，随后明确选择“全部 TAG（三酰甘油）的总输出”。本次使用已登记的lipid-unlump候选d5bc83aa…，实际加载上轮保存且校验过的有效候选JSON，继承相同SD-Leu／PO1f配置；完整候选和实际输入SHA见plan.json及result.json。没有重算参考模型或更换培养基。

选取候选全部343个显式tag_lp物种，全部位于脂滴区室C_lp，共7³个有序链组合。各增加一条只消耗该TAG的临时单向需求d_i，界为[0,1000]，允许组成自由变化。没有按生物量比例锁定配方，也未恢复旧xLIPID。四个仍存在的泛化TAG节点分子式含通配符或缺失，不能赋予确定分子量，故本次范围准确称为“全部显式TAG”。

目标与约束为：

\[
q_{TAG}=\sum_{i=1}^{343}\frac{MW_i}{1000}d_i,\qquad
\max q_{TAG},\quad Sv=0,\quad l\le v\le u,\quad
v_{biomass\_C}\ge0.14650760568106092.
\]

分子量由各TAG的完整元素式计算，范围639.00126–891.47970 g/mol。生长下限保留旧参考最优生长的10%这一**绝对数值**；没有静默改为候选自身最优生长的10%。需求表示额外胞内TAG消耗／积累的模型代理，没有建立新的生理分泌机制。

随后固定q_TAG等于求解器返回的q*，在同一条件下最小化Σ(f+r)，再添加Σ(f+r)≤1.25×最小值。最大产量条件下获得的最小值为526.33514，故该pFBA上限允许保存的最大产量解在原数值容差内成立。这里的未加权通量总和不是实测酶容量，且依赖反应拆分和尺度。

## 实际执行与停止点

本轮预登记预算最多25,000次后端、1200秒、3条链各1000样本，thinning=100，独立种子20260931/32/33，单进程／单线程。实际执行46.1827115秒，**420次后端：前两次最大TAG和最小总通量均optimal；预热调用418次，其中417次optimal，最后一次infeasible。**随后立即停止，无重试、无容差调整、无额外链、无样本或ESS/R-hat结果。

完整额外约束、采样器实际等式／不等式／变量边界已在首个预热后端调用前保存。没有把最大值偷偷降为90%或99%，也没有把预热点当作采样结果。

独立复核发现，按变量名对齐后，采样器实际等式矩阵与保存的原求解器矩阵有1242个系数存在微小差异，最大4.8069894e-11。例如一个生物量脂质系数从−1.21635519301062e-5变为−1.21636e-5，呈现复制／序列化舍入迹象。因此不宣称两者逐系数完全相同。两份主优化点代入实际采样矩阵后，最大等式残差仍为8.1798164e-8，低于原1e-7标准；该差异没有被证明就是预热失败的原因。

两个保存的主优化解在原1e-7数值标准内满足完整原JSON的守恒和反应边界：最大|Sv|=8.1798170e-8，最大净边界偏差=5.6227950e-8，最大split变量边界偏差=9.7231787e-8。最优性来自求解器状态；后处理核验的是保存点可行性，不是另一次最优性复现。

其中445个split变量具有容差内的小负值，总和约−5.62624e-6，使净L1比split总和高约1.12525e-5。原始值保留，未裁零，未据此混同净L1和正反通量总和。多项偏差已接近既定容差，故q*应作为求解器容差下的近似最优值解释。

预热infeasible与前述可行点之间存在数值层面的不一致。精确最优面和数值误差是待检验的解释；**本次没有定位或证明根因**，不能写成“生物学不可行”“模型不能产TAG”或“已证明采样不收敛”。没有进行自动重求解或放宽条件。
