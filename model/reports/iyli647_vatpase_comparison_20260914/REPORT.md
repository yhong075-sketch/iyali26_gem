# iYLI647 未解决当前液泡 ATPase 问题

核验时间：2026-09-14。本轮读取2018论文公开附录及此前实际筛选的 `iYLI647_corr_3`，并复核既有筛选输出；新增LP和模型修改均为0。

**两个受检版本都没有提供一个可运行、可解释液泡酸化必需性的 ATPase 方案。** 这一判断来自完整物种守恒行及实际计量，不是依据反应名称、边界是否打开或全模型 essential 命中率。

## 直接结构证据

两个版本的液泡反应 `ATPS3v` 都写为：

`ADP[v] + Pi[v] + 3 H+[c] → ATP[v] + H2O[v] + 2 H+[v]`，边界 `[0,1000]`。

Golgi反应 `ATPS3g` 具有相同形式，只将 `[v]` 换成 `[g]`。这是允许 ATP 合成的计量表示；与本项目 R794/R795 使用胞质 ATP 水解的表示不同，不能仅凭名称认作等价步骤。

完整扫描所有反应后：

| 物种 | 原始附录的全部关联 | corr_3的全部关联 | 稳态约束 |
|---|---|---|---|
| ATP[v] | ATPS3v，系数+1 | ATPS3v，系数+1 | v_ATPS3v = 0 |
| ADP[v] | ATPS3v，系数−1 | ATPS3v，系数−1 | −v_ATPS3v = 0 |
| ATP[g] | ATPS3g，系数+1 | ATPS3g，系数+1 | v_ATPS3g = 0 |
| ADP[g] | ATPS3g，系数−1 | ATPS3g，系数−1 | −v_ATPS3g = 0 |

原附录四个物种的 `boundaryCondition` 均为 `false`。因此，在保留这些完整物种平衡行的标准稳态模型中，两条反应被结构性阻断，和选择哪一个最优解无关。仅改变它们的方向边界也不能解除这一单反应物种行限制。

两个版本中，所有同时涉及任一区室ATP与液泡/Golgi H⁺的反应也只有上述两条；未发现采用不同名称的直接 ATP 水解质子泵。这是限定化学模式的全反应检查，不宣称覆盖一切可能的间接能量耦合机制。

反证检查：两个版本的 `H2Otv`（胞质水↔液泡水）确实已经开放为 `[-1000,1000]`，因此它们没有本项目R1363关闭这一具体水转运问题；但水转运不能解除 ATP/ADP 的独立断点。这也不意味着其他液泡反应全部被阻断。
