## 完整底物链证明：开水仍不能产生需求

R1363 实际计量只有 `H2O[cy] -> H2O[va]`，没有 ATP 或 H⁺ 项；开放只把上界从 0 改成 1000，未改变反应方向。R795 本身使用胞质水，而液泡水的消耗发生在以下 4 条水解中。

| 二肽 | 外部交换 e | 胞外→胞质转运 t1 | 胞质→液泡转运 t2 | 液泡水解 h |
|---|---|---|---|---|
| Gly-Asp | R2018 | R2019 | R2020 | R2021 |
| Gly-Glu（模型名称 Gly_Glu） | R2026 | R2027 | R2028 | R2029 |
| Ala-Gly | R2031 | R2032 | R2033 | R2034 |
| Gly-Pro | R2036 | R2037 | R2038 | R2039 |

对每一种二肽，独立枚举原 XML 中其胞外、胞质、液泡 3 个具体物种的**全部反应关联**。4×3=12 行均只有下列项，没有遗漏的内部合成反应、旁路或其他来源；这是对当前模型表示的核实，不是对真实细胞合成能力的判断：

```text
胞外二肽: -e - t1 = 0
胞质二肽:  t1 - t2 = 0
液泡二肽:  t2 - h = 0
所以 h = -e
```

本轮 4 个外部交换实际均为 `[0,1000]`，而交换计量为消耗胞外物种（−1）。因此其非负方向为排出，摄入需要负值且不被允许；不能把正上界 1000 解释为允许摄入。4 条水解实际下界也均为 0。于是 `e>=0`、`h>=0` 与 `h=-e` 联合强制 `e=t1=t2=h=0`。

由此，双开后的液泡水守恒为：

```text
v_R1363 - v_R2021 - v_R2029 - v_R2034 - v_R2039 = 0
```

4 条水解全部为零，所以 **`v_R1363=0`**。这轮不再依赖“水进口关闭”来解释零水解；二肽摄入未开放本身就是独立的阻塞条件。

液泡甘氨酸和脯氨酸行进一步给出 `v_R2030=0`、`v_R2040=0`。液泡异亮氨酸的去路 R883 仍为 `[0,0]`，唯一非关闭关联 R882 也被其物料守恒强制归零。所有相关反应的实际边界与上述推导匹配；其余液泡 H⁺ 关联反应仍关闭。故液泡质子行化简为：

```text
2*v_R795 - v_R882 + v_R2020 + v_R2028
    + v_R2030 + v_R2038 + v_R2040 = 0
```

所有伴随项已为 0，因此 **`v_R795=0`**。这解释了即使不要求最优生长、直接最大化水进口或泵通量，两者仍返回 0；不只是最优生长选择了另一条途径。

此证明限于保留当前其他边界与计量的情况，未证明开放某一二肽来源就一定恢复生长耦联或必需性。当前报告无需也不能据此自动更改培养基、其他运输或酸化下限。
