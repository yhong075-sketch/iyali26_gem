# 全模型 GPR 传导与重复反应静态筛查

核验日期：2026-09-11。本次对原模型 **1074 个基因条目、2315 个反应**完成静态检查，复用既有 SD-Leu / PO1f 有效运行条件。原模型条目包含占位 ID 和线粒体 ID；额外运行时伪基因 `PO1f_plasmid_LEU2` 单列，未当作原生实验敲除对象。

**没有发现“规则已变假，但程序漏关反应”的实现错误。** 独立布尔解析与实际 `COBRA Gene.knock_out()` 的边界结果全部一致。主要待审问题是模型写入了什么布尔关系，以及是否存在重复化学步骤；这与程序能否执行规则是两件事。

本次新运行仅为模型读取、布尔计算、内存敲除边界核对和计量比较，**0 次 LP、FVA 或优化求解**。模型、整理数据及既有实验标签均未修改。历史生长数值和 11 个 KO 的通量见证为已存结果，不称为本次重新求解复现。

## 检查如何完成

逐反应用 Python AST 独立解析已保存的布尔 GPR；只接受基因名、AND、OR 和括号，非法表达式立即报错。每次令一个原模型基因条目为假，其他基因为真。规则为假时预期边界为 `[0,0]`，否则应保留有效运行边界。实际在 COBRA 的独立模型上下文中调用单基因敲除，逐一核对全部反应的边界，随后恢复原上下文。

对全部反应，以完整、含区室的代谢物 ID 和精确十进制计量构造规范化向量。相同、反号或成比例向量进入同组；将反应允许的正负方向一起换算到规范方向，再逐基因检查“一条记录被关，另一条相同化学方向仍可运行”。因此不会把两个相反的单向记录直接当成同方向替代，也不会把胞质与线粒体的同名反应合并。

## 结论的边界与交付

此次已证明的是编码的单基因 GPR 逻辑正确传到反应边界、哪些条目完全不改变约束，以及哪些精确重复列保留了被敲化学步骤的允许方向。没有证明任何 OR 生物学上错误；没有证明一条仍开放的重复反应必然支持稳态生长；没有对全模型做方向可行性、FVA 或全体多基因组合验证。

重复比较只认同一代谢物 ID 和精确比例；不同 ID 表示同一化学实体或舍入不同的近似计量不在此筛查覆盖范围。来源缺失与已证伪不同。存在明确身份/功能问题时，后续需结合已批准的蛋白和结构证据流程，而不是为当前静态检查自动启动整批结构预测。

背景身份、运行时 22 条边界/GPR 差异、每个基因及每组反应的完整结果见 [gpr_results.json](gpr_results.json)。可复核脚本 [gpr_scan.py](gpr_scan.py) 包含最小断言自检；该脚本不会优化。两次静态执行中，第二次仅修正“原模型条目”字段表述并重新核验，数字未变。受保护输入 SHA 前后相同。既有机制和通量证据见 [此前 11 个差异基因诊断](../iyli647_screen_20260910/nonessential_diagnosis_20260911/REPORT.md)。
