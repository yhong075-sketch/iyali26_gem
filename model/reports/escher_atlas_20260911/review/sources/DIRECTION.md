# iYali26 全模型方向性静态筛查

本次对固定模型全部 2315 条反应进行静态检查，复读此前保存的 22 个完整通量见证；没有新增 LP、FVA 或模型修改。统计使用已保存的培养条件与 Po1f 叠加后的有效边界。892 条可逆反应并不等于 892 个错误；判断须依据具体化学方向、条件和酶学证据。

对全部非边界开放反应的允许方向，搜索两个不同反应、单位系数、含至少一步负向且存在中间物抵消的组合。检查 67311 个组合，得到 **135 个精确/容差验证的非零计量恒等式，涉及 80 个目标反应**；其中 11 个组合的两步曾在同一个保存见证中同时运行。这是方向和计量相容的候选集，并非 80 个已验证基因旁路。未枚举任意比例或三步以上路线，也未证明容量足够、对目标敲除仍可行或热力学可行。

## 优先核查的结构风险

### 1. 六条既有方向整理与当前版本边界存在明确差异

`data/reference_build/curation/gap_fill_direction_curation.csv` 的 6 条记录均标为 active、只允许所整理的化学方向；当前模型 6 条均为 `[-1000,1000]`。模型 notes 保留 `metadata_previous_gap_fill_direction_*`，并说明当前结构来自用户选择的 metadata 版本。这是**有来源的版本选择与方向依据冲突**，不能直接称为软件回归或本次未经授权变更。

| 反应 | 当前允许而既有整理排除的化学方向 | 保存 WT 通量 | 22 个保存解中该方向出现次数 |
|---|---|---:|---:|
| R_NTP1 | H⁺ + ADP + Pi → ATP + H₂O | +157.555763494 | 22 |
| R_NDP1 | H⁺ + AMP + Pi → ADP + H₂O | +19.928005233 | 12 |
| R_NTP3pp | H⁺ + GDP + Pi → GTP + H₂O | 0 | 0 |
| R_NTP7 | H⁺ + UDP + Pi → UTP + H₂O | 0 | 0 |
| R_PGAM1_PhosHydro | Pi + 丙酮酸 → PEP + H₂O | +0.359416479 | 18 |
| R_CAT2p | 乙醛 + 2 H₂O → 乙醇 + H₂O₂ | −20.012469344 | 19 |

前三个和 PEP 生成在当前列的正向；因此只筛 `v<0` 会遗漏风险。应检查**化学方向**与其能量/酶学依据，不能仅看数值正负。六条记录所引用的 KEGG/MetaNetX 链接及 rationale 已逐条保存，本次没有重新审阅外部原始文献，不能把整理表视为新完成的生物学验证。

`S_R_NTP1 + S_xMAINTENANCE` 的完整残差是 `−H⁺[C_cy]`，ATP、ADP、Pi 和水恰好消去。因此这不是完整两步净零循环，不能省略质子后声称已证明封闭能量循环。它直接显示 ATP 生成与维护消耗之间的结构风险，但尚不能量化这几步分别导致了多少必需性误判。

验收候选：先审定既有方向记录是否适用于当前化学计量和条件，再在获准的固定环境中做定向关闭对照，观察 ATP 供给、生长及已知正确结果是否改变。本次不改边界。

### 2. 两条已经定位的补偿路线得到完整计量证书

- **UDP-葡萄糖：** `S_R319 − S_R780 = S_R793`，包括质子完全相等。R780 必须逆向才能组成这条替代；11 个保存单敲解中两步同时运行且 R793 为零。此前定向控制已支持其对目标预测的作用；方向合理性仍需底物和酶学依据。
- **丙二酰-CoA：** 新核实 `S_R690 − S_R2004 = S_R88`。R690 的丙酮酸羧化与反向 R2004 恰好组成乙酰-CoA 羧化的净反应；17 个保存解同时使用两步、R88 为零。此路线仍净消耗 ATP，并非净零循环或“无能量代价羧化”。R2004 无 GPR，需核查这项酶活性和反向运行的依据。此前关掉 R2004 后，R2120/R2121 还能提供另一条补偿，不能单凭 R2004 判定修复充分。
- **线粒体脂酰-ACP：** 既有完整见证中，`R2233 → 反向 R2234 → R2235 → R1572 → R1448` 提供不饱和脂酰-CoA。R2234 是无 GPR 的可逆转运注释反应，实际逆向把该脂酰-ACP 从线粒体移至胞质；应交给区室供给审查核查载体与转运机制。这条五步路线超出本次两步枚举范围，结论来源是既有见证。

这些方向边界在原 iYali21 中已存在；部分计量后来改变。继承来源不是正确性证明，不能据此跳过审核。
