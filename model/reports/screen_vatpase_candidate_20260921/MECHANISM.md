# 为什么 V-ATPase 关闭后仍能保持 WT 生长？

核查日期：2026-09-21。范围为本轮已筛选候选 XML、实际 SD-Leu/PO1f 边界及保存的 WT 完整通量；只做局部计量、边界和已保存结果核查，没有新优化、FVA 或模型修改。完整身份、反应式及可运行断言见 [mechanism_details.json](mechanism_details.json) 和 [mechanism_check.py](mechanism_check.py)。

**直接原因是：当前模型已有一份达到 WT 生长的通量方案，完全不使用两条泵；相关区室功能也没有成为这份生长方案的必经步骤。** 进一步检查发现，部分过程由供应或去路断点强制为零，其他过程在保存解中可不运行。两类证据不能混为一谈。

## 1. 此处的 ATPase 消耗 ATP，生长所需 ATP 不依赖它生成

R794/R795 的存储计量均为：

`ATP[cy] + H2O[cy] + 2 H+[cy] → ADP[cy] + Pi[cy] + 2 H+[go 或 va]`。

本次目标是最大化 `biomass_C`，其 ATP 消耗系数为23.09，没有直接 Golgi/液泡物种项。保存解中的胞质 ATP 可由其他反应提供，例如 R642、R694。ATP 生长消耗并不会自动要求 V-ATPase 消耗 ATP。这里只说明该模型的通量分配，不对完整能量网络作新的生理有效性认证。

本次计量平衡约束要求物种生成/消耗速率相等；H⁺ 出现在计量式中，不等于已经表达液泡/Golgi必须维持某个pH或膜电位。保存的泵零通量最优解证明本次约束没有强制这些泵承担维持该生长率的任务。

## 2. 液泡利用链存在可证明的静态断点

R795本来就是[0,0]。在液泡H⁺的完整22条邻接反应中，16条原已关闭；其余6条虽然单独边界允许非零，也被相关物种守恒限制。

液泡水 `m1384[C_va]` 的完整守恒行为：

\[
v_{1363}-v_{2021}-v_{2029}-v_{2034}-v_{2039}=0.
\]

R1363供水边界为[0,0]，后四个二肽水解均不可逆、非负。因此**四条水解全部被迫为零**。这是从完整水池连接与边界得出的结论，不是只观察到WT取了零值。

二肽供应还有独立限制：Gly-Asp、Gly-Glu、Ala-Gly、Gly-Pro四个交换R2018/R2026/R2031/R2036均只准排出，不准摄入。每条链的外部、胞质和液泡二肽池都没有其他入口；把三池守恒式相加得到 `−交换−水解=0`。两项均非负，所以交换、两段转运、水解均为零。**即使单独开放供水，现有培养下这四条利用链仍不会运行。** 无外源二肽是当前培养供给限制，不能直接称为生物学错误。

水解为零后，Gly/Pro液泡池的守恒也把R2030/R2040限制为零；Ile液泡池只有R882输入和已关闭R883输出，故R882也为零。由此，6条边界允许非零的H⁺邻接也无法运行。这些液泡利用过程没有参与当前生长方案，敲除本已关闭的泵也不会再夺走这部分供应。

如果只把R795开放、其他边界保持，上述底物/水/去路推导仍成立，液泡H⁺完整守恒行只剩 `2 v795=0`，因此单独开放这条泵也不能建立非零需求。这是符号推导，本轮没有实施开泵或新增求解。

## 3. Golgi需求没有成为当前生长的必经环节

所有涉及Golgi腔 `C_go` 物种的**76条反应在保存WT中均为零**。这是该解的观察，不能据此宣称全部76条在任何条件下都被结构阻断。

其中R141糖基转移步骤确有可证明的结构断点：底物 `m289[C_go]` 仅在R141被消耗，没有生产/运输入口；产物 `m291[C_go]` 仅由R141生成，没有后续去路。两物种均受稳态约束，故各自一行就要求 `v141=0`。该孤立步骤不能代表真实细胞的完整糖基化过程。

生物量中mannan的需求仍可由当前模型的内质网路线满足：R289生成mannan[er]，R1250逆向将其送到胞质，供`biomass_C`使用。保存通量为：

\[
v_{289}=-v_{1250}=0.4414815702
=0.235849\times1.87188230694.
\]

因此，这项生物量需求在当前模型中不要求先经过Golgi质子泵。不能将这个模型表示外推为原生mannan功能无需Golgi。

## 4. R1159目前不能被称为实际代偿原因

Golgi H⁺的完整守恒式是：

\[
v_{141}+2v_{794}+v_{1159}-2v_{2048}+v_{NDP7g}=0.
\]

保存WT中五项全为零，所以没有必须由R794满足的净质子通量需求。R1159的存储反应允许无需ATP的可逆胞质—Golgi H⁺转运，确实是需要审查方向和能量依据的结构连接；但它在该WT解中也是零，不能说是它运行起来替代了泵。

## 对修改模型的含义

12共同组件的GPR敲除传导已生效。需要继续解决的是：哪些区室过程在匹配培养条件下确实应当影响生长、其底物供给和产物需求是否完整，以及酸化依赖如何有依据地进入模型。局部供应断点、培养下没有需求和真实生物学必需性应分别判断。仅增加AND、强制泵下界、开放一条供水或添加任意质子消耗，都不能自动构成经过验证的修复。

数学上，单敲仅收紧反应边界，KO可行域包含于WT可行域；原WT通量在KO后仍可行且目标不变，因此KO最优值仍可达到原WT最优值。这解释了本轮约100%的KO/WT。原始全通量可行性见[screen审计](AUDIT.md)，不是本次新增求解。

## 补充：R1159方向审查（2026-09-23）

本次直接重读候选XML及保存WT，并审查原始文献；未修改模型、培养或GPR，未运行新LP/FVA。R1159名为`H+ diffusion`，存储计量为`H+[cy] → H+[go]`，边界`[-1000,1000]`，无ATP项、耦联离子或GPR。其来源注释含`EX_h_e`、`MNXR02`；这些标签本身不证明W29的Golgi跨膜机制或方向。

**判断：在未表达pH和膜电位的当前FBA中，不受驱动力限制的双向边界过宽；但不能把被动扩散在所有条件下都定义为不可逆。** 正向电化学自由能为

\[
\Delta G_{cy\to go}=2.303RT(pH_{cy}-pH_{go})+F(\psi_{go}-\psi_{cy}).
\]

若Golgi更酸，且膜电位未抵消这一化学梯度，则正向上坡，被动净泄漏应为`go → cy`。在此条件假设下，保留原计量并用`v1159≤0`（例如`[-1000,0]`）是可审查候选；1000只是沿用边界，不是测量的通透率。若驱动力反转，净扩散方向也可反转。当前尚无本次W29/PO1f培养条件的区室pH、膜电位及具体泄漏机制证据，因此这不是已验证的正式方向修订。
