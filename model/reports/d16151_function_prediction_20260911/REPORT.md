# YALI1D16151g 蛋白功能预测

分析日期：2026-09-11。本次完成九个固定参考的序列比较、六个单链结构比较及全部结构配对距离的复核；未进行代谢模拟或模型/GPR变更。

**首选功能注释：GS 家族、GlnA4-like 的 ATP 依赖性 γ-谷氨酰有机胺连接酶候选。乙醇胺是当前优先的具体底物候选。** 这是“基于 AlphaFold 预测的功能候选”，并结合序列及已表征参考的实验文献；尚不能把它确定为乙醇胺连接酶，也不能证明其完全没有谷氨酰胺合成活性。

**目标身份：YALI1D16151g，W29 蛋白 AOW03998.1，458 aa；对应 CLIB122 的 YALI0D13024g／Q6C990，完整序列一致。** 文献曾称 GLN2/GS2，统一正式符号尚未核实。历史 UniProt A0A1D8NED6 的“glutamine synthetase”来自自动注释，并非目标蛋白的纯化酶活证据；当前条目因不属参考蛋白组被删除，不代表假基因或无活性。基因别名不替代以上序列身份。

## 预测等级

| 层级 | 判断 | 证据强度与边界 |
|---|---|---|
| 蛋白家族 | GS 相关的 ATP 依赖连接酶框架 | 较高的间接证据：全长折叠、催化域及多个保守位点吻合；酶活本身尚未测定 |
| 广义反应 | 将谷氨酸的 γ-羧基与某种有机胺连接 | 中等的间接证据；优先于直接接受经典 GS 注释 |
| 首选具体底物 | 乙醇胺，形成 γ-谷氨酰乙醇胺 | 低至中等，候选级：GlnA4 在本次序列与结构参考集中均居首，仍有重要口袋差异 |
| 其他可能底物 | 腐胺／其他多胺、甲胺或其他有机胺 | 保留候选；不同胺类参考均相似，无法由折叠指定哪一种 |
| 经典 GS 功能 | 氨／铵参与的谷氨酰胺合成 | 证据较弱但未排除，尤其不能排除低水平副活性 |

这些等级是证据评价，不是经过校准的概率。尚不赋予确定 EC 编号、原生降解通路或细胞区室。

## 最有判别力的位点及反证

与实验 GS I（1FPY，以下用PDB作者编号）的直接结构对应显示，E129/E131/E212/E220/H269/E357 分别对应目标 E135/E137/E197/E204/H253/E354，六个参考金属结合位点均保留。结合域结构，这支持保留连接反应框架的候选解释；目标金属种类和实际催化效率未知。

| 参考位点 | 目标对应位点 | 解释与限制 |
|---|---|---|
| GS I E327 | W322；pLDDT 67.19 | 酸性侧链变为芳香疏水侧链，削弱直接移植经典氨反应机制的依据；该环区构象低置信度，不能断言侧链位置或排除GS副活性 |
| GlnA4 F331 | W322；Cα距离0.79 Å | 两者均为芳香残基，与GlnA4候选相容；该位点不是乙醇胺特异性的独立证明 |
| GS I N264；GlnA4 E269 | 均对应 P248；pLDDT91.50 | 与两参考均有明显差异，是不能直接认定相同底物识别或反应效率的反证 |
| GS I D50、Y179 | C45、G164 | 本次直接对齐显示化学性质不同；不同参考中的局部对应并不稳定，不将它们定为无歧义的同源替换 |

例如经 PauA7 间接转移时，G40对应目标G43、A147对应F163，与直接GS对齐位置不完全一致。PauA7 W296有晶体坐标，但未被本次对齐配对，**不是未建模**。因此本次不声称已精确重建氨/胺口袋体积、寡聚装配或跨亚基活性位点。

[PauA7 原始研究](https://doi.org/10.1021/bi3014856)说明GS同源蛋白可偏好有机胺；[GmaS 原始研究](https://doi.org/10.1271/bbb.60590)则提醒我们，偏好甲胺/乙胺并不等于氨活性严格为零。目标在氮源变化下的表达响应曾有[酵母转录研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5311114/)支持，但表达响应不是底物或酶活验证。本次未找到目标序列的直接底物表征。

## 可采用的注释与验证重点

建议候选注释为：**“YALI1D16151g：GS 家族 ATP 依赖性 γ-谷氨酰有机胺连接酶候选，GlnA4-like；乙醇胺为优先底物候选，基于 AlphaFold 预测及序列比较，未实验验证。”**

最有判别力的后续证据是直接区分谷氨酰胺与有机胺谷氨酰化产物，并比较乙醇胺、氨/铵及其他胺类，而非仅测ATP消耗、磷酸释放或表达变化。这里提出验证方向，没有执行湿实验、决定实验条件或修改GPR。当前证据不足以认定目标可独立承担R2081，也不足以凭预测宣判其绝无该活性。
