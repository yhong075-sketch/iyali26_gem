## 1. 固定输入与跨菌株身份

W29 目标序列分别为 **374 aa** 和 **458 aa**。本次逐位确认：带版本 NCBI 蛋白 FASTA、旧 UniProt 缓存、AlphaFold API 序列和 PDB 链 A 的全部 Cα 残基序列一致，坐标编号完整覆盖 1–374 / 1–458。历史 UniProt 记录分别是 entry version 31/32、sequence version 均为 1、序列更新日 2017-01-18；输入文件及序列完整 SHA 存在 `target_sequence_structure.json`，没有以当前网页状态替换旧序列。

当前两条 UniProt API 记录均为 `Inactive`，删除原因是 **Not part of a reference proteome**。这是数据库条目状态，不是基因不存在、假基因或蛋白无活性的证据。当前 NCBI 的标题仍为 hypothetical protein，也不能据此抹去已存在的序列同源证据。[F00821g 当前 UniProt](https://rest.uniprot.org/uniprotkb/A0A1D8NLC7.json)、[D16151g 当前 UniProt](https://rest.uniprot.org/uniprotkb/A0A1D8NED6.json)

跨菌株核查有一项实质差异：F00821g **不等同于** Q6C3E0 的 364 aa 序列。在明确的 C 端偏移比较中，W29 多出开头 10 aa，随后 W29 第 11/12 位 S/N 对应 CLIB122 第 1/2 位 M/V；W29 **13–374** 与 CLIB122 **3–364** 的其余 362 位完全相同。这只是序列比较，不断言差异形成机制；尤其不能忽略 N 端差异直接转移定位结论。D16151g 与 Q6C990 的 **458 位全部相同**；同序列也不意味着表达、培养条件或蛋白活性已经验证。[Q6C3E0](https://www.uniprot.org/uniprotkb/Q6C3E0/entry)、[Q6C990](https://www.uniprot.org/uniprotkb/Q6C990/entry)

旧序列注释给出 F00821g 的 GS beta-grasp 25–104 与 GS catalytic 111–374（相应域 pLDDT 均值 96.84、95.47）；D16151g 给出 GS catalytic 112–458（94.90）。这些域来自序列注释，**不是本次由结构比对重新证明**。D16151g 缺少一个命名 beta-grasp 域条目，不等于蛋白缺失 N 端折叠；其 CLIB122 条目仍带相关 N 端超家族注释。

可保留的“**基于 AlphaFold 预测的功能候选**”是：上述序列候选具有相对高置信度的单链折叠，适合后续有边界的结构与实验比较。本轮未测结构叠合分数、配体接触、底物口袋或亚基界面。pLDDT/PAE 不证明真实催化、氨与多胺选择性、定位、反应方向、复合体组成，也不能判定 OR 或 AND。

**数值冲突保留：** API `globalMetricValue` 为 94.81 / 95.00，与本次 PDB Cα 每残基均值相差 +0.0321123 / −0.0226201。初版核查把两种汇总要求在 0.02 内相等，于 BLAST 前触发断言停止；本次没有调宽容差使其通过，而是取消未有依据的“两个汇总必须相同”假设，分别保留数值和失败记录，来源差异仍未决。逐位蛋白身份不受此差异影响，也不把这两种均值写成相同数值。

## 4. 复查边界与审计入口

`check_sequences.py` 默认只读取固定来源、重算身份/置信度并核查保存的 BLAST XML；`--run-blast` 仅允许首次生成，已有 XML 时拒绝覆盖。BLASTP 2.17.0+，BLOSUM62，E≤10⁻⁵，SEG=yes，soft_masking=false，comp_based_stats=2，gapopen=11，gapextend=1，word_size=3，单线程，超时 300 秒。完整参数、输入与参考 SHA、序列版本、原始 HSP、逐位 binding-site 映射及工具/脚本身份保留在相邻 JSON。后续输入指纹变动会停止复查。

这是**固定三个参考的比较，不是全 Swiss-Prot 搜索**；E-value 依赖本小型参考集合，不能与全库值直接比较。未进行同源集系统发育、全面底物谱筛选、定位验证或新结构预测。本轮结果可支持“候选身份与证据缺口”结论，不能批准科学模型/GPR变更。
