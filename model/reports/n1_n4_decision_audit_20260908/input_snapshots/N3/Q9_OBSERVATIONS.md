# 人工Q9：Q0与α需要什么生理观测（N3附页）

旧A包已核实的是人工库存预算：关闭原模型净新合成时，来源补充满足αμ，库存满足Q＋α(B−B0)≈Q0，因而编码生物量上限为B0＋Q0/α。本轮复用终审，不再求解。驱动脚本设Q0＝αB0×pool；旧值α＝10⁻⁴ mmol/gDW、B0＝0.01 gDW/L、pool＝1是输入政策，不是实测校准。

**仅靠增长上限识别不了Q0与α各自的值。** 预算式中只出现Q0/α；两者同乘正数c，上限不变。该脚本的参数化还使上限等于B0(1＋pool)。这是预算层面的可辨识性结论，不声称全部GEM通量或生理轨迹对缩放不变。[N3-C002]

| 要约束的量 | 生理观测与单位 | 仍需排除的混杂 |
|---|---|---|
| 初始细胞总量C_Q | 配对测Q9与Q9H2，分别保存并求和；nmol/样本、mmol/L、mmol/gDW，带内标回收、氧化状态处理及干重 | 氧化还原转换不等于总池消耗；总提取量不等于可动员reserve。 |
| 可支持新增生物量的Q0 | 初始量、供给受限后的剩余量、功能阈值与可动员区分；同批增长/活性数据 | 初始细胞已经占用的功能池不能再全算作额外reserve；区室可达性、结合与不可动员部分未知。 |
| α的候选含义 | 在匹配生长/氧供下新增干重与所需功能Q池的绝对增量；多于一个状态检验比例稳定性 | 单次WT总Q/干重只给含量，不自动给最低需求；呼吸速率不能直接换成Q9净消耗率。 |
| 合成、周转及其他限制 | 配对总Q时间序列、合成阻断有效性、必要时标记周转；营养、氧供及活性 | 残余合成、降解、再分配、营养限制都可改变表型，不能把增长停止全归因于Q耗尽。 |

若另行验证“可达总池C_Q、固定最低功能含量q_min、无残余合成/损失”这一简化，额外reserve才可候选表示为max(C_Q(0)−q_min B0,0)，并检验α是否可对应q_min。该映射未获验证，C_Q、q_min及可达比例均未知，不能代入现有人工Q0。
