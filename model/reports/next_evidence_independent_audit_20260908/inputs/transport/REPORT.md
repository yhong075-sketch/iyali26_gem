# R909、R910、R917：运输方向与质子耦合证据

本轮检得并核对的原始研究，**尚不能确认这三条反应在 Yarrowia lipolytica 中的 1:1 H⁺:底物比例**。新增的原生证据包括鸟氨酸对赖氨酸摄取的竞争作用；腐胺补充支持生长；精胺处理增加质子泵活动及细胞表面净 H⁺外排。三者测量对象不同，不能拼接成某条运输反应的实测计量。以下是作者核查后的证据分层，所有决定性主张仍待独立审阅。[PAT-C020]

| 反应与指定参考中的正向式 | 支持到哪一步 | 反向结果、替代解释与未决项 |
|---|---|---|
| **R909**：H⁺[cy] + Orn[mi] → H⁺[mi] + Orn[cy]；边界 [0,1000]。线粒体鸟氨酸外运、H⁺反向进入，模型写为 1:1 反向运输。 | 酿酒酵母载体重构实验报告鸟氨酸与质子交换；作者提出其生理作用是线粒体向胞质供给鸟氨酸。[Palmieri 1997](https://pubmed.ncbi.nlm.nih.gov/9237680/) | 该研究不是 Y. lipolytica；本轮只核实摘要，定量比例和详细条件未核实。另一酿酒酵母分离线粒体研究发现独立的碱性氨基酸交换活性，提示须区分 H⁺交换与氨基酸对换；这不否定前一载体。[Soetens 1998](https://pubmed.ncbi.nlm.nih.gov/9874237/) 原生方向、比例及边界均未由检得实验确定。 |

| **R917**：H⁺[cy] + Put[ex] ⇌ H⁺[ex] + Put[cy]；边界 [−1000,1000]。腐胺摄取伴 H⁺外流，模型写为 1:1 反向运输。 | 原生营养缺陷株可利用外加腐胺支持生长；酿酒酵母研究另有 pH 5.0 的标记腐胺摄取。[Jiménez-Bremont 2001，图5](https://academic.oup.com/femsyr/article/1/3/195/636473)、[Uemura 2007，图1及方法](https://pubmed.ncbi.nlm.nih.gov/17218313/) | 生长救援未测初始摄取/H⁺比例。原生精胺研究的净 H⁺外排可由质子泵增强解释，底物也不是腐胺。[Cogo 2018，图5、8](https://pmc.ncbi.nlm.nih.gov/articles/PMC5861359/) 酿酒酵母酸性条件外排解释存在示踪外排未检出的限制，不能移植为原生腐胺反向运输的证明。[Uemura 2005](https://pubmed.ncbi.nlm.nih.gov/15637075/) |

cy 为胞质，mi 为模型的线粒体区室，ex 为细胞外。R909 的 mi/cy 表示没有显式分出膜间隙；把它映射为某一内膜面的实验系统仍需说明。1000 是优化边界，不是实测运输能力。R918 核对为 [0,0]，继续关闭。上述为指定暂定参考的静态提取，本轮没有求解或修改运输式。[PAT-C001–C004]

**测量与假设怎样分开**

原参考将鸟氨酸与腐胺的电荷均记为0；C7将它们分别表示为 C₅H₁₃N₂O₂⁺ 和 C₄H₁₄N₂²⁺。这些是文件中的化学表示，不是上述培养条件下测得的微观质子化分布。C7鸟氨酸立体构型未指定，不能自动等同于1978实验的 L-鸟氨酸。本轮没有重新判定酸解离常数，也没有用培养pH推算比例。[PAT-C015]

仅按固定物种电荷与现有系数进行形式记账，R909、R910、R917每单位正向通量造成的胞质净电荷增加，在原参考分别为 −1、+1、−1，在C7分别为 **0、+2、+1**。因此，保持 H⁺系数不变，并不意味着改变物种电荷后仍是同样的电荷转移。这不是实测电流，也不是此次求解结果。[PAT-C016]

若底物从 a 到 b，电荷为 z；n 为随同一方向移动的 H⁺数（反向运输取负），固定物种、单一耦合循环且无滑漏时：

\[
\Delta G=RT\ln(a_{S,b}/a_{S,a})+nRT\ln(a_{H,b}/a_{H,a})+(z+n)F(\psi_b-\psi_a).
\]

C7三条正向反应的 (z,n) 为 (1,−1)、(1,+1)、(2,−1)，电位项系数依次为0、2、1。该代数性质成立的前提不等于生物学已满足；没有两侧活度、电位和耦合证据，就不能由此确定可行方向或新的边界。[PAT-C017]

对质膜摄取，令 Jₛ 为向内底物通量，JH,net 为向外净质子通量，则：

\[
J_{H,net}=J_{pump}-nJ_S+J_{other}.
\]

单独测净外排不能识别 n。**纯示意、不是实验数据**：Jₛ=1、JH,net=5，既可由 n=−1 与其余外排4解释，也可由 n=+1 与其余外排6解释。抑制质子泵又会改变 ΔpH、Δψ 和摄取，不能默认处理前后简单相减即可隔离耦合项。2018结果正好提供了泵活动变化这一替代解释；其泵荧光/ATP水解倍数也不能相除得到运输计量。[PAT-C018]

**最小判别实验建议——尚未实施，也不构成新的计算或实验授权**

| 要判断的分歧 | 最少需新增的观察 | 何时可以作结论 |
|---|---|---|
| R910的同向 H⁺内流，与无耦合/其他驱动力 | 原生来源、取向已知的质膜体系，同时取得标记 L-鸟氨酸与校准后的摩尔 H⁺初始通量。先定一个记录完整的条件；pH 5.0可作为连接1978结果的首个候选点，需另行确定适用菌株及两侧条件。 | 排除吸附、漏通量及残余泵后，底物摄取与 H⁺同向才支持同向耦合；仅观察摄取或pH响应仍不足。 |
| R917的 H⁺外流，与同向摄取/泵代偿 | 在同类质膜体系独立测腐胺，不用精胺替代。固定并测量 ΔpH、Δψ；有无底物、空膜泡、相同缓冲容量及残余ATPase对照；底物加样本身的酸碱响应另扣除。 | 相反方向的配对 H⁺才支持反向耦合；若能去除背景且存在非零初始底物通量，用耦合 H⁺对底物的斜率及不确定度判断是否接近1。未解决混合载体时只能报告体系有效比例。 |
| R909的鸟氨酸/H⁺交换，与跨膜氨基酸对换 | 独立的原生线粒体/内膜体系，明确实验膜面的方向；配对鸟氨酸 mi→cy 与 H⁺ cy→mi，并用跨侧氨基酸是否促进运输来区分对换解释。 | 先证明膜完整、底物确实跨膜，再在可控梯度下检验配对方向与比例；质膜实验不能代替这一项。 |

三者共同的验收条件是：原始底物/H⁺通量、缓冲容量、膜完整性、ΔpH/Δψ及不确定度可追溯；梯度反转/消散对通量的影响须与所提机制一致。非零通量范围内的比例稳定性才有意义；零摄取、不可分辨的信号或异常值不得通过相除生成“1:1”。完整细胞摄取加表面pH可作先导筛查，若质子泵和多载体贡献仍未分开，就停止在有效净通量结论，不升级为分子计量。以上预期收益是提高机制可识别性，尚无本次实验验证。[PAT-C019]
