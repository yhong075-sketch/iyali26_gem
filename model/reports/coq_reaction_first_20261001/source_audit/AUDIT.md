## 化学拆分

旧 R19 为线粒体内：

`S = m63 (C52H80O2, 0)`

`Q = m59 (C52H78O3, 0)`

`S + O2 -> Q + H2O`

该净式原子与电荷守恒，但它同时包含**羟基引入及醌醇氧化成醌**。守恒不能证明是某个酶实测的单步反应。

官方 EC 1.14.15.46 与 Nicoll 的实测反应先生成 `QH2 = C52H80O3, 0`：

`S + O2 + 2 Fd_red + 2 H+ -> QH2 + H2O + 2 Fd_ox`

Fd 的氧化还原态原子相同，Fd_red 电荷比 Fd_ox 少 1。其后仍需指定：

`QH2 -> Q + 2 H+ + 2 e−`

后一式只是半反应，不是可以直接放进 GEM 的无受体反应。候选前一步可以赋 COQ6；完整原 R19 的净反应仍没有被所审来源精确指派。

在上级已记录的**中性 NADH/NAD、相差 2 H** 的模型约定下，等效羟化候选可写：

`S + O2 + NADH -> QH2 + H2O + NAD`

这一候选供体链可承接此前针对 C5 的 **YALI1B03314g / YAH1 铁氧还蛋白候选（XP_500417.1）**与 **YALI1B19490g / ARH1 还原酶候选（XP_500902.3）**证据，但 C1 原生 NADH 耦合仍是跨物种假设。若保持 lumped 表示，可候选为 `YALI1A08781g and YALI1B03314g and YALI1B19490g`；若显式建 Fd 池，羟化 GPR 与供体再生应分开。

**不能用一句“醌醇会被氧化”消去全部还原力成本。**

| 后续假设 | 两步相加的净式（使用上述中性 NAD 约定） | 证据判断 |
|---|---|---|
| `QH2 + NAD -> Q + NADH` | 恰好恢复旧 `S + O2 -> Q + H2O` | 数学可相消；所审来源没有直接证明此 NAD 还原反应或其与羟化的耦合。不能据此建生理通路。 |
| `QH2 + 0.5 O2 -> Q + H2O` | `S + 1.5 O2 + NADH -> Q + 2 H2O + NAD` | 氧作为最终受体的形式净式，**不等于原 R19**；仍需验证底物、催化/自氧化机制与适用条件。 |
| `QH2 + O2 -> Q + H2O2` | `S + 2 O2 + NADH -> Q + H2O + H2O2 + NAD` | 另一形式氧化结果；产物和计量同样不等于原 R19，不是本次获得的特定生理实测式。 |

也可以形式上让 QH2 还原 Fd_ox 从而回收先前消耗的 Fd_red；这只是另一种代数消去，没有所审实验证据。**未找到直接支持，不等于证明任何此类催化机制都不可能。**

R18 当前以 Q 为底物；只给 R19 增加 QH2 会引入新的衔接缺口。Nicoll 的下一步甲基化实验使用醌醇。应在后续有限化学方案中明确选择氧化步骤或审查下游底物状态，不能偷偷增加无成本醌醇汇。

## 来源审计及反证

**S1 官方反应定义。** [IUBMB EC 1.14.15.46](https://iubmb.qmul.ac.uk/enzyme/EC1/14/15/46.html)，2024 建项。Accepted name、Reaction、Comments 与 reference 1 已重开核查；快照在 sources。定义产物为 1,4-benzoquinol，消耗还原型铁氧还蛋白和氧。名称中的 phenol **4-hydroxylation** 对应 CoQ 前体沿用编号的 **C1**；不能把编号差异当作不同羟化位点。该条引用 S2，**不是第二份独立实验**。

**S2 精确的羟化实验参考。** [Nicoll 等，2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC7615680/)，DOI 10.1038/s41929-023-01087-z。已重开 Results “COQ4 and COQ6 are responsible…”、Fig. 4、Fig. 1 图注和 Methods “Small-scale reactions”。实验参考为截短四足动物祖先构建 **OQ859713.1 / WLG15894.1，tAncCOQ6_tr**（不是酿酒酵母或人天然序列；本次已查看主代理保存的 GenBank 身份）。截短与全长均显示 4a→4b；FDXR/FDX2/NADPH 系统参与，孤立条件产物低，接 COQ4 后更高。使用单异戊二烯尾部类比底物。COQ6 对羧基前体 3 无活性。Fig. 1 注释承认醌醇可经酶、氧或歧化转成氧化态，但没有为本 R19 指定 NAD+ 再生、氧化酶或完整氧计量。故支持羟化候选，不支持照抄旧净式。

**S3 直接的酵母反证。** [Ozeir 等，2011](https://hal.science/hal-00630764/document)，DOI 10.1016/j.chembiol.2011.07.008。复用已归档全文，并重新读取 Results “Coq6 is required for the C5- but not the C1…”（PDF 页 14–15；稿件页 5–6），Fig. 2 相关正文。**YGR255C / COQ6，P53318** 是酿酒酵母 CoQ 羟化酶；其缺失株经 Coq8 过表达，或表达失活 Coq6 突变体，仍积累已发生 C1 羟化的 4-HP/4-AP。这反对“所有真菌 C1 修改必需 Coq6”。它不排除 S2 对甲氧基化酚的实验活性，也不否定原生 COQ6 作为底物匹配候选；不同反应顺序、物种与底物状态必须保留。

**S4 COQ4 的替代路线与限制。** [Pelosi 等，2024，公开作者稿](https://iris.cnr.it/retrieve/12ea9ce7-85c7-491f-80e7-8c0b7e131d03/COQ4.pdf)，DOI 10.1016/j.molcel.2024.01.003。已重开 PDF 页 10–14，Figs. 3–4 与 Discussion。人/酵母 COQ4 可恢复细菌 decarboxylase+C1 hydroxylase 双缺失，却不能恢复仅缺 C1 hydroxylase、已积累脱羧底物的菌株。酵母 COQ4 为 **YDR204W / COQ4，O13525**，CoQ 脱羧/复合体相关蛋白；异源细胞实验支持氧化脱羧。在无内源 CoQ 系统的 Corynebacterium 中检出 polyprenyl-benzoquinone，但作者保留原初产物羟基/酮氧化态及机制不确定性。Discussion 由酵母 vanillate 绕过提出可接受 C5 甲氧基化羧酸前体；因此联合 R40+R19 候选值得保留。并未提供独立旧 R19 的证据，或完整无供体净计量的纯化实验。

**S5 2026 的有限更新。** [Wu 等，2026](https://link.springer.com/article/10.1186/s44280-026-00132-3)，DOI 10.1186/s44280-026-00132-3，2026-06-24 发表。Results “TgCoq4 exhibits…”/Fig. 2 与 Discussion 已核查。**TGGT1_275980 / TgCoq4**（434 aa，Coq4 家族蛋白）在线粒体定位，并部分恢复 E. coli 双缺失株的有氧生长。正文报告重组蛋白对未异戊烯基化 4-HB 的体外测定未检出活性。此为进一步跨物种功能支持，不能称其已纯化重构旧 R19、解决醌醇氧化或确定所有辅因子。其邻近标记也不等同直接复合体或共同必需 GPR。
