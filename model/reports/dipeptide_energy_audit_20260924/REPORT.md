# 二肽身份与封闭ATP再生：本轮实际审计结果

核验日期：2026-09-24。**四条二肽水解暂不能正式补GPR或确定液泡定位；封闭ATP再生已定位三种具体路径，但尚未修复。** 三条已知异常合成方向同时限制后，完整封闭模型仍达ATP测试上界1000。真实培养下生长保留，不等于能量正确。

## 1. 四条二肽反应能否接受酶/GPR？

| 反应 | 精确自由底物 | 本轮裁决 |
|---|---|---|
| R2021 | Gly-Asp | 无可接受的W29精确底物酶；不补GPR |
| R2029 | Gly-Glu | 同上；不能用Glu-Gly或γ-谷氨酰反应替代 |
| R2034 | Ala-Gly | 同上；不能用Gly-Ala替代 |
| R2039 | Gly-Pro | 有较合适的prolidase-like实验候选，但催化/区室仍未确认 |

R2039优先待测候选为 **YALI1E16433g（原生正式名称未核实；预测M24B prolidase-like肽酶）**，W29 AOW05368.1=XP_503902.2，454 aa，含自动注释的Prolidase结构域。它与旧CLIB122同源序列有1个残基差异，不能直接声称旧结构与W29序列相同。支持程度为版本明确的序列/家族注释，未上升为原生游离Gly-Pro酶实证。[NCBI记录](https://www.ncbi.nlm.nih.gov/protein/AOW05368.1)、[IUBMB酶定义](https://iubmb.qmul.ac.uk/enzyme/EC3/4/13/9.html)

对于R2200的 **YALI1F23706g（原生正式名称未核实；DUG1-like/M20A Cys-Gly金属二肽酶候选）**，现有证据不足以将其赋给上述四反应。其W29当前蛋白XP_505554.3/AOW07335.1及复用的既有AlphaFold预测均为同一478 aa序列。高pLDDT支持预测结构可靠性，不能证明精确底物或液泡定位。酿酒酵母 **YFR044C/DUG1（实验确认的Cys-Gly金属二肽酶）** 的关键底物表未测试这四种目标，所以属于“未测试”，不是阴性结果。[2009年原始实验Table2](https://pmc.ncbi.nlm.nih.gov/articles/PMC2682898/)

每条底物顺序、版本、实验支持/反对、区室等级和最低确认实验见 [反应证据卡](reaction_identity_cards.md)；结构预测来源和局限见 [身份核查](identity_r2200/REPORT.md)。未新跑AlphaFold、BLAST或对接。

## 2. 液泡定位和化学身份可靠吗？

四条实际反应全部在C_va，但旧名称为“cytosol nonspecific dipeptidase”；这一冲突已存在于两个原始iYali输入。名称不能推翻计量区室，计量区室也不是原生定位实证。现有证据不足以接受液泡腔定位，也不足以直接迁移至胞质。

12个二肽池（ex/cy/va）及液泡Gly缺分子式/结构字段。条件性补式可以算出，但不能把算术配平等同于底物身份确认。胞质、胞内、分泌通路与分泌到胞外不能混称；游离二肽水解不能与从长肽切下二肽混称。详细原始字段与来源见 [溯源报告](provenance/REPORT.md)。

## 3. 无外源输入的ATP具体从哪里来？

在保留1877个代谢物稳态约束的完整模型中，关闭183条单侧来源/交换/排出列及6条biomass合成列，共189条；释放原维护下界为0。没有放宽内部方向、没有添加ATP或二肽源、没有删除稳态约束。零通量在全部变量和约束边界内可行。

直接使用原有、按存储分子式/电荷已经配平的耗散列：

**D = ATP[cy] + H2O[cy] → ADP[cy] + Pi[cy]。**

最大D=1000 mmol gDW−1 h−1，达到人为容量上限；不是测得ATP产率，也不能由此说数学问题无界。固定D=1后，最小化其他反应绝对通量总和得到以下三种不同见证。下表全部在胞质，未省略H+、H2O或Pi；正负号相对于模型存储方向。

| 路径 | 反应/通量 | 按实际通量方向的化学式 |
|---|---|---|
| PEP路径 | R_PGAM1_PhosHydro +1 | pyruvate + Pi → PEP + H2O |
| | R694 +1 | PEP + ADP → pyruvate + ATP |
| GTP路径 | R_NTP3pp +2 | 2 GDP + 2 Pi + 2 H+ → 2 GTP + 2 H2O |
| | R594 −2 | 2 GTP + 2 ADP → 2 GDP + 2 ATP |
| | R2010 +1 | DHA + ATP → DHAP + ADP + 2 H+ |
| | r0242 −1 | DHAP + H2O → DHA + Pi |
| UTP路径 | R_NTP7 −2 | 2 UDP + 2 Pi + 2 H+ → 2 UTP + 2 H2O |
| | R603 −2 | 2 UTP + 2 ADP → 2 UDP + 2 ATP |
| | R2010 +1 | DHA + ATP → DHAP + ADP + 2 H+ |
| | r0242 −1 | DHAP + H2O → DHA + Pi |

**每一路去掉D后都精确净生成：ADP + Pi → ATP + H2O = −D。** 再加D，所有物种抵消。这证明是能驱动耗散的ATP再生循环，而非与ATP无关的普通净零循环。

PEP路径的pyruvate/PEP抵消；GTP/UTP路径的核苷磷酸、DHA/DHAP和H+抵消。GTP路径中生成2ATP、DHA磷酸化消耗1ATP，因此净得1ATP。所有逐物种加权贡献、分子式/电荷、反应GPR和来源notes均导出：[完整活跃反应](energy_delivery/atp_witness_fluxes.tsv)、[净反应账本](energy_delivery/atp_net_reaction_ledger.tsv)。

保存4份L1见证，其中两份是同一GTP路径，故只报告3种不同路径。L1分别2、6、6；它是通量总量最小解，**不是严格最少反应数证明**。每次干预都从完整封闭基线重新开始，不在裁剪后的见证小图里验证。

## 4. 哪些是生物学错误，哪些只是数学断路？

PEP路径各列均元素/电荷守恒，问题在于把PEP磷酸酶逆转为没有能源耦联的PEP合成。[PEP水解定义](https://www.kegg.jp/entry/R00208)支持仅保留水解的方向候选。GTP/UTP磷酸水解的反向合成也缺少适用酶学/能量依据。[GTP定义](https://www.kegg.jp/entry/R00335)、[UTP定义](https://www.kegg.jp/entry/R00159)

另外，当前R_NTP3pp、R_NTP7、r0242的存储正向分别有H/charge残差−1、+1、−2。见证中这些错误加权后抵消，**整体净式正确不能证明每一列化学正确**。原维护列本身并没有这个问题。

静态追踪找到管线原因：水解单向整理在早期gap-fill阶段已有，但后续metadata字段选择把三条恢复双向，并改变部分H+计量。应在最终输出层核验修订不会被覆盖。三条高能合成方向候选、化学配平候选与仅用于断路的控制分别列在 [候选修订清单](candidate_corrections.md)。正常丙酮酸激酶、核苷二磷酸激酶不能仅因出现在路径中就删除；r0242见证用的逆向本来就是水解。

## 5. 限制方向后，封闭ATP和真实培养怎么样？

六个单方向干预及两个联合干预全部optimal，最大D仍为1000。最强的本轮组合限制为：PGAM正向关闭、NTP3pp正向关闭、NTP7逆向关闭，仍未通过能量验收。因此模型还允许未枚举的替代路径；本轮按三种不同见证的范围停止继续枚举，完整剩余通量已保存。

| 实际运行版本 | 封闭最大D | 真实PO1f/SD-Leu WT，h−1 |
|---|---:|---:|
| 原版 | 1000 | 1.8718823069402888 |
| 三方向联合限制 | 1000 | 1.8718823069402994 |

真实培养比较恢复原交换、生物量目标及NGAM下界7.8625；约1.1e−14的差异在数值容差内。旧WT见证曾使用PGAM异常合成方向119.45，本轮没有沿用它作为修后可行证据，而是实跑两次对照。新的生长解可行也不代表能量代谢合理，因为该候选仍有封闭ATP再生。

没有接受酶/区室修订版本，故未伪造二肽单改版与联合版比较；没有新增基因敲除或重跑历史screen。[八项干预](energy_delivery/direction_interventions.tsv)、[生长结果](growth_comparison.json)

## 6. 本轮执行和独立核查覆盖什么？

固定输入是本地默认 `model_metadata_trna_r1159_leak.xml`，不是9月21日另存的V-ATPase候选。四个历史输入指纹核对一致，使用现有加载器和工作区内的PO1f/SD-Leu配置。代码处于原有dirty工作树；没有以HEAD声称所有运行文件干净。完整输入/代码/培养/菌株/求解参数和前态见 [总清单](closed_energy_manifest.json) 及链接的原始运行清单。

实际调用16次：13个有效封闭LP、2个有效生长LP，另有1次初始软件失败尝试。最初COBRA复制重置了底层求解器参数，保存时又遇到无限时间上限的JSON错误；该次未计作合格结果，实际耗时未知，预算仅保守预留60秒。修复后另一次账本跨副本对象匹配错误停止了整理；其两份有效求解原始结果保留，修复账本后复用，没有隐瞒或重复计数。每一阶段代码快照与日志保留。

预先声明上限60次LP、1200秒累计求解调用时间、每次60秒。实际调用数未超预算；有效15次求解调用合计约0.287秒，加首次失败的60秒预留仍低于累计预算，但首次实际耗时未知，不能称全轮实测耗时已知。以上不包括构建/解析/文件写入墙钟时间。15次有效计算均实际设置并记录60秒、1线程、Presolve=0、三容差1e−7；没有放宽容差获取结果。

独立审核覆盖15份全部2314维通量、八项方向变更、四份账本及真实培养恢复，最大独立守恒残差约2.28e−13，边界违反为0。输入20项保护SHA不变；8项不含优化的静态/恢复测试通过。一次误用系统Python导致依赖导入失败的测试日志也保留，正确工作区环境重跑通过。独立核验不是独立重新优化，也不声称重建所有历史环境。COBRA复制的固定零通量R1372列有极小底层矩阵舍入，已记录，不影响本轮封闭可行域。[独立结果审核](boundary_audit/RESULT_AUDIT.md)

## 7. 整合的前提和剩余缺口

当前有两个阻塞正式接纳的缺口：**原生酶/精确底物/区室未确认；全模型封闭ATP仍异常。** 先完成能量方向和化学修订的可重复验收，再根据真实定位确定二肽及氨基酸转运；特别是R2035当前没有H+，不能一概解释为质子同向运输。最后才考虑有前体序列、成本、供给量和定位证据的内源蛋白周转模块。

后续版本、运输逐项要求、实验最小设计和停止条件见 [整合计划](integration_plan.md)。本轮实际修改仅为诊断代码、测试、证据和状态文档；正式模型、GPR、培养、biomass及管线整理数据未变，未commit/push或发起集群作业。
