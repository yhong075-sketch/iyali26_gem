## 为什么 R795 仍被强制为零

从原 XML 的全部液泡物种行提取计量，并与本次 `open_WT_fluxes.tsv` 的实际边界逐项核对。R795 的模型式为：

```text
ATP[cy] + H2O[cy] + 2 H+[cy] -> ADP[cy] + Pi[cy] + 2 H+[va]
```

以下是删除已固定为零的反应后，现有模型的必要稳态等式。这里液泡水限制的是下游水解网络；R795 本身使用胞质水，不能说泵直接缺少液泡水底物。

1. 液泡水的唯一供给反应 R1363 实际为 [0,0]；其余 4 条都是下界为 0 的不可逆水解：

   `-v2021 - v2029 - v2034 - v2039 = 0`

   所以 `v2021=v2029=v2034=v2039=0`。

2. 三个二肽物种各只有对应转运和上述水解作为非关闭项：

   `Gly-Asp: v2020-v2021=0`；`Gly-Glu: v2028-v2029=0`；`Gly-Pro: v2038-v2039=0`。

   所以 `v2020=v2028=v2038=0`。

3. 液泡甘氨酸和脯氨酸行分别为：

   `v2021+v2029+v2030+v2034+v2039=0`；`v2039+v2040=0`。

   所以 `v2030=v2040=0`。液泡异亮氨酸行唯一未关闭项是 `v882=0`，对应去路 R883 已关闭。

4. 液泡 H⁺ 的全部 22 条关联反应中，开放后的非关闭项化简为：

   `2*v795 - v882 + v2020 + v2028 + v2030 + v2038 + v2040 = 0`。

   代入上面的约束即得 **`v795=0`**。

这是依赖现有计量和边界的数学结论，无需假定生长最优；与本次直接最大化 R795 返回 0 一致。通常只放宽上界保留原可行解，故最大生长不会因此降低，但是否增加应由计算判断。本次还有上述更强的阻塞证明，因此开放上界没有增加可行通量能力。不能把一般的“允许通量不等于要求通量”代替本次具体的网络阻塞解释。
