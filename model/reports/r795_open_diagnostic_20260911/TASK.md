# 临时开放R795的影响

用户问“打开R795会发生什么”。使用三共同AND假设模型，R795只在一次性内存模型把bounds从[0,0]放宽至[0,1000]（借用R794同上界，作为诊断设定，不宣称实测容量）；保留下界0，不强迫运行。SD-Leu/PO1f、其他计量/GPR/培养/目标不变。模型、管线和整理数据不写回。

顺序：核对固定输入/封存源码；WT关闭/开放生长比较；开放后三个共同亚基分别单敲；开放WT最优生长下R795最小/最大通量（生物量下界=本次open最优值−1e-8 h^-1，数值松弛明确记录）；若该范围为零，可选做一次无生长最优下界的R795最大化区分阻塞与目标权衡。最多8个主LP，总600秒、每LP60秒、Threads1，不重试、不调参；失败/非有限值保留并停止后续依赖，不当作死亡。并非新的全基因screen；仅三目标分类，采用既有严格1/5/10/15%且不舍入。
