# 指定双敲加其余单敲：未出现额外生长下降

2026-09-18。实际完成28主LP：WT、14个成员各单敲、指定双敲，以及双敲背景上分别叠加其余12个成员。全部optimal，一次执行4.87秒（模型加载后28次求解及记录约1.18秒），没有重试。

**指定双敲后生长为WT的86.1725%；12种三敲均与双敲相同。按严格KO/WT<15%，双敲和所有三敲均未达到必需／致死阈值；1/5/10%也相同。** 这里评价的是组合，不把三敲结果当额外成员的单基因必需性。

该输入保留旧R_NTP1结构，不包含后续已实施的R_NTP1水解或R539修订，**不是9月18日最新默认管线模型的screen**。选择它是为了与本任务前次实验同条件比较；结果不转写至新模型或全局必需计数。

**原因已由全模型GPR和边界核对确认：** 当前规则把YALI1F38820g提升为共同AND，所以它单敲就关闭两泵。指定双敲与此单敲关闭的反应相同；再敲其他12个成员中的任一个，都没有额外关闭其他反应。全部三敲的完整计量、GPR、边界和目标与双敲一致（基因functional状态按实验不同），故有效优化问题完全相同。唯一有额外反应关联的成员在R_NTP1还有一个保留OR分支，因此不会产生额外边界变化；原始完整规则保存在effective_reactions.json。

14个单敲中，三个共同AND成员各关闭两泵、生长约86.1725%；其余11个单敲不关闭任何反应、生长约100%。相对于100%的最大浮点偏差为1.23×10⁻¹⁵，原值保留，没有人为改写成1。

关闭两泵后基础生长仍存在，与前次零泵可行解一致；这不证明真实细胞不需要酸化。当前输入还存在既有的R_NTP1未编码供能耦联问题，限制绝对生长率的生物学解释。本次双敲解R_NTP1通量为180.9596820268488，与旧保存解的不同通量不能混用；本次没有修改或评估其后续修订版本。
