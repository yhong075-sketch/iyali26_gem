# Yarrowia lipolytica 原生 CoQ 系统与表达证据

2026-09-18。此次把“如何表达”分别核查为：原生 CoQ 产物、候选基因的实际转录、蛋白功能/定位及调控。**取得了九个 CoQ 候选位点的原生 RNA-seq 表达记录；逐蛋白催化机制、定位和复合体依赖仍不等于已验证。** 本次没有修改模型、管线、GPR或实验评价口径。

## 原生系统与功能层次

Y. lipolytica 有 CoQ₉。原始研究在本菌纯化的线粒体复合体I制备中检测到Q9；这是产物存在的直接证据，不能把制备物中的含量当成细胞内总浓度或合成通量。[Dröse等，2002，PMID 12351219](https://pubmed.ncbi.nlm.nih.gov/12351219/)

结合物种序列注释与跨物种机制，工作框架为：侧链合成、侧链与4-HB连接、环修饰以及辅助蛋白共同支持CoQ₉合成。线粒体内膜/基质侧是值得核查的组织框架；本次没有取得九个原生蛋白逐一定位或完整CoQ合成复合体重构证据。呼吸链利用Q9/Q9H2与这些蛋白合成Q9是不同过程。

## 蛋白功能和调控证据的边界

**COQ1：** [Saeed等，2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11237637/)使用解脂耶氏酵母蛋白XP_501989.1的催化部分，并换成酿酒酵母靶向段，在酿酒酵母产生Q9。这支持侧链酶功能，不能当成解脂耶氏酵母原生启动子、表达量或定位测定。主文Fig.5是工程酿酒酵母；本次未取得补图S2原图，不把它充作新核实的原生测量。

**COQ6与PKA：** 找到2013年本科论文用抗磷酸化底物抗体富集、二维电泳和MALDI-TOF鉴定候选蛋白。表4.1的spot25描述为putative COQ6，但原文编号是**YALI0C09042p**（原生正式名/确切蛋白身份未闭合），与本项目和2019表达表中的YALI0A09042g不是同一字符串；同表另两行又把C09042p用于不同蛋白描述。原表经过视觉核查，不能静默把C改为A。

因此它只能记录为“可能涉及Coq6的原生蛋白/PKA调控线索，位点归属未闭合”。论文自己要求进一步体内/体外验证。它是学位论文，不是已核实的同行评审酶学结论；不能写成“PKA已经证实直接调控YALI1A08781g”，更不能据此推断CoQ系统整体转录调控。[原论文，表4.1及讨论，印刷页40–42](https://repositorio.ub.edu.ar/handle/123456789/2444)

## 对当前研究的含义

原生转录数据加强了这九个候选确实被表达的依据，但不决定GPR中的AND/OR。当前优先缺口仍是COQ6原生电子供体、逐蛋白定位以及C1化学，而不是缺少COQ6转录的证据。此数据的W29碳限制恒化条件也不是当前模型的PO1f/SD-Leu筛选条件，不用于替换旧essentiality标签或解释其数值阈值。

本轮未找到足以闭合本菌九蛋白完整复合体组成、统一启动子调控或逐位点原生催化酶活的直接研究；这是本次有界检索的覆盖限制，不声称相关证据不存在。旧专利的工程表达/产量、其他物种的酶学及KEGG自动注释分别保留为不同层级，不当原生九蛋白已验证证据。
