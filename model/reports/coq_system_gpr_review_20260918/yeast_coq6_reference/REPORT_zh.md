# Coq6：酿酒酵母模型参照核查

2026-09-18，只读研究。已检查固定 Yeast-GEM 9.1.1、项目内 Yeast-GEM 9.0.2、iMM904 和当前 R539 标记模型。**酿酒酵母可提供功能和电子供给线索，但所查模型的 GPR/计量不能直接复制到 iYali26。** 本轮没有修改模型、管线或整理数据，没有构建、优化或 screen。

## 模型实际存储内容

| 模型及反应 | C5 羟化的实际表示 | GPR 与限制 |
|---|---|---|
| Yeast-GEM 9.1.1 `r_0043` | 胞质；六异戊二烯侧链底物 + 0.5 O₂ → 羟化产物；无还原供体 | `YPL252C or YDR376W`，没有催化蛋白 COQ6 |
| Yeast-GEM 9.0.2 `r_0043` | 与上行相同 | 同一 OR；两个版本一致不构成独立生物学验证 |
| iMM904 `3OPHB5Hm` | 虽然名称称 mitochondrial、ID 以 m 结尾，实际三个物种全部在胞质；同样仅 0.5 O₂ | 无 GPR |
| 当前 iYali26 `R39` | 胞质；九异戊二烯侧链底物 + 0.5 O₂ → 羟化产物 + H⁺；无还原供体 | 无 GPR；底物为中性酸、产物为负一价阴离子，不能把另一模型的质子系数照搬过来 |

以上根据 SBML 物种的区室、化学式、电荷和反应引用提取，不凭反应名称推定。当前 R39 与酿酒酵母表示相似，但侧链和质子化状态不同，不称计量完全相同。固定 9.1.1 的 [上游文件](https://github.com/SysBioChalmers/yeast-GEM/blob/2d594ae1c4a2d550ccef120d96a58c7bbf586255/model/yeast-GEM.xml)对应本地已保存版本，不声称今日远端最新。

Yeast-GEM 将 COQ6 放进另五条 CoQ 反应共用的六基因 AND；iMM904 相应五条反应使用七基因 AND。前者包含 `r_0022`，对应当前 R19 的后续氧化表示。这体现模型的途径依赖约定，不能证明 COQ6 直接催化每个甲基化/羟化步骤，也不能据此把大 AND 复制回 R19。完整原规则保存在 `model_comparison.json`。

## 基因身份与原始实验

| 系统 ID | 名称及蛋白功能 | 本次采用的证据等级 |
|---|---|---|
| 酿酒酵母 YGR255C | COQ6；FAD 依赖单加氧酶，参与 CoQ 环 C5 羟化 | 酿酒酵母突变、代谢物与前体救援实验支持；不是解脂耶氏酵母原生酶活证明 |
| 酿酒酵母 YPL252C | YAH1；线粒体铁氧还蛋白，电子载体 | 原生条件性突变实验支持 CoQ 合成依赖；与下行共同作为电子供给机制线索 |
| 酿酒酵母 YDR376W | ARH1；线粒体铁氧还蛋白还原酶 | 原生条件性突变实验支持 CoQ 合成依赖；不等同于另一种独立 C5 羟化酶 |
| 解脂耶氏酵母 YALI1A08781g | COQ6 功能候选；推定 FAD 依赖 CoQ 单加氧酶，原生正式名称未独立确认 | 复用本轮前段的版本化序列比较及同序列既有 AlphaFold 预测；不是原生酶学或定位实验确认 |

[Pierrel 2010](https://pubmed.ncbi.nlm.nih.gov/20534343/) 支持铁氧还蛋白与还原酶均参与酿酒酵母 CoQ 合成，并将受影响步骤指向早期羟化。[Ozeir 2011](https://pubmed.ncbi.nlm.nih.gov/21944752/) 用突变和可绕过缺陷的前体支持 COQ6 的 C5 功能；其摘要对两蛋白作为体内电子来源保留可能性措辞。因此这些资料支持电子供给链的候选解释，不应冒称已用纯化酿酒酵母三蛋白直接完整重构。

模型 `r_0043` 所引 [PMID 15792955](https://pubmed.ncbi.nlm.nih.gov/15792955/) 主要研究 CoQ 生物合成蛋白的复合体关联；本次核查的摘要不能为 `YAH1 OR ARH1` 独立替代催化解释提供依据。结合上述蛋白功能，该 OR 不适合作为待迁移的催化规则。

[2015 年实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC4591803/) 还支持 COQ6 在酿酒酵母 pABA 支路参与 C4 脱氨；不能将 2011 年的表述推广成“COQ6 在所有物种、全部底物上只做 C5”。该 C4 反应也不能直接拿来确认当前 R19 的 C1 机制。全文与摘要的实际访问覆盖以 `source_audit.json` 为准。

## 可借鉴的候选表示

候选方向是：保留 iYali26 的九异戊二烯侧链，将 C5 羟化定位、还原电子供给和催化 GPR 作为一个相互关联的重构问题。COQ6 是蛋白名；酿酒酵母产物 CoQ₆ 中的下标则指侧链长度，二者不能混同。

1. **催化步骤：** 根据跨物种机制提出线粒体 C5 羟化候选，候选催化 GPR 为上述 YALI1A08781g。必须连同 R39/R969/R808 的区室连接核查；不是直接给旧胞质 R39 填入基因。
2. **电子供给：** 显式区分还原/氧化铁氧还蛋白及其再生反应。供体的解脂耶氏酵母原生位点、辅因子偏好和定位在本次尚未鉴定，不能虚构 GPR 或把酿酒酵母基因 ID 塞进来。若用合并反应表达依赖，也必须先有相应身份和机制依据，不能把 OR 随手改成 AND 即视为解决。
3. **化学参考：** [IUBMB EC 1.14.15.45](https://iubmb.qmul.ac.uk/enzyme/EC1/14/15/45.html) 明确写出完整 O₂、两个单电子还原态铁氧还蛋白和水的计量，可作为校核框架；其依据包含体外重构的脊椎动物体系，不能替代原生功能证据。最终 H⁺ 系数须依选定物种的化学式、电荷和质子化状态重算。
4. **保留未决：** R40/R19 的联合 C1 重构仍与这一 C5 候选分别记录。也不因参考模型可生长或有 AND 就认定当前 CoQ 合成已与生物量需求耦联。

本次实查加强了“COQ6 功能候选有依据、旧 R39 表示尚不足”的结论。下一项实质证据缺口是原生电子供给蛋白及其线粒体供给机制，而不是再次复制酿酒酵母的大 AND。

## 可复核范围

`extract.py` 仅使用标准库读取四个 XML，包含固定输入身份、目标 GPR、区室和 O₂ 系数断言。`model_comparison.json` 保存目标方程、边界、化学式、电荷、原始 XML、来源 URI 与完整输入 SHA；独立审核另直接读取原始模型和文献。没有通过模型名称搜索推断“全模型不存在任何其他电子载体”，没有进行生长/必需性计算。
