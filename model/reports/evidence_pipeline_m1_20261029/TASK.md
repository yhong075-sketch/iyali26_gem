## Plan

| Module | Content |
| --- | --- |
| `schemas.py` | Pydantic v2 types: predicates, the 19 claim levels, `Condition` (+ `medium`, `marker_complementation`), `SubjectRef`, a value union keyed on predicate, `Claim`, `Passage` (≤ 25 words, char offsets), `Source` (kinds incl. `legacy_case`, `prior_model`; `peer_reviewed`, `unpublished`, `legacy_scoring`), `PairClass`, `PairRelation`, `Assertion`, `Verdict`, `Decision`, and the R1–R3 contracts as types only (`ConflictPacket`, `ReviewVerdict`, `ClaimChallenge`, `DecisionReview`) |
| `weights.py` + `model/curation/evidence_pipeline/evidence_weights.yaml` | One versioned YAML: level → ECO and expected ECO branch, admissibility, per-predicate directness tiers, level bands, confidence rules, subsystem precedence, canonical strain set, `essentiality_threshold: 0.15` with sensitivity `[0.05, 0.10, 0.15, 0.20]`, verdict priority weights, literature-compartment → model-compartment map |
| `taxonomy.py` | `taxon_distance` from organism + strain in code; a null strain is never W29 |
| `id_map.py` | Gene ID table on `LocusCrosswalk` + model UniProt/NCBI annotations + S2 GeneID, with `cardinality` (1:1, 1:n, n:1); anything not 1:1 is `UNRESOLVED`; dispositions for the 15 non-YALI1 model gene IDs |
| `rules.py` | Comparability, value conflict per predicate, pair classifier (derivative, independence classes, supersession, strong/weak) |
| `aggregate.py` | L4 forward pass (R1 scope count, R2 directness, R3 taxon, R4 independence, R5 rebuttal, R6 recency, R7 advisory only) and the derived 0–4 score with `n_independent` reported beside it |
| `verdicts.py` | L5 engine. Takes the model as an input and records model path, commit and SHA-256 on every verdict; elements: existence, GPR, compartment, bounds, cofactor, subsystem; priority = model impact × uncertainty |
| `trace.py` | `trace()`, `load_bearing()` (leave-one-out), `chain_quality()` (`homology_only`) |
| `converters.py` | Deterministic L0–L2 builders: parent-model inclusion (iYli21 reactions and GPR genes, with origin tags where available), the model's evidence-status notes (`prior_model`), W29 13C rows (`unpublished=True`), Cas9/Cas12a rows and the consensus list (derivative of the screens), the 240 legacy cases (sources only, `legacy_scoring=True`, no live claims), and hand-written literature claims whose quotes are verified against the cached `gem_review` chunks |
