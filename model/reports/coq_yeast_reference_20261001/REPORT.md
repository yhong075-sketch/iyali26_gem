## 新增反应与规则

R39 从旧胞质无供电子体表示，替换为以下**线粒体、NADH 耦联候选**：

`nonaprenyl-4-hydroxybenzoate + O2 + NADH → hydroxylated product anion + NAD + H2O + H+`

`GPR = YALI1A08781g and YALI1B03314g and YALI1B19490g`

三项依次是 COQ6 家族羟化酶、YAH1 样铁氧还蛋白、ARH1 样铁氧还蛋白还原酶。AND 表示合并反应里的连续供电子依赖，不是三者构成稳定复合体的声明；没有增加可免费供给的铁氧还蛋白池、FAD 消耗或任意 ATP 系数。R39 ID 和边界保留，计量、区室、GPR、名称及说明改变；路径分组中的 R39 显示名同步更新。

酿酒酵母原始实验把 C5 缺陷定位到羟化酶及供电子链，2011 年作者提出 NAD(P)H 经该链到羟化酶的机制，并明确仍需纯化体系确认。较早还原酶实验接受 NADPH 和 NADH，但使用牛 adrenodoxin 等异源受体。因此 NADH 是有证据基础的**备选建模假说**，不能称为原生偏好或排他供体。[Ozeir 2011 原始稿](https://hal.science/hal-00630764/document)、[Lacour 1998](https://pubmed.ncbi.nlm.nih.gov/9727014/)

最初考虑的 NADPH 表示未应用：当前 m176 为 C21H30N7O17P3／电荷0，m178 实际为 C21H29N7O17P3／电荷0，其名称却写 H28。相差一个 H 而不变电荷，无法仅用 H+ 和 H2O 同时配平本步骤。本次保留这两种全局辅因子；NADH 选择依据独立酶学兼容性，而非声称配平即可证明生物学。现用 m30/m27 中性形式相差 H2，加一个产物 H+ 后元素与电荷严格守恒。

旧 R39 无供体方程已被替换。R969、R808 原有转运未改；其胞质端各自只剩这一个连接，稳态行约束分别强制转运通量为0，不再绕过新步骤。检查两区室目标底物/产物的直接转化只剩新 R39，未发现同计量正向或反向重复；这不是全模型所有多步替代路径的穷举证明。

此前 R695 的 COQ7–COQ9 条件性功能规则保持：`YALI1E18269g and YALI1F34675g`，分别为去甲氧基泛醌羟化酶与脂质呈递辅助蛋白家族候选。其作用与原生绝对依赖的限制见[此前报告](../coq_gpr_completion_20261001/REPORT.md)。

## 新序列与定位检查

两条完整 RefSeq 蛋白、原生 locus、缓存 UniProt 序列和实际 AlphaFold PDB 序列一致。对13个酿酒酵母参考蛋白的小面板，YAH1 样候选一致性72.727%、本物种序列覆盖81.988%；ARH1 样候选一致性36.646%、覆盖96.336%。两条酿酒酵母蛋白反查7,894条缓存本物种蛋白，首位分别为这两个候选。该搜索范围支持家族身份，不等于全物种正交关系或供电子专一性证明；两次 BLAST 实际执行，无新增搜索矩阵。[比对记录](donor_comparison.json)

本次实际 TargetP2 Non-Plant：两条供电子候选 mTP 分别0.998637和0.931576；切割30–31、34–35，切点概率分别0.4414、0.2619。完整输入161/464aa、逐位点输出1–161/1–200及成熟链均核对一致。此前羟化酶 XP_499891.1 的465aa预测mTP0.999294复用，未重跑。分类概率不是原生定位的实验确定性，也不提供线粒体内部更精细定位。[原始结果核验](targetp/verification.json)

两条供电子蛋白均复用**AlphaFold 预测**：AFDB文件版本6、AlphaFold Monomer v2.0 pipeline，未新做预测。平均pLDDT为81.844和92.158，平均PAE为13.353和5.655 Å；完整序列来源/版本/SHA、模型建立及获取日期均在比对记录中。它们是**基于 AlphaFold 预测的功能候选**；单体预测不证明相互作用、底物选择或原生定位。

## 验证结果与科学边界

两次 offline/no-solve 完整构建均完成。首次导出暴露历史注释箭头的 XML 转义问题，导致重新应用候选时报冲突；v1与失败证据保留。v2仅用普通文字替代箭头并解释历史注释，科学规则不变。检查脚本首次还遇到变量显示串中0/0.0差异；修正为按变量名和数值比较，未放宽模型守恒要求。

最终核验：

- 相对此前独立 COQ9 候选，完整 XML 只有 R39 内容及其分组显示名变化；其余物种、基因、反应、边界、目标和分组成员 ID 一致。
- R39 原子及电荷严格配平；六类输入冲突都在修改前拒绝；重复应用与保存重读保持一致。固定前候选只应用这一项即可得到完整管线输出相同的加载定义。
- 11条候选逐一做静态敲除传导检查：只新增这三个基因各自关闭 R39 的行为；两供体原来关闭 R383 的行为保留。未计算生长。
- 15项相关既有软件测试通过；本轮零模型优化、screen/dFBA、HPCC或新 AlphaFold 作业。
- 逐物种供给/消耗/转运列表见 [局部供给检查](local_supply.json)。它证明连接的静态范围，不证明所有供给在固定培养下可行。
- Q9 与 Q9H2 的总量守恒仍只有 R385 净生成；普通稳态迫使其净生成通量为0。模型缺少净CoQ稀释/周转需求的问题保持，因此本候选不能单凭 GPR 推导生长必需性。

独立v2实施审核10/10项支持，另外核对七类冲突均无部分修改；此覆盖只涉及身份、实现及数学声明，不包含原生生物学认证。详见[主核验](verification.json)、[独立实现与身份核验](implementation_audit/AUDIT.md)。输入采用当前目录模型的完整默认构建链，未冒充E5暂定参考；实际输入、培养、无菌株覆盖状态、完整代码与数据身份保存在 v2.build.json。未改变正式科学基线、培养、实验标签或其他工作线。

## 剩余判断

COQ8 候选 YALI1B20527g 的 ATPase/合成复合体作用有跨物种支持，但酿酒酵母过表达实验影响多个蛋白和中间体，不能独立确定某个化学步骤。保留途径辅助注释，不用任意单反应或全途径 AND 来凑覆盖。[Xie 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3390632/)、[He 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC3959571/)

R19 仍涉及 C1 羟化/氧化及 quinol–quinone 表示问题；COQ4/COQ6 分步与耦合机制的跨体系证据不能自动合并。原生辅因子偏好、上述供体配对与定位实验仍限制声明，但不是拒绝所有同源候选的理由。后续若检验表型，应先明确 CoQ 需求定义及固定输入/培养/预算，不能以命中率倒推 GPR。

本次原始来源独立审核10/10项，6项支持（含条件性推断）、2项反证、2项未解决；支持不是原生实验证实。2010早期C1功能假说按2011更具体实验校正；重复引用同一中间体实验不算独立重复。[来源审计](source_audit/AUDIT.md)

构建时显式使用 `--coq-c5-gpr --coq9-functional-gpr --offline --no-solve --coq9-curation metadata` 和新输出路径。关闭选项则保留既有默认行为。最终候选供审阅与后续有限验证，尚未作为正式模型接受。
