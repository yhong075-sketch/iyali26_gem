# CoQ末端反应：补入直接Q9底物证据

2026-10-02，依据用户提供的Houser & Olson 1977及既有来源作有限核验。本补充更正此前将R385支持主要概括为酵母短链类似物实验的证据说明；旧报告保留为历史记录。模型、整理数据、GPR、默认开关均未修改，未运行优化或新序列/结构任务。

## R385：还原态Q9前体有直接酶学支持

Houser & Olson研究的是大鼠肝线粒体中的去甲基Q9末端甲基化。原始论文摘要明确说明：NADH用于生成氢醌，后者才是直接甲基化底物。因此“没有Q9前体酶学、只能由酵母Q3类似物外推”不再是准确概括。本轮打开的是论文摘要；出版社全文获取失败，未声称重新核查全部实验方法或原图。[Houser & Olson 1977，PMID863914，JBC252:4017–4021](https://pubmed.ncbi.nlm.nih.gov/863914/)

结合IUBMB EC2.1.1.64，可记录反应：

**DMeQ9H2 + SAM → Q9H2 + SAH**

该净式不额外加入NADH；NADH参与把氧化型前体还原为直接底物，与SAM依赖甲基转移本身分开。具体质子项依模型微物种约定。IUBMB还把历史名称“5-demethylubiquinone-9 methyltransferase”列为本条目的别名，并引用该1977论文；这是旧酶名与现分类的对应，不表示醌和醌醇是同一化学物。[EC2.1.1.64](https://iubmb.qmul.ac.uk/enzyme/EC2/1/1/64.html)

Poon1999提供另外一类证据：YOL096C — COQ3 — CoQ环O甲基转移酶（酿酒酵母线粒体缺失/回补实验验证）与末端甲基化的功能关系。该实验使用短链Q3类似物，检测前人为氧化产物；这些限定保留。早期O甲基化属于EC2.1.1.114，不能和末端EC2.1.1.64混用。已存原文的p21670也引用1977论文为其参考65，本轮重新核对了相关讨论。[Poon1999原文](https://www.biochemistry.ucla.edu/Faculty/CClarke/pdf/21665.pdf)

适用状态应写为：**还原态末端O甲基化有原始Q9酶学及标准反应定义支持；迁移至Yarrowia的Q9通路属于跨物种支持，非本物种直接实测。** 本模型YALI1B20835g — 原生正式符号未核实、COQ3家族CoQ环O甲基转移酶候选（既有同源/整理注释及AlphaFold预测支持，原生酶活未验证）的证据等级不因大鼠实验自动升级。

## R695：必须成对选择底物氧化态与供电子方式

|当前分类|净反应的核心表示|证据边界|
|---|---|---|
|EC1.14.13.253|DMQ9 + NADH + O2 → DMeQ9 + NAD+ + H2O|以Q9书写的分类参照；定义是醌态底物/NADH，来源实验主要是人源及四足动物祖先蛋白和短链底物，非Yarrowia Q9实测。|
|EC1.14.99.60|DMQ9H2 + AH2 + O2 → DMeQ9H2 + A + H2O|当前条目说明为原核酶、供体未指定；不能把上一行NADH证据直接搬进这一醌醇净式。|

以上为官方分类方程的生化记号；当前模型采用的中性NAD/NADH分子式须单独核对，不能直接照抄NAD+电荷记号。[EC1.14.13.253](https://iubmb.qmul.ac.uk/enzyme/EC1/14/13/253.html)、[EC1.14.99.60](https://iubmb.qmul.ac.uk/enzyme/EC1/14/99/60.html)

Lu2013的底物结合介导NADH供电子及产物检测支持受测人源酶羟化，不能据此得到自由DMQ9H2的全套净计量。Nicoll2024的醌/醌醇对照以NADH消耗为终点；醌醇条件未见该信号，不排除所有NADH非依赖周转。其Fig5d–e另有从氧化态前体出发的耦联产物检测，得到氧化/还原型Q1；不等于逐个游离中间体氧化态均被独立实测。本轮重新读取此前存档的原文相关段落；网络PMC入口返回验证码页，不冒称本轮重新取得全文。[Lu2013](https://doi.org/10.1021/bi301674p)、[Nicoll2024](https://doi.org/10.1038/s41929-023-01087-z)

因此R695未决项须写成“**底物氧化态、供体和产物状态之间的匹配**”，不能只写“AH2尚未确定”。此前YeastCyc醌醇记录仍是来源比较对象，不能压过当前分类直接认定真核Q9净式。

## 新线索与仍未闭合的连接

Houser1977摘要另报告：Triton X-100溶解过程使去甲基Q9还原活性失活，连二亚硫酸盐可部分替代NADH。这提供大鼠体系中 **DMeQ9 → DMeQ9H2** 的还原活性线索；本轮可读摘要没有指定还原酶基因，也没有证明Yarrowia存在独立同功能酶，更不是DMQ9H2氧化证据。不能据此直接填入新GPR或确定原生净计量。

若把当前R695的醌态/NADH表示与还原态R385衔接，就需解释两处前体氧化还原连接：R18产物DMQ9H2到R695底物DMQ9，以及R695产物DMeQ9到R385底物DMeQ9H2。这是对当前表示的连接要求，不证明体内必然存在两个独立游离酶步骤。R385化学证据加强，也不等于整个通路已闭合。
