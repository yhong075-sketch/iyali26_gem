# R153 / R2176 GPR 定向审查

核验日期：2026-09-11。范围为当前已发布 `model_metadata_trna.xml`，以及现有 screen 的封存 SD-Leu／PO1f 运行条件；不是根目录旧模型或其他假设版的替代审查。

**结论：R153 的占位 GPR 身份未解；R2176 的单基因 GPR 存在明确的功能注释反证。两条又是同区室、同计量的重复反应，确实能互相绕过单敲。不能直接把 R2176 的基因复制给 R153，也没有依据把两条解释成已确认的同工酶。** 本轮未修改模型、GPR、培养、实验标签或评价口径。

## 2. 为什么 R2176 的 GPR 不宜接受

身份链可追溯到 NCBI `AOW04049.1` 与历史 UniProt `A0A1D8NEI7`，entry 28／sequence 1，384 aa。NCBI 序列、独立下载的历史 UniSave 序列、本地缓存、AlphaFold API 和 PDB 坐标序列逐残基一致。

- 历史 UniProt 直接描述为 **Peptidase A1 domain-containing protein**，结构域 61–366，预测信号肽 1–17；两处预测催化位点为 Asp79、Asp262。注释来自 PROSITE、SignalP、PIRSR 等自动推断。唯一列举的文献是基因组组装，不能作为催化功能实验。[历史 UniSave v28](https://rest.uniprot.org/unisave/A0A1D8NEI7?format=txt&versions=28)、[PROSITE 家族定义](https://prosite.expasy.org/PS51767)
- 原始 S2 对照表 `sheet1` 第 4465 行把两个系统 ID 配对，并给出相似于酿酒酵母 GPI 锚定天冬氨酸蛋白酶的注释。它是同源推定，不能转写成目标原生正式名称、已确认定位或酶活。
- 对应 CLIB122 条目 `Q6C947` 当前 entry 113／sequence 1 仍为未审阅条目，自动标注 Pepsin A、EC 3.4.23.1；与目标 384 aa 完全一致。这是跨来源／版本一致性证据，不是两项独立酶学实验。[UniProt 记录](https://rest.uniprot.org/uniprotkb/Q6C947.json)

ATP 依赖的瓜氨酸—天冬氨酸连接与蛋白质肽键水解是不同的化学功能。上述证据对 R2176 现有赋值构成强反证；预测信号肽还提示需要另行核实其与胞质反应的定位匹配。**审查判断是“高度疑似误赋，不应将其视为已确认 GPR”；不是已经实验排除了该蛋白所有可能的副活性。** 未找到本目标催化 EC 6.3.4.5 的直接实验依据，真实连接酶身份仍未解决。

当前 `A0A1D8NEI7` 为 inactive/deleted，理由是“不属于参考蛋白组”；这不等于蛋白不存在或历史序列被证伪。采用可追溯的历史版本，并保留当前状态。未把编号转换、同序列比较或 GO 自动注释视为原生功能验证。

## 3. AlphaFold 辅助证据

本次复用 **既有 AlphaFold 预测** `AF-A0A1D8NEI7-F1`，未向 HPCC 提交新作业。API 报告工具为 AlphaFold Monomer v2.0 pipeline、创建日期 2022-06-01，下载文件版本 v6；本次获取日期 2026-09-11。

目标全长与预测序列完全相同。384 个 Cα 的平均 pLDDT 为 **85.387**；其中 65 个低于 70，最低 30.92。61–366 注释域平均 pLDDT **91.613**；两个预测催化 Asp 的 pLDDT 为 95.00／95.38。全长平均 PAE 7.943 Å，最大 31 Å，注释域内平均 4.184 Å；信号肽区平均 pLDDT 36.205。

这些数字说明该预测中注释域比 N 端更有结构置信度，**不能证明酶种、底物特异性、活性、GPI 锚定或胞内定位**。本轮未做新 BLAST、结构比对或酶学实验，不能声称由折叠匹配确认了蛋白酶身份；若纳入此结构作功能假设，仍标记为“**基于 AlphaFold 预测的功能候选**”，并明确主要家族依据来自序列注释。YALIUNK2 缺少可追溯序列，不能针对它进行身份特异的结构预测。

## 4. 敲除逃逸已用静态通量见证核实

沿现有运行读取链重建模型，完整核对 2315 条反应计量、边界与 GPR，均与旧快照一致。实际调用 COBRA 单基因敲除仅检查内存边界，**新增优化求解为 0**。

| 情形 | 新关闭反应 | R153 通量 | R2176 通量 | 已存或构造见证的生长目标 |
|---|---|---:|---:|---:|
| 旧 WT 全通量 | 无 | 0 | 0.20917915810634488 | 1.8718823069403 |
| YALI1D17462g 单敲的代数见证 | 仅 R2176 | 0.20917915810634488 | 0 | 1.8718823069403 |
| YALIUNK2 单敲的代数见证 | 仅 R153 | 0 | 0.20917915810634488 | 1.8718823069403 |

若两列计量均为 \(s\)，则其守恒贡献为 \(s(v_{153}+v_{2176})\)。关闭 R2176 后令 \(v'_{153}=v_{153}+v_{2176}\)、\(v'_{2176}=0\)，守恒贡献不变；本例新通量也在 R153 边界内。全部 1877 个物种行的最大残差为 **8.06×10⁻¹⁵**，边界违反为 **0**。故当前约束确实允许该重复反应完全承接目标单敲后的这部分通量；不是求解器漏关了 GPR 为假的反应。

这里证明可行通量存在。若接受历史 WT 的 optimal 记录，则 KO 可行域缩小与这一等生长见证合起来给出同最优值；本次没有重求解或新对偶证书。旧全基因 screen 也记录两条目 KO/WT 均约 1，但属于历史结果。两条目在本评价表均 **unlabelled**，不能称为 FN、TN 或新修复的实验错例。

还需保留两个数学边界：

1. 单看“有无允许该化学步骤”，两条不同 GPR 形成替代关系；但重复列的 WT 合计容量是 `[-2000,2000]`，不能把它与容量 `[-1000,1000]` 的单条 OR 反应宣称全局等价。本见证的 0.209179 远低于单条上限。
2. 精氨代琥珀酸在本模型只有一个胞质池，其完整行只有 R153、R2176 和下游裂解 R152，要求 \(v_{153}+v_{2176}-v_{152}=0\)。双关会强制 R152=0；R152 反向消耗精氨酸，不能凭反向开放就称其能净补充精氨酸。**本次没有双关闭生长求解或全体精氨酸来源阻断证明，不能据此宣布双关必死。** ATP、AMP、PPi、瓜氨酸和天冬氨酸的完整相关物种行已保留用于核验替代；替代不改变任何辅因子净需求或运输。

两条当前均允许逆向，但上述见证仅用正向，逃逸结论不依赖逆向开放。生理方向需另查酶学、热力学及 PPi 耦联条件，不能把 IUBMB 的等号当作本条件双向通量范围的实验证明。

本仓库最早能核实含此对反应的导入为 2026-03-19，已存在这两个不同 GPR 和重复计量。原始 `data/iyli21.xml`／`data/iyali26.xml` 的两个反应均含额外产物 H⁺，为七物种；当前发布模型为六物种。**同一版本内重复一致，不等于跨版本完整计量不变。** 本次没有查明占位 ID 的原始创建动机或 R2176 误赋的作者决策，不能把当前注释补全操作当成其产生原因。
