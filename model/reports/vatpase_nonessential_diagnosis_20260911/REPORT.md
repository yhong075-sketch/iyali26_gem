# 为什么共同 AND 后仍不影响生长

**当前模型允许完全不使用 Golgi／液泡质子反应，也达到最大生长。** 因此三个共同基因敲除虽然关闭R794/R795，却没有切断当前生物量目标所需的通量。这个结论来自本次保存的实际可行解，不是从“泵不重要”推测。

输入为上一轮三共同AND假设模型，SD-Leu／PO1f配置及生长目标保持。仅在一次性内存模型执行3次诊断LP，没有改写任何模型或整理数据。

| 诊断条件 | 生长率 h⁻¹ | R794通量 | R795通量 | Golgi／液泡全部H⁺关联反应通量 |
|---|---:|---:|---:|---|
| WT | 1.8718823069403 | 0 | 0 | 全部为0 |
| 同时关闭R794/R795 | 1.8718823069402994 | 0 | 0 | 全部为0 |
| 再额外关闭R1159 | 1.8718823069402994 | 0 | 0 | 全部为0 |

所有返回均optimal，全部反应的边界违反量为0，全模型最大质量守恒残差不超过6.54×10⁻¹⁴；按实际浮点值计算生长差仅约4.44×10⁻¹⁶。这里只展示找到的最优见证解，不宣称所有最优解的胞器质子通量必定为0。

## 具体原因

**R795在WT就已关闭。** 其原有上下界为[0,0]，此次GPR改动保持该边界，所以单敲不会进一步减少其可用通量。

**R794也可以完全不用。** 本次WT见证解中它已经为0。新GPR能将敲除时的R794界限锁定到0，但这个WT解仍满足锁定后的约束，因此仍能达到同样的最优生长。

数学上，敲除只缩小可行域，所以最优生长不能升高；同时，原WT最优解已满足被删反应通量为0，它也是敲除后的可行解，所以最优生长不能降低。两点合起来就是本次KO/WT≈1。

**模型未强制要求维持胞器酸化才能生长。** 当前目标为biomass_C；无显式pH或膜电势变量/约束，生物量不直接消耗Golgi／液泡H⁺。更强的实际证据是：两个区室所有H⁺关联通量同时为0仍可最大生长，说明现有下游计量和边界也没有在这个条件下形成必须由这两条泵满足的需求。H⁺稳态物料守恒不等价于维持酸性pH或跨膜梯度。

例如Golgi H⁺行实际为：

```text
v_R141 + 2*v_R794 + v_R1159 - 2*v_R2048 + v_R_NDP7g = 0
```

这些通量全部为0就满足该守恒式，它自身没有正的酸化需求下限。胞器pH、梯度以及它们与运输/加工/生长之间的生理关系需要另有证据的约束，不能由增加GPR中的AND自动产生。

## R1159的作用和解释边界

R1159在模型中写成不消耗ATP、无GPR的可逆 `H⁺[cy] ⇌ H⁺[go]`，界限[-1000,1000]。它在数学上允许独立于R794的Golgi质子运输，是后续需要审查的表示。但本次三个见证解中它均为0，额外关闭它也不改变生长；**本次结果不能单独归因于R1159旁路**。

同样，已有封闭ATP生成问题没有在本轮作因果隔离，不能把它自动认作这次非必需预测的原因。没有新增基因身份或原生功能结论，也不能从模型预测推导实验非必需。
