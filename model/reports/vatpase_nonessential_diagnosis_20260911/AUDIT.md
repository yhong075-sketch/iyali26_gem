## 局部模型方程

原文件 R794 的界限 [0,1000]，正方向为：

`ATP[cy] + H2O[cy] + 2 H+[cy] → ADP[cy] + Pi[cy] + 2 H+[go]`。

R795 同式将产物 H+ 放到液泡，原界限已经为 [0,0]。因此关闭 R795 本身不改变原可行域；新的共同 AND 让指定基因单敲关闭 R794，此后仍有上述可行解。

Golgi H+ 的完整质量平衡行仅含：

`v_R141 + 2 v_R794 + v_R1159 − 2 v_R2048 + v_R_NDP7g = 0`。

R1159 是无 GPR 的 `H+[cy] ⇌ H+[go]`，界限 [-1000,1000]，结构上允许不耦联 ATP 的正向质子供给。**但这里实际通量为零，并且在同时关闭 R1159 与两泵后生长仍不变，所以不能把“该旁路实际替代了泵”作为本次原因。** 其他 Golgi 产/耗 H+ 项也全为零；零通量即可满足此守恒行。

液泡 H+ 共 22 条关联反应，原 R795 和扩散 R1163 均 [0,0]。其余包括可逆无 GPR 的二肽/氨基酸相关转运和多数原本关闭的转运；本次全部为零，未发现需要解释成实际替代泵的非零收支。`proton_reactions.json` 的两个物种对应反应集合、计量系数和边界已全部独立与 XML 对照一致。

SBML `biomass_C` 只含胞质物种，不直接消费 Golgi/液泡 H+。原 SBML 无 rules、constraints、events 或 initialAssignments，也未定义 pH/膜电势状态变量；其物种质子计量守恒不是 pH 阈值约束。已读 screen 的 effective simulation context 与 PO1f overlay，只叠加培养边界、R612 关闭及 R45 质粒 GPR，不添加胞器 pH、膜电势或正酸化通量下限。**“没有正需求”同时由结构检查和零胞器 H+ 通量的最优见证支持；不是只凭一般 GEM 常识推断。**
