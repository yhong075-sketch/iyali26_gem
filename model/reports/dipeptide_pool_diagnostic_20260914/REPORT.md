# 四种二肽 pool 的液泡网络测试

2026-09-14。本次实际完成 12 个定向 LP，全部 optimal。**人工胞质二肽供给使液泡网络部分恢复：Ala-Gly、Gly-Pro 两条水解链和 R795／R1363 恢复正通量；Gly-Asp、Gly-Glu 两条仍因产物没有去路而阻塞。** 这证明限定模型中的连通性变化，尚不构成真实液泡网络已修复或原生合成路线已确认。

## 测试设置

沿用此前 V-ATPase 三共同 AND 假设模型和同一 SD-Leu／PO1f 运行时配置，输入和加载源码完整 SHA 与上一轮匹配。没有以另一路线较新的 R1025/R1026 模型替换本轮比较对象，也未声称重建全部历史 dirty 环境。

在临时内存模型中，为胞质 Gly-Asp、Gly-Glu、Ala-Gly、Gly-Pro 各添加一个独立人工来源，范围均为 **0–1 模型通量单位**。这表示可持续提供底物的诊断边界，不是有限初始浓度，也不是有酶学依据的内部生产反应；四种二肽不相互转换，不指定 GPR。保留原有胞质到液泡转运，避免直接向液泡供给而跳过该环节。

无 pool 和有 pool 均将 R795（液泡 V-ATPase）及 R1363（胞质水进入液泡）临时开放为 [0,1000]。原二肽 Exchange 摄入仍关闭；其余原反应计量、方向、GPR 和边界保持，仅在明确的对照中关闭 R795 或改变目标／生长下限。未写回模型 XML、默认培养基或正式构建流程。

## 实测结果

| 检查对象 | 无 pool | 加 pool | 判断 |
|---|---:|---:|---|
| R795 最大通量 | 0 | **1** | 泵通量恢复可行 |
| R1363 水入口 | 0（由旧计量证明及本次基线见证） | 最大 **2** | 与两条水解同时恢复 |
| Gly-Asp 水解 R2021 | 0 | 单独最大化仍 **0** | 产物 Asp 没有去路 |
| Gly-Glu 水解 R2029 | 0 | 单独最大化仍 **0** | 产物 Glu 没有去路 |
| Ala-Gly 水解 R2034 | 0 | 单独最大值 **1** | 恢复 |

各单独最大值来自不同目标的优化，不能通常假定它们能同时达到。不过本次 **pool WT 的同一完整可行解**中，R795=1、R1363=2、R2034=R2039=1，确实同时达到；只有 Ala-Gly 和 Gly-Pro 两项人工供给各使用 1。其余两项人工供给和四条 Exchange 在该见证中均为 0。

上限 1、2 随本轮假设容量而定，不是预测的真实细胞最大速率。生长升高包含额外营养供给的作用，不能当作对原 SD-Leu 生长的预测改进。

## 泵为什么可以运行

依照实际计量，pool WT 见证中的路径为：

| 步骤 | 反应通量 | 实际方向／液泡 H⁺ 贡献 |
|---|---:|---|
| Ala-Gly 进入液泡 | R2033 = +1 | 胞质→液泡；该反应虽名 antiport，实际无 H⁺ 项 |
| Gly-Pro 进入液泡 | R2038 = +1 | 二肽与 H⁺ 同向进入；液泡 H⁺ +1 |
| 两条二肽水解 | R2034 = +1；R2039 = +1 | 生成 2 Gly、1 Ala、1 Pro；消耗 2 份液泡水 |
| Gly 返回胞质 | R2030 = **−2** | 反向运行；液泡 H⁺ −2 |
| Ala 返回胞质 | R2035 = **−1** | 反向运行；无 H⁺ 项 |
| Pro 返回胞质 | R2040 = **−1** | 反向运行；液泡 H⁺ −1 |
| 质子泵补偿 | R795 = +1 | 液泡 H⁺ +2 |

所以液泡 H⁺ 净值为 **2 + 1 − 2 − 1 = 0**。泵利用 ATP 供能，补偿这条计量路径净向外运输的质子；两条水解本身无 H⁺ 项。

更一般地，令 a、p 分别为 Ala-Gly、Gly-Pro 的非负水解通量。在其余当前边界保留时，完整物种平衡给出：

```
2 × v_R795 = a + p
v_R1363 = a + p
0 ≤ a ≤ 1，0 ≤ p ≤ 1
```

因此 R795≤1、R1363≤2；本次实际可行解达到这两个上界。这条路径有净二肽消耗、氨基酸产出及 ATP 消耗，不是净零循环。它使用了既有可逆边界允许的氨基酸反向运输；本轮没有验证这些运输方向、耦联比例和生理条件是否符合真实 W29 生物学。

## 两条未恢复的链

液泡 Asp 的全部关联只有 R2021 生成和 R871 消耗：`v_R2021 − v_R871 = 0`。但 **R871=[0,0]**，所以 R2021 必须为 0。

液泡 Glu 同理：`v_R2029 − v_R876 = 0`，而 **R876=[0,0]**，所以 R2029 必须为 0。

这是供给打开后仍存在的**产物出口断点**。继续增加 Gly-Asp/Gly-Glu 的来源上限无法单独解除它们；本轮没有开放这两条出口，也未推断原作者关闭动机。

## 是否成为生长必需

在 pool 条件下关闭 **R795 反应**：

- 最大生长率回到 **1.87188230694 h⁻¹**，是 pool WT 的 **86.1725%**。
- 四条水解通量之和的可行最大值为 **0**，因此剩余生长无需利用这些人工二肽供给。
- 为维持 pool WT 生长减 1e-8 h⁻¹，R795 的最小通量为 **0.99999995838**。这是另一项定向最小化的结果，比仅观察一次 WT 正通量更能说明其对新增最高生长的必要性。

因此，R795 已与这部分额外二肽利用和新增最高生长建立计量依赖，但**不是维持生长所必需**。本轮是反应关闭对照，未执行任何基因 KO，不能据此更新目标基因分类或全模型 essentiality 数量。

关闭泵并以最大化水解为目标时，有一个返回解的 biomass=0；该解并非最大化生长，不能视为死亡。生长能力应以上述独立生长目标结果判断。
