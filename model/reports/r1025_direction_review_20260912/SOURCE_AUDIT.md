# 核内补偿反应方向：独立来源审计

核验日期：2026-09-12（America/Los_Angeles；来源获取记录使用 UTC）。范围为 R1025、R1361、R1050、R1028、R1161 的方向依据及主审提交的五条声明。独立打开来源、读取有关原文段落，并重新解析固定 SBML 的局部计量、边界、区室和电荷；没有运行 LP、热力学求解、BLAST 或结构预测，没有修改模型、管线或科学输入。

结论：现有证据不足以把这五步判成“方向错误”，也不足以证明既有 KO 解的核内补偿在真实细胞中达到所需速率。保留可逆性、明确实际热力学与容量未决，比依据 KO 结果单向封堵更符合当前证据。这里的“保留”是审查建议，不是对所有边界和定位的生物学验收。

## 方向与热力学声明的独立核对

固定模型为 `model_metadata_trna_r1026_gpr_build2.xml`，本次重算 SHA256：`b16e13050d378f2bb097a43f649908e85374f6c626ee34e430338e8f170cf222`。五步均无 GPR，边界均为 [−1000, 1000]。本次核查的是已保存模型和既有 KO 解，未重新求解。

| 反应 | 既有 KO 通量方向 | 审计后的方向判断 |
|---|---|---|
| R1025 | 核内 CO₂ + H₂O → HCO₃⁻ + H⁺ | 水合方向本身不违背碳酸酐酶可逆化学；核内催化/自发容量未证。 |
| R1361 | 水：胞质 → 核内 | 被动交换合理；实际驱动力取决于水的化学势，不能由反应名决定。 |
| R1050 | CO₂：胞质 → 核内（相对模型正向为负） | 该方向不存在由名称或“扩散”推出的禁令；仍需合适化学势差。 |
| R1028 | HCO₃⁻：核内 → 胞质（负） | 不能以 CO₂ 脂溶性作为机制；离子的该方向需满足自身电化学势条件。 |
| R1161 | H⁺：核内 → 胞质（负） | 不能从核孔存在推出 pH 相等，亦不能从其他物种 pH 梯度规定本条件方向。 |

独立计量重算得到：

`S(R1025) + S(R1361) − S(R1050) − S(R1028) − S(R1161) = S(R1026)`。

对任一离子从核内 n 到胞质 c 的一步被动转移，采用相同标准态时可写：

`ΔG(n→c) = RT ln(a_c/a_n) + zF(ψ_c−ψ_n)`。

H⁺ 的 z=+1、HCO₃⁻ 的 z=−1；各转移一摩尔时电势项在和中抵消。将水/CO₂ 输入、核内水合及产物输出的完整化学势差相加，核内物种项也消去，只留下胞质净水合反应。以上是状态函数与计量给出的条件恒等式，不是每步 ΔG<0 的证明。若分别表示为未耦联的被动通道，每条有净通量的方向仍须与自己的驱动力一致；亦不能从整条净反应有利推导任意大流量。

本轮没有本培养条件的区室活度、pH、电势、核内有效催化量或未催化速率，故未代入“典型数值”给出实际 ΔG。此前赋予胞质 R1026 的基因 YALI1F28274g（正式名称未核实；β-碳酸酐酶功能候选，依据同源/注释而非原生定位和酶学验证），不能仅凭本条核内补偿通量再自动赋给 R1025。
