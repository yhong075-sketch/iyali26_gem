# 核内补偿路径：反应方向是否科学

核验日期：2026-09-12（America/Los_Angeles）。固定上轮实际执行的 R1026 GPR 构建与已保存 KO 通量，本轮只进行模型读取、来源审查与热力学推导，新增优化求解0。

**现有证据不支持因为出现逆向通量，就把这些反应改成单向。CO₂水合的化学可逆性有明确依据；核质被动交换支持允许双向的建模解释。但本条件下每一步的实际下坡方向、核内催化及通量容量尚未确认，因此不能把这条 FBA 补偿当作已验证的生物学路径。**

## 逐步核对

五条反应的 GPR 均空、边界均为 [-1000,1000]。以下实际方向来自上轮已求得的最优解，不是本轮新求解。

| 反应 | 模型记录的正向 | 上轮KO实际方向 | 方向判断与限制 |
|---|---|---|---|
| R1025，碳酸氢盐形成 | 核内 CO₂ + H₂O → HCO₃⁻ + H⁺ | 同正向 | 化学可逆有依据，水合方向本身没有矛盾；核内催化身份或自发反应容量未确认 |
| R1361，水扩散 | 水：胞质 → 核内 | 同正向 | 允许两向交换合理；净水流由水的化学势/渗透条件决定，没有证据固定只入核 |
| R1050，CO₂转运 | CO₂：核内 → 胞质 | 逆向，胞质 → 核内 | 被动交换不固定“向外”；有适当化学势差即可向内，目标梯度未测 |
| R1028，HCO₃⁻转运 | HCO₃⁻：胞质 → 核内 | 逆向，核内 → 胞质 | 可用核孔交换解释双向许可，但不能用CO₂脂双层渗透替代机制证据；原生通量与速率未测 |
| R1161，H⁺扩散 | H⁺：胞质 → 核内 | 逆向，核内 → 胞质 | 需要核质pH、电位及缓冲条件支持；允许双向不等于可任意逆电化学梯度输送质子 |

**R1025 的可逆性：** IUBMB EC4.2.1.1 在正式命名条目中明确描述可逆 CO₂ 水合。将碳酸解离合并后即模型中的 CO₂ + H₂O ⇌ HCO₃⁻ + H⁺。因此不能仅依据反应名称中“forming”或主通量正负决定不可逆边界；该条目支持反应化学，不确认 Yarrowia 核内酶。[IUBMB，EC4.2.1.1](https://iubmb.qmul.ac.uk/enzyme/EC4/2/1/1.html)

**核孔与脂双层要区分：** Ma 等在 digitonin 通透化 HeLa 细胞中直接观察核孔被动通行，其小探针范围0.3–29 kDa，并展示输入/输出事件。Timney 等在活酿酒酵母中测量27–67 kDa蛋白的被动核质平衡。这些支持核孔存在双向被动通路，但均未测本模型目标 HCO₃⁻/H⁺ 的转运容量。Gutknecht 等在人工脂双层实验中观察CO₂穿膜，而HCO₃⁻不按相同机制穿膜；它不能用来否定核孔介导的交换，也不能替代原生核孔的测量。[Ma et al., 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3358865/)，[Timney et al., 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5057280/)，[Gutknecht et al., 1977](https://pmc.ncbi.nlm.nih.gov/articles/PMC2215341/)

**不能强设核质pH相同：** Seksek与Bolard的原始研究摘要报告，所测哺乳动物细胞在RPMI中核pH比胞质高0.3–0.5，在PBS中没有该梯度。这里只把它作为“核孔存在不保证所有条件下pH完全相等”的反例；不能把哺乳动物数据填作PO1f的pH或据此指定R1161方向。该项本轮读取原始摘要/元数据，未获取订阅全文。[Seksek & Bolard, 1996](https://doi.org/10.1242/jcs.109.1.257)

## 热力学上能判断到哪一步

以核内水合的明确化学物种为例，在固定温度、明确标准态时：

\[
\Delta_rG_{1025}=\Delta_rG^\circ+RT\ln\frac{a_{\mathrm{HCO_3^-},n}a_{\mathrm{H^+},n}}{a_{\mathrm{CO_2},n}a_{\mathrm{H_2O},n}}.
\]

正向净反应需要负的自由能变化，反向则相反；在平衡时为0。不能只看pH，也不能把显式H⁺的化学标准自由能与已经固定pH的生化变换标准自由能混用，否则会重复计入质子效应。酶改变反应速率，不改变同一化学反应的平衡；有自发水合不代表其速率足够承担生长需求。STRENDA建议明确区分K/K′、标准态与平衡条件。[Goldberg et al., 2023，§2](https://doi.org/10.3762/bjoc.19.26)

对于被动转运，本项目采用以下物理条件判断，而没有给未知量填入默认值：

\[
\Delta G_{i,c\to n}=RT\ln(a_{i,n}/a_{i,c})+z_iF(\psi_n-\psi_c),
\]

其中两边标准化学势相同的部分已抵消；若标准态/压力等不同，需保留对应差项。H⁺/HCO₃⁻的方向要看电化学势，水和CO₂看相应化学势。这里的公式不是目标条件下ΔG的测量或计算结果。

沿用前轮逐物种核实的列恒等式：

`S_R1025 + S_R1361 − S_R1050 − S_R1161 − S_R1028 = S_R1026`

五步相加后，核内物种抵消，总效果仍为胞质 CO₂ + H₂O → HCO₃⁻ + H⁺。同样将各步电化学势相加，核内项抵消；等摩尔H⁺与HCO₃⁻向外转运的电势项相互抵消。因此，把反应绕到核内不会凭空改变同一净反应的总自由能。**这项数学恒等式不证明每个步骤都下坡，不证明路径唯一，也不证明任何既定通量可达。** 两种离子分别通行即可产生总和抵消，不需要假设模型未记录的共同转运体。

## 本轮建议

1. **暂不改成单向。** 没有发现足以把当前三个逆向步骤判为方向错误的原生条件证据。若今后在预先确定的浓度/pH/电位范围内某方向始终上坡，才有依据提出对应边界修改；区间跨过平衡时应保留方向未决或可逆。
2. **优先核对R1025的角色和容量。** 若为酶促反应，需要核内酶与定位证据；若为自发反应，需要按条件、区室体积和单位换算建立速率上限。当前±1000是宽松的有限边界，不是核内酶量或自发速率测量，不能把它称为已验证的供给能力。
3. **R1028/R1161保留机制与梯度缺口。** 需要适用的核孔/离子交换证据及本条件pH、电位/活度范围。仅添加一个方向约束而缺少这些依据，可能把未知供给误做成敲除必需性。

上轮约10.45253的补偿通量已通过计量/边界核验，但没有被浓度、pH、电位或动力学数据验证。本轮未改变模型、GPR、培养、标签、管线或求解参数，没有重跑KO。证据缺口限制“实际方向/容量已科学确认”的声明，不阻塞上述有限结论。
