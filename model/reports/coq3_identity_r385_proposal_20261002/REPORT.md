# COQ3 身份映射与 R385 局部化学修改提案

核验日期：2026-10-02。两项结果均已完成：**三个指定编号可对应到同一 W29 基因及相同蛋白序列；R385 采用醌醇→醌醇时，产物可复用既有 Q9H2，底物 DMeQ9H2 则需新增，并暴露未确定机制的还原连接。** 本次只核查记录与模型一致性、列出提案；没有修改模型、GPR、整理数据或默认开关，没有构建、FBA、新 BLAST、AlphaFold 或集群作业。

## 第一项：COQ3 身份映射

**YALI1B20835g — 原生正式符号未核实，COQ3 家族候选 — CoQ 生物合成 O-甲基转移酶。** 功能为同源及既有 AlphaFold 预测支持的候选，当前官方蛋白记录仍称 hypothetical／uncharacterized；本次验证的是身份对应，不是 W29 原生底物特异性或酶活。

因此，对本次明确指定的 **AOW01767.1 ↔ XP_500950.3**，分类是**“同一 W29 基因／蛋白的记录对应”**：它们是两个数据库记录，不是两个不同株系的蛋白，也不再是“无法建立关系”。这项判断由官方显式交叉引用、株系／locus／BioSample／坐标对应和全序列一致共同支持，不只是相似性推断。[AOW01767.1](https://www.ncbi.nlm.nih.gov/protein/AOW01767.1)、[XP_500950.3](https://www.ncbi.nlm.nih.gov/protein/XP_500950.3)、[Gene 2907025](https://www.ncbi.nlm.nih.gov/gene/2907025)

**对既有证据的影响：**先前绑定 AOW01767.1 的保存序列、同源分析及同序列 AlphaFold 预测，现在可以明确对应到 XP_500950.3 的同一记录序列；功能仍是候选。上一轮“XP_500950.3 尚缺身份桥接”的未决项由本轮新取得的官方记录解决，旧报告保留为历史核查状态。当前模型的该 RefSeq 交叉引用无需因此前未决而自动替换。完整来源、全序列 SHA 和 14 项身份检查见[身份记录](identity/identity.json)。

## 第二项：R385 局部化学修改提案

本次“当前模型”固定为此前讨论的 **CoQ 文献局部管线候选**，不是新选择的正式基线。独立解析其全部 **1,879 个代谢物和 2,314 条反应**；下面 ID 用模型短写，完整 SBML 标识见[原始计量提取](model_local_extract.json)。所有下列 CoQ 物种都在 **C_mi（模型线粒体区室）**。

### 当前实际反应

| 反应 | 本次读取的实际方程 | 边界 |
|---|---|---|
| **R695** | **DMQ9 (`m61`)＋NADH (`m30`)＋O2 (`m64`) → DMeQ9 (`m611`)＋NAD (`m27`)＋H2O (`m26`)** | [0,1000] |
| **R385** | **DMeQ9 (`m611`)＋SAM (`m60`) → Q9 (`m468`)＋SAH (`m62`)** | [0,1000] |

R695 实际产物与 R385 实际底物是同一个 **醌态 m611**，不是 DMeQ9H2；R385 当前实际产物是 **醌态 m468**。此处 NAD／NADH 沿用模型中性微物种记账，不直接改成另一套离子式。

### 对应醌／醌醇是否存在，哪些反应连接

| 物种 | 当前模型身份／分子式 | 全部相关连接 |
|---|---|---|
| **DMeQ9：去甲基泛醌-9** | **m611[C_mi]，C53H80O4，charge 0** | R695 生成、R385 消耗；没有其他连接。 |
| **DMeQ9H2：去甲基泛醌醇-9** | **未发现相符实例**；对应中性式应为 **C53H82O4**。 | 无已编码生成、消耗或转运。不能复用 m611，否则会同时改写 R695 的产物身份。 |
| **Q9：泛醌-9** | **m468[C_mi]，C54H82O4，charge 0** | R385 当前直接生成；另与下面全部成熟 CoQ 红氧反应连接。 |
| **Q9H2：泛醌醇-9** | **m471[C_mi]，C54H84O4，charge 0** | **已存在，可作为 R385 提案产物复用**；全部连接列于下表。 |

|---|---|
| **R262、R570、R1889、R1977、R2062** | 正向均为 **Q9→Q9H2**，边界均 [0,1000]；各自保留不同共底物／供电子反应。 |

“连接存在／方向由边界允许”只是静态模型事实，不证明该方向在整个网络中能承载非零通量，也不重新认证这些反应的生物学正确性。没有找到以上物种在其他区室的实例。模型另有 **DMQ9H2（C53H82O3）**和 **DDMQ9H2（C52H80O3）**，二者的化学身份及分子式均不同于 DMeQ9H2，不能凭缩写近似互换。

### 仅需列出的局部改变

[IUBMB EC 2.1.1.64](https://iubmb.qmul.ac.uk/enzyme/EC2/1/1/64.html) 将反应定义为去甲基泛醌醇到泛醌醇的 SAM 依赖 O-甲基化。若采用该定义，提案为：

**DMeQ9H2＋SAM → Q9H2＋SAH**

| 项目 | 局部修改提案；本轮未实施 |
|---|---|
| 底物物种 | 新增 **DMeQ9H2，C53H82O4，charge 0，C_mi**，作为内部代谢物；保留旧 m611 的醌身份。新增 ID 在实际获准实施时确定。 |
| R385 底物 | 将 **−1 m611[C_mi]** 换为 **−1 新 DMeQ9H2[C_mi]**。 |
| R385 产物 | 将 **＋1 m468[C_mi]** 换为 **＋1 已有 m471[C_mi]**。不新建重复 Q9H2 池。 |
| 辅因子、GPR、边界 | SAM／SAH 各 1 保持；R385 的 **YALI1B20835g（COQ3 家族 O-甲基转移酶候选）**及 [0,1000] 不因这项化学定义连带改变。纯甲基转移净式不额外加入 NADH。 |
| 名称与注释 | 名称改为 **3-demethylubiquinol-9 3-O-methyltransferase**；保留 EC 2.1.1.64，并让解释性注释明确醌醇→醌醇。原反应数据库交叉引用须按新底物／产物身份重新核对，不能仅凭 EC 相同照搬。 |

按本模型的中性微物种约定，提案两侧分别为 **C53H82O4＋C15H22N6O5S** 和 **C54H84O4＋C14H20N6O5S**，元素与电荷均守恒。当前醌式 R385 也守恒；因此“配平通过”不能裁决酶的实际底物氧化态，修订理由来自反应定义及既有酶学证据。

### 暴露的还原连接，不自动补反应

R695 仍生成 **DMeQ9**，提案 R385 则消耗 **DMeQ9H2**，所以两者之间显露出：

**DMeQ9 → DMeQ9H2：还原当量、实际催化或耦联过程、可对应的 W29 基因均未确定。**

当前模型没有这个连接；前轮大鼠前体还原活性线索也不能指定 W29 的供体或 GPR。不能为了接通而自动添加 NADH 还原反应、把 R695 产物改成醌醇，或认定必须存在一条独立游离还原酶反应。

若只实施上述局部替换、其他结构不变，新 DMeQ9H2 只有 R385 消耗，旧 m611 只由 R695 生成。在内部物种稳态假设下，二者的守恒式分别是 **−v_R385＝0**、**v_R695＝0**。这是条件性的计量结构结论，未运行 FBA，也不是 W29 生物学失活证据。R18 产物 DMQ9H2 到 R695 底物 DMQ9 之间还存在此前已记录的上游红氧缺口，不由本项提案解决。

**产物端则已有连接：m471 的 Q9H2 可通过 R305 正向、或在 R740 原有共底物约束下反向转为 Q9。** 因此这项提案不需要另造一个成熟 Q9H2 氧化步骤；真正需要保留未决的是上述去甲基前体的还原衔接。

本提案是依据 R385 反应定义进行的模型一致性检查，**不是已验证的 W29 机制，也不是通路闭合方案**。本次来源审查及化学独立核查分别见[source_audit/AUDIT.md](source_audit/AUDIT.md)与[chemistry/AUDIT.md](chemistry/AUDIT.md)；范围、完整输入指纹和未改动检查见 SCOPE.json、MANIFEST.json。
