# R293 / R2080 功能预测：独立参考来源与位点审计

审计日期：2026-09-11。审计者：独立子代理 `source_audit`。范围为六成员参考面板、三篇结构/酶学全文、三个酵母/人酶学原始摘要及既有局部比对输出；没有重跑 BLAST、US-align、Kabsch 或模型求解，没有修改模型/GPR。原始来源先独立读取，随后核对主代理给出的结果文件；来源判断形成后，对最终功能报告作收口核对。下面的审计计数仅覆盖末表明确列出的声明，不代表全领域覆盖率。

两个目标的身份沿用前轮已核版本：**YALI1E20159g**（W29 AOW05525.1；历史 UniProt A0A1H6PYK1；566 aa，尚无核实的专属标准酶名）与 **YALI1B12742g**（W29 AOW01464.1；历史 A0A1D8N739；463 aa；旧名 YALI0B09515g 在文献中称 EKI1，但该称谓不是酶学验证）。二者当前的催化解释均为序列和 **AlphaFold 预测**辅助的功能候选。

S6 的 **CHKA L419（其短型编号 L401）与 CHKB F352** 突变改变 HC-3 磷酸化/抑制行为；这些突变体仍有胆碱活性。它们不是经实验验证的“胆碱↔乙醇胺开关”。本轮没有获得乙醇胺特异激酶的实验配体结构作为对应的阴性/阳性结构对照，不能以全局 TM-score 判定底物。

一个重要未决线索是 See Too 2006 学位论文的 **ETNK1 L312Q 与 CHKA Q308L**。公开 PDF 只有 49 页，正文止于第 24 页；目录列出第 160、161、231 页的相关实验及讨论，但结果页面不在所获文件中。因此未将其列为已经核实的特异性开关。当前 Q9HBU6 的第 312 位确为 L；目录使用 Δ89N-hEK1，452−89=363 aa 可解释构建长度，仍不足以替代缺失的构建和结果资料。PDF 文本可提取，所试页面渲染有字体缺失，未宣称已完成该论文结果页的视觉核验。

独立检查范围：直接从 6 个链文件读取 CA 记录，对八项比对的 **2,774 对残基**核对氨基酸身份、对齐数及 query/参考实际坐标覆盖率分母；全部一致。另对两个目标相对于 2CKQ 的 **19 个所选位点对**，用标准库重新应用保存的旋转/平移矩阵并计算距离，均与输出的 0.001 Å 舍入精度相符，目标 pLDDT 也与坐标文件相符。记录见 `sources/reference_audit/local_spotcheck.json`。这属于输出一致性核验；没有独立重算所有 Kabsch RMSD 或所有距离，也没有重跑寻优。

最后对 `functional_evidence.json` 的 **34 条位点记录**逐条检查：结构对应与已核查的实际坐标对一致；序列对应由本审计直接遍历已保存 HSP 字符串重新导出，与输出一致，包括 E Y534 缺序列对应及 B C364 仅有序列对应。最终 `REPORT.md` 的八行结构数字、底物候选分级、原始论文接触位点描述及未决边界与本次审计一致；未发现需要改变功能结论的矛盾。报告身份及检查时刻记录于上述抽核文件。未将主代理的全距离/Kabsch 复算写成由本独立审计全部复现。

八项结构比较中，实验参考仅包含两个胆碱激酶家族结构；Q9HBU6_AF 和 Q03764_AF 的蛋白功能有实验依据，坐标则为 AlphaFold 预测。E 的全链 query-normalized TM-score 对 Sc EKI1 预测结构最高，因此“全部结构排序独立支持 E 是 CKI1”不是准确表述。实验结构中的催化口袋对应与序列最邻近支系提供互补信息。不同参考长度、晶体缺失片段、目标插入段及低 pLDDT 部分使全链分数不能当成已校准的功能概率。
