# Task reports

One folder per task, named `<topic>_<yyyymmdd>`: TASK.md (scope and authorization), REPORT.md
(results and limits), audits and small tables or figures.

Large outputs for the same task (flux dumps, run folders, candidate XMLs, structure
predictions) are kept outside git, in a folder with the same name under
`$IYALI26_RESEARCH_ROOT/artifacts/tasks/`. Never-committed candidate models are in
`$IYALI26_RESEARCH_ROOT/artifacts/candidates/`. Both were copied there on 2026-10-07; see
`$IYALI26_RESEARCH_ROOT/archive/iyali26_gem_untracked_20261007/RELOCATION_MANIFEST.tsv` for
SHA-256 values and original paths.
