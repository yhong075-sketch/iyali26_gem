# 三个 amidase 候选的蛋白功能预测

用户在 R2251/R2087 GPR 审查后要求“预测蛋白功能”，本次范围为此前三个已固定 W29 目标 YALI1E14619g/A0A1D8NI23、YALI1E41276g/A0A1D8NL97、YALI1F21875g/A0A1D8NNQ1，原始版本、序列SHA及AlphaFold模型沿用上一轮已审证据，逐项重新核对。目标是区分家族功能、最可能底物及替代假说，不预设模型底物正确。

顺序：固定输入；对人工审阅/有实验的参考酶先作序列BLASTp，再比较全链结构和催化/底物位点；对照本物种乙酰胺遗传证据、定位线索及同家族其他底物；独立审计来源与实际输出，给出分层功能候选和可证伪条件。正式名、具体底物和定位未证实处保留未知。

范围/预算：最多一次3序列批量NCBI Swiss-Prot BLAST提交，每目标最多100命中，显式等候不超过10分钟；固定最多20条人工审阅或实验参考用于本地BLAST比较；最多18个单体结构比较（3目标×最多6参考），单线程，本地序列/结构总执行预算300秒。参考获取及文献读取约30分钟。若全库请求超时，则仅报告有限参考面板，保留RID与原始状态，不称全库最优。不得因弱命中提高E值或无界扩参考。

只使用本轮工作目录写分析/报告，保存源文件、工具版本、参数、完整SHA和原始日志；复用现存BLASTP与US-align，不安装依赖。已有AlphaFold结构覆盖全部目标，不重复提交HPCC预测；若本轮材料不足，报告剩余候选与局限。原模型/GPR/化学/培养/标签及同事文件不变，不运行代谢求解，不进行模型构建、提交/推送或外部人员通信。

证据门槛：家族/折叠及催化残基保守可以支持酰胺水解功能候选，不能单独确认底物。底物判别须与已知实验参考、口袋差异及物种证据一致；发现同折叠异功能或高分对照时保留竞争解释。结构结果明确标为“AlphaFold预测”与“基于AlphaFold预测的功能候选”。候选不自动接受为GPR。科研治理技能要求独立来源审计；本次使用一名只读审计代理。
