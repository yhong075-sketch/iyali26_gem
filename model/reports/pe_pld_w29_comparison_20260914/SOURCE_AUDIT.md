# 历史酵母 PE-PLD 的分子身份：独立来源审计

核验日期：2026-09-14；审计者：`source_audit`。问题限定为 Tang 2002 所研究的 Ca²⁺依赖、偏好磷脂酰乙醇胺（PE）的磷脂酶 D 活性，是否已有可追溯的基因和蛋白序列，足以直接查找 W29 同源物。

**本轮没有找到把这项历史 PE-PLD 活性明确连接到已鉴定基因/蛋白序列的后续原始证据。** 可以追溯的是一种生化活性：文献暂称 `ScPLD2`、`PtdEtn-PLD` 或 Ca²⁺依赖 PE-PLD。不能把这个临时活性名称当作已克隆的基因，也不能用同名哺乳动物 PLD2 记录代替。该结论是有界检索的结果，不是断言所有未索引文献中都不存在后续鉴定。

有明确序列的 **酿酒酵母 YKR031C — SPO14/PLD1 — P36126，1683 aa** 是已知磷脂酶 D 比较对照，主要相关反应为 PC 水解为磷脂酸和胆碱；历史 PE 偏好活性在其缺失背景下仍被检测到。因此将它与 W29 注释 PLD 比较是一个独立的问题，不能称为已经找到了历史 PE-PLD 的 W29 同源物。

## 原始研究链

| 来源 | 实际证据与定位 | 分子身份判断 |
|---|---|---|
| [Mayr 等，1996，PMID 8814297](https://pubmed.ncbi.nlm.nih.gov/8814297/)，DOI 10.1016/0014-5793(96)00893-9 | 原始摘要：从酿酒酵母膜组分溶出并部分纯化 Ca²⁺依赖活性，偏好 PE/PS；与 SPO14/PLD1 活性在 Ca²⁺、PIP₂及转磷脂酰化行为上不同 | 是部分纯化的活性，未在所读摘要中给出对应新基因或蛋白序列。约 60 kDa 是该实验的表观分子量，不能据此指定一个 ORF |
| [Waksman 等，1997，PMID 8995222](https://pubmed.ncbi.nlm.nih.gov/8995222/)，DOI 10.1074/jbc.272.1.36 | 原始摘要：在 PLD1 缺失细胞中仍发现第二种活性，临时称 PLD2；偏好 PE、依赖 Ca²⁺、不受 PIP₂激活、不进行短链醇受体的转磷脂酰化 | “PLD2”在此是酶活名称，不等于提供了第二个已鉴定 PLD 基因 |
| [Tang 等，2002，PMID 12153579](https://febs.onlinelibrary.wiley.com/doi/10.1046/j.1432-1033.2002.03073.x)，DOI 10.1046/j.1432-1033.2002.03073.x | 原始摘要及出版社索引的 Introduction/Discussion：作者明确表示寻找该基因的尝试没有成功；随后是胞质/膜相关活性及调节研究 | 2002 年该研究没有完成基因鉴定；作者对非 HKD 家族的解释是推断，不是获得新序列后的结构域确认 |

Tang 的 Discussion 还记述了三个位点 **YLR019W、YLL010C、YOR086C** 的删除筛选：它们是当时按 C2 域挑选的未知蛋白候选（该处未给标准名称，也未验证 PE-PLD 功能），相应提取物的 PE-PLD 活性与野生型相近。这支持“这些单基因删除没有消除所测活性”，不能把它们列作已找到的 PE-PLD，更不应把这项有限条件的负面筛选写成全条件的绝对遗传排除。

Tang 的关键原始段落由出版社的搜索索引直接返回，已实际读取；直接页面打开失败、HTML 下载返回 HTTP 403。本审计**未取得该全文的本地档案，也未声称读过所有表图或补充材料**。原始摘要已由 NCBI 保存。数据库/检索摘要中的索引词 `Phospholipase D/genetics` 不构成基因鉴定证据。

## 排除另一个可能的同名/同族混淆：Fmp30

本轮后续检索命中有序列的 **酿酒酵母 YPL103C — FMP30 — Q02883，468 aa**。其当前 UniProt 条目（entry 158，2026-09-02；sequence version 1）仍标作线粒体 NAPE-PLD；但名称不能直接证明它就是历史 PE-PLD。**N-acyl-PE（NAPE）和普通 PE 是不同底物，N-acylethanolamine（NAE）与游离 ethanolamine 也是不同产物。**

- [2005 原始摘要，PMID 15878693](https://pubmed.ncbi.nlm.nih.gov/15878693/)：YPL103C 缺失与细胞 NAE 降低有关，结合其与人 NAPE-PLD 的同源性提供功能线索。摘要没有把它识别为 Tang 的 Ca²⁺依赖 PE-PLD，也没有报告以普通 PE 产生游离乙醇胺的对应蛋白实验。
- [Baker、Guerra 等，2026 原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13392021/)，DOI 10.1038/s41467-026-73766-x；2026-05-30 发表：Results “Fmp30p is a PI hydrolase…” 与 Figure 2b–f 支持重组 Fmp30 的 PI 水解；在所测 NAPE、PC、PE、CL、PI 中，普通 PE 未显示相应 PA 生成，PI 有活性。这不能被简写为“新发现的 PE-PLD”。

这里有重要条件限制：2026 Methods “Fmp30”/“Enzyme assay and lipid extraction” 使用 **His₈-MBP-Fmp30 ΔN76**，18:1 脂质底物，pH 8.5、0.1% DDM、1 mM MnCl₂及 1 mM CoCl₂；配方未列 Ca²⁺。因此该研究的 PE 阴性结果**不能单独排除**其他条件下的 PE 活性，亦不能独自证明 Fmp30 绝不可能与历史活性有关。可得的判断是：它的已验证 PI 水解功能和历史 Ca²⁺依赖 PE 活性尚未建立同一性，不能直接替代为“历史 PE-PLD 查询序列”。本轮不追查它在 W29 的候选同源物。

## 对本轮 W29 比较的边界

主代理已保存的官方参考条目中，P36126 明确对应 YKR031C/SPO14/PLD1。W29 候选条目为 **YALI1_E22633g — 标准名未由序列记录核实，文献旧位点称 SPO14 — AOW05630.1 / 历史 A0A1D8NJ18，1829 aa，注释 PLD 候选**；CLIB122 的 **YALI0_E18898g / Q6C5D8** 是另一菌株记录，不能默认字节相同。

主代理完成比较后，本独立审计直接解析已保存 FASTA、官方记录和全部 3 条原始 HSP：冻结 W29 文件含 7,894 序列；实际查询与 P36126 当前记录逐残基一致；命中序列与 W29 AOW05630.1 及历史 A0A1D8NJ18 逐残基一致。原始输出仅有 A0A1D8NJ18 一个目标、3 个 HSP。最佳 HSP 为 427/875 列相同（48.800%），Sc 309–1169 对 W29 288–1116；全部 HSP 区间并集覆盖 Sc 1,206/1,683（71.66%）、W29 1,123/1,829（61.40%）。这些身份、区间、并集和完整位点映射均由本审计重新遍历原始字符串核对，并非重新执行 BLAST。

六个选定 HKD 位点也一致：Sc H796/K798/D803 → W29 H738/K740/D745；Sc H1096/K1098/D1103 → W29 H1043/K1045/D1050。W29 与上述 CLIB122 条目只有第 1745 位 A/T 差异，故 CLIB122 坐标不能标为目标的完全同序列结构。仓库映射表 `data/yali1_yali0_map/iyli21_genes_vs_S2.csv` 第 679 行确实给出 YALI1E22633g↔YALI0E18898g。核验记录、输入 SHA 和范围见 `sources/independent_audit/comparison_check.json`。未独立复现搜索的候选寻优过程，也未验证新结构。

恰当的报告标签是“**已知 SPO14 型 PLD 与 W29 注释 PLD 的比较对照**”。即使观察到同源性或共有催化基序，结果也不能完成未知 PE-PLD 的鉴定、确认 W29 的 PE 底物偏好，或证明游离乙醇胺供给。没有可追溯的历史 PE-PLD 查询序列时，不应给它虚构 accession、以已知 PLD 替身运行同源搜索，或为该未知身份生成 AlphaFold 预测。
