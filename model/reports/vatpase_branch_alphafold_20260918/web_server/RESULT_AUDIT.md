## 解释的边界

- **ipTM/pTM 是预测置信度，不是功能相同概率。** A 与 B 的大小、组成和界面数不同，不能依据总分高低认定谁更能泵质子，更不能把分差写成两者功能不同的量化概率。
- 全局结构相似分数受覆盖与组分差异影响。B 的两条链局部可对应 A 的某些折叠，不代表覆盖 A 的完整组件功能；一个小片段的低 RMSD 不表示两组完整复合体相同。
- 单拷贝假设仍然存在：A 缺实验参考中的 c″且未按真实 A3/B3/E3/G3/c8 等多拷贝构架建模；B 为 a/c″候选，未含 ATP 水解头。结构预测不补出未输入的组件。
- A 中旧 F 亚基候选来自 CLIB122，W29 对应位点的伪基因冲突保持未决；一份良好预测不能确认其在 W29 表达完整蛋白。各蛋白原生正式名称/功能证据仍以 DESIGN_REVIEW 表为准。
- 网页 seed1、服务器默认模板设置及未知后端版本独立记录，不能标成 HPCC seed0/3.0.2/10 recycles 的完全复现。没有显式膜、ATP/离子或质子梯度，本次不模拟耦联 ATP 水解和质子运输，也不直接批准新的 GPR 或 essential 标签。
