# R1025 候选的 AlphaFold 结构结果

核验日期：2026-09-12（America/Los_Angeles）。

**结构结果支持 YALI1F28274g 是 Nce103-like β-碳酸酐酶功能候选，但不能据此确认它在核内催化 R1025。** 该基因原生正式名称未核实；预期蛋白功能为可逆 CO₂ 水合。证据等级为自动注释、同源关系和“基于 AlphaFold 预测的功能候选”，不是目标原生酶活或定位实验确认。

本轮复用了与目标 **222 aa 完整序列完全相同**的既有 **AlphaFold 预测**，新增实验结构比较和坐标核验；没有把复用写成新提交的 AlphaFold 作业。目标来自 A0A1H6PNW2 历史条目 v32、序列 v1；模型 AF-A0A1H6PNW2-F1 使用 AlphaFold Monomer v2.0 pipeline，文件版本 v6，创建于 2022-06-01，原获取日期为 2026-09-11 UTC。

实验正参考为 **YNL036W — NCE103 — 碳酸酐酶（实验功能支持）**，来自酿酒酵母；3EYX实际为删除前13残基并附标签的构建体，A链只有17–40及49–221共197残基有坐标。比较保留所有可用坐标，没有按得分裁剪目标或参考，也不称参考为完整天然221 aa结构。[原始结构研究](https://doi.org/10.1186/1472-6807-9-67)、[3EYX](https://www.rcsb.org/structure/3EYX)

三个直接锌配位残基在结构对齐中对应 **C57/H112/C115 → 目标 C53/H108/C111**，全部保守，目标位点 pLDDT均约98.5–98.8。另核对论文列出的七个口袋残基：六个相同、一个为参考V80→目标I76。十个位点合计九个相同，Cα位置差为0.37–0.85 Å；这些是主链坐标的重叠，不是金属配位键长或侧链活性验证。**D59→D55为口袋位点，不能称D59是3EYX的第四直接Zn配体**；该晶体的第四配体是水。[原始结构研究，锌结合与底物通道部分](https://pmc.ncbi.nlm.nih.gov/articles/PMC2775743/)

**本轮判断：加强 β-碳酸酐酶功能候选的结构依据，R1025 的核内 GPR 仍待验证。** 需要核内存在与靶标催化归因的证据才能提高区室赋值等级；没有已核实的近缘异功能对照，不能用两结构面板排除所有其他功能。没有修改R1025或其他GPR、方向、培养和标签，没有重跑敲除。独立审计覆盖11/11条来源及输出声明，10条在注明范围内支持，1条原生核内/装配/容量声明未核实；未核实的生物性质没有被计算检查通过所替代。
