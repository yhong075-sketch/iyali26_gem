# R1025 候选的 AlphaFold 结构核验

用户要求对“待验证的核内酶促候选”使用 AlphaFold 预测。本轮以 YALI1F28274g（原生正式名未核实；Nce103-like β-碳酸酐酶功能候选）历史 A0A1H6PNW2 v32/序列v1、222 aa 为固定输入，复用已经核实完全同序列的 AF-A0A1H6PNW2-F1（Monomer v2.0 pipeline，文件v6）；不把既有结果写成新提交预测。

顺序：核实序列与模型身份及 pLDDT/PAE；复用前轮已完成的实验参考 BLAST 和候选筛查；获取实验结构3EYX及不同折叠的α-CA结构2CBA；比较完整可用链A，核对3EYX构建体、缺失坐标及关键位点映射；独立来源/输出审计；交付结构图与条件化功能结论。2CBA只作为不同家族折叠对照，同样催化CO₂水合，不是失活或非CA阴性对照。没有已核实的近缘异功能旁系同源对照，不以这两个结构宣称排除所有替代功能。

预算：两次US-align，固定整条可用单体链、每次60秒、单线程，总120秒；不按得分裁剪或重试。来源限现有目标/BLAST/定位资料及两项PDB关联实验来源；不扩展蛋白组检索。绘图与已保存输出的数值核验为本轮结构分析的一部分。输入不符、结构身份/编号无法确定、执行失败即停止受影响步骤并保留记录，不换目标或调参。

最弱环节是将结构功能推断转移到原生核内区室。高结构置信度或与酶结构相似不能确认核内定位、足够通量、反应方向、底物活性或复合体。参考3EYX为同源二聚体，单体AF不验证本目标二聚体形成。核内GPR保持候选，模型/GPR/培养/标签不改，不运行LP/敲除或新增HPCC作业。若以后确需新结构作业，遵循既有HPCC授权另立明确输入与资源计划；本轮优先使用已有同序列预测。
