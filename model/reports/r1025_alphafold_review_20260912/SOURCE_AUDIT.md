核验日期：2026-09-12（America/Los_Angeles）。本阶段只读原始论文、公开结构记录和已保存 PDB 的链/编号；没有执行 BLAST、US-align、预测、HPCC 或代谢求解，没有修改模型/GPR。后续数值输出审计将另行追加，不以原始论文中的结构比对冒充本次目标的比对结果。

目标为 **YALI1F28274g / YALI1_F28274g**（正式基因名尚未核实；Nce103-like β-碳酸酐酶功能候选；A0A1H6PNW2 历史 v32，对应 Q6C0V4）。实验参照为酿酒酵母 **YNL036W / NCE103 / P53615**，名称和碳酸酐酶功能有实验依据。复用的目标模型仍须标作**既有 AlphaFold 单体预测**，结构相似性属于功能候选证据，不是原生核内酶学验证。

## 原始来源及定位

- **独立结构记录核对：** [3EYX](https://www.rcsb.org/structure/3EYX) 对应上述实验。重新读取主审保存的 `sources/3EYX.pdb` 中 COMPND、DBREF、SEQADV、REMARK 350 及 Cα 记录；PDB SHA256 为 `fa47ef5cd916b5f4ce45eea02a237349553dcc03c048521bee7626c9080ce8de`。

## 后续结果允许支持到哪一层

若目标全链对 3EYX:A 的匹配明显优于另一 CA 家族，可支持“预测结构更符合 Nce103-like β-CA 折叠”。判断仍须同时列出两种长度归一化的得分、实际比对残基数、RMSD、缺失坐标和局部位点匹配范围，不能仅摘录最高分。不同家族对照不能排除同折叠异功能蛋白或未检索的候选。

参考晶体含底物类似物乙酸，而不是动态 CO₂ 水合过程的直接观察；原文的底物通道还使用 CAVER 计算并作机制推测。把参考 Zn 或乙酸位置映射到目标图上只能称“参考位置”，不能称目标已结合金属/底物。特别是没有配体的单体预测，不证明真实金属配位几何、催化状态或活性口袋完整性。全局 pLDDT/PAE 也不能替代这些验收。
