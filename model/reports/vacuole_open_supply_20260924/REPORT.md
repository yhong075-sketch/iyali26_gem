# E5 液泡连接候选开放与有限二肽供给复测

四连接候选已实现，并完成能量回归、有限供给、联合可行性及 FVA。结果支持**在当前模型中，这四个连接能够支持人工输入二肽的水解和氨基酸回收**；不等同于原生内源供给、酶/GPR或区室已经确认。

## 1. 候选实际改变了什么

[独立候选 E5_vacuole_open.xml](E5_vacuole_open.xml) 已生成并重新加载验证。原 E5 的实际 SHA 与用户固定输入完全一致，规模为2314反应、1877代谢物。候选数学定义仅四条边界改变：

| 反应 | E5 边界 | 候选边界（mmol/gDW/h） |
|---|---|---|
| R1363，供水 | [0,0] | [0,0.04] |
| R795，ATP耦联质子泵 | [0,0] | [0,0.04] |
| R871，Asp回收 | [0,0] | [0,0.01] |
| R876，Glu回收 | [0,0] | [0,0.01] |

下界全部为0，不强制运行。计量、分子式、电荷、全部GPR、区室、目标和八条E5能量修订及其保护记录均保持；独立XML审核也验证了这一范围。候选没有二肽源、drain、测试耗散列或强制水解/FVA约束。默认开关关闭，原E5及正式默认模型未覆盖。容量是诊断参数，不是实测生理上限。

R795实际保留：
`m141[C_cy] + m32[C_cy] + 2 m10[C_cy] → m143[C_cy] + m35[C_cy] + 2 m1007[C_va]`，即ATP、水及胞质H⁺消耗，产生ADP、Pi和液泡H⁺。未简化成无ATP消耗的质子运输。

证据：[四边界差异](baseline_vs_candidate_diff.tsv)、[构建清单](E5_vacuole_open.build.json)、[独立审核](AUDIT.md)。

## 2. 无来源的能量回归

先经实际PO1f/SD-Leu/CRISPR质粒选择加载器，再审计封闭183条单侧物料边界和6条biomass列；仅在封闭副本释放xMAINTENANCE下界，保留全部真实稳态约束。没有二肽、水、H⁺、ATP来源或产物drain。

| 情景 | ATP最大耗散 | GTP | UTP | CTP | 精确零通量 |
|---|---:|---:|---:|---:|---|
| C0 原E5，四连接关闭 | 0 | 0 | 0 | 0 | 可行 |
| C1 四连接有限开放 | 0 | 0 | 0 | 0 | 可行 |
| C2 四连接均[0,1000]压力测试 | 0 | 0 | 0 | 0 | 可行 |

12个最大化和3个零通量控制均实际执行，状态全部optimal，判读容差1e−7。C2只存在于诊断内存副本；这些结果只支持本轮四种能量检查，不是全模型无循环或热力学正确的证明。未继承聊天侧HiGHS结果为通过证据。

证据：[逐项能量结果](run/closed_energy_results.tsv)、[实际加载差异、闭合清单与运行参数](run/manifest.json)。

## 3. 无供给、单独供给、联合供给和连接关闭

正常培养、biomass_C最大化和NGAM下界7.8625保持。四种来源均是直接进入液泡的人工物料输入，边界[0,epsilon]；没有新增出口或回收捷径。下表epsilon=0.01，四连接容量在所有对照中固定。

| 情景 | 条件 | 生长（h⁻¹） | 四水解各自可达的最大值：Asp / Glu / Ala / Pro |
|---|---|---:|---|
| G0 | 原E5，无来源 | 1.429177892 | 0 / 0 / 0 / 0 |
| G1 | 开放连接，无来源 | 1.429177892 | 0 / 0 / 0 / 0 |
| G2 | 原E5＋四来源，连接关闭 | 1.429177892 | 0 / 0 / 0 / 0 |
| G3 | 开放连接＋四来源 | 1.434139670 | 0.01 / 0.01 / 0.01 / 0.01 |
| G4 | 仅Gly-Asp | 1.430193461 | 0.01 / 0 / 0 / 0 |
| G5 | 仅Gly-Glu | 1.430512639 | 0 / 0.01 / 0 / 0 |
| G6 | 仅Ala-Gly | 1.430176051 | 0 / 0 / 0.01 / 0 |
| G7 | 仅Gly-Pro | 1.430791195 | 0 / 0 / 0 / 0.01 |
| G8 | G3关闭供水R1363 | 1.429177892 | 0 / 0 / 0 / 0 |
| G9 | G3关闭泵R795 | 1.429177892 | 0 / 0 / 0 / 0 |
| G10 | G3关闭Asp出口R871 | 1.433124101 | 0 / 0.01 / 0.01 / 0.01 |
| G11 | G3关闭Glu出口R876 | 1.432804923 | 0.01 / 0 / 0.01 / 0.01 |

无来源时，开放连接未改变生长，保存的最优/pFBA解四连接均为零；另行最大化各水解也都是零。因此这里的阻塞结论来自实际最大化，不只是某个pFBA解未选中路径。仅添加四来源但连接仍关闭的G2也不能水解。

单独供给可支持对应的一条水解。关水或关泵会阻断全部四条；关Asp出口只阻断Gly-Asp，关Glu出口只阻断Gly-Glu。这些是连接隔离试验，不是基因KO。各情景均独立做了生长最大化、pFBA及四个水解最大化，逐解生长和完整通量保留。

pFBA的次级总通量不是生长。例如G3次级目标为964.7180631106196，实际biomass_C仍为1.434139669972012 h⁻¹。表中四个单独最大值也没有被当成同一通量解。

证据：[情景汇总](scenario_summary.tsv)、[逐目标结果与实际摄取](run/growth_and_hydrolysis.tsv)、[单调性检查](run/monotonicity.tsv)、[额外G3≥G2检查](additional_monotonicity.tsv)。全部相关可行域放宽对照均未出现生长下降。

## 4. 同一个解能否同时水解四种二肽

可以。分别在无额外生长要求、99% G3最优生长、G3最优值减1e−6三种条件下，实际将四水解下界同时置0.01，三次均optimal且达到约1.434139669972 h⁻¹。半量回退未被触发，没有把未运行的半量情景写成通过。强制下界已撤除，不写入候选XML。

近严格最优的同一完整见证中：

| 反应／量 | 通量（mmol/gDW/h） |
|---|---:|
| R2021、R2029、R2034、R2039，各自 | 0.01 |
| R1363，液泡供水 | 0.04 |
| R795，ATP消耗 | 0.035 |
| R795，H⁺转入液泡 | 0.07 |
| R871，Asp回收 | 0.01 |
| R876，Glu回收 | 0.01 |
| R2030，Gly回收 | −0.04 |
| R2035，Ala回收 | −0.01 |
| R2040，Pro回收 | −0.01 |

回收负号由存储方程决定；R2035只转运Ala，不含H⁺。四水解共生成Gly0.04，Asp/Glu/Ala/Pro各0.01。液泡水行：0.04供给＝4×0.01消耗；H⁺行：2×0.035＝Gly回收0.04＋Pro回收0.01＋Asp回收0.01＋Glu回收0.01。R795同时从胞质消耗0.035 ATP和0.035水，这是该反应实际计量乘以通量所得；完整水账覆盖液泡水，ATP账覆盖胞质ATP，并未另行汇总胞质水的全部反应。

以上是完整S矩阵和保存通量核算的结果，没有预先固定泵0.035或供水0.04。G3最优、pFBA及联合见证中，四人工源各0.01均被水解，相关完整二肽外排为零；其他情景的源和水解分别记录，未假定它们恒等。2H⁺/ATP仅是模型计量，不代表测得pH、膜电位或原生耦联比。

证据：[联合可行性](run/joint_feasibility.tsv)、[完整同一通量见证](run/G3_joint_near_strict_full.json)、[全水/质子/ATP/氨基酸账本](run/proton_water_atp_ledger.tsv)、[逐池总账](run/ledger_totals.tsv)、[带符号相关反应通量](run/related_fluxes.tsv)、[二肽去向](run/dipeptide_fates.tsv)。

## 5. 最优生长是否需要这些反应

预先设定delta=1e−6 h⁻¹（既定1e−7可行性容差的10倍），未事后调节。FVA分别在99%最优值和绝对近最优阈值下执行五个反应各自min/max，共20次。

| 反应 | 99%最优时范围 | 近严格最优时范围 |
|---|---|---|
| R2021 | [0.00000000, 0.01000000] | [0.00999015, 0.01000000] |
| R2029 | [0.00000000, 0.01000000] | [0.00999251, 0.01000000] |
| R2034 | [0.00000000, 0.01000000] | [0.00998998, 0.01000000] |
| R2039 | [0.00000000, 0.01000000] | [0.00999380, 0.01000000] |
| R795 | [0.00000000, 0.03500000] | [0.03499015, 0.03500000] |

99%阈值为1.419798273272，低于原E5的1.429177892279，所以无需新增回收路径也已满足该宽松要求。下界为零不能证明这些路径在严格最优时不需要。

绝对近最优阈值为1.434138669972；此时四水解及R795下界均显著大于1e−7。结果支持：在本模型、供给上限和该生长要求下，五条反应都必须承担正通量。这个判断来自各自FVA最小值，不是来自一个pFBA解。原E5仍能以正速率生长，因此不能由此宣称细胞存活必需或原生基因必需。

证据：[逐项FVA](run/targeted_fva.tsv)、[范围汇总](fva_summary.tsv)。

## 6. 生长、输入物料与低供给敏感性

G3比原E5提高0.004961777693 h⁻¹（0.347177%）。葡萄糖摄取仍10；氧摄取约14.825076927→14.879664444，铵摄取约8.701216076→8.653372295 mmol/gDW/h；NGAM仍7.8625。培养文件及边界未改，差异来自允许额外人工物料进入并回收，不是验证了酵母内源生产这些二肽。

在固定连接容量下，epsilon=1e−4和1e−3的G3生长分别为1.429227510056和1.429674070048 h⁻¹；对应pFBA四水解各达到该供给量，泵分别0.00035和0.0035，供水分别0.0004和0.004。未对这两个小供给档额外开展独立水解最大化或FVA；本轮代表性完整矩阵是epsilon=0.01。

G3额外输入按名称推定为0.25 mmol C原子/gDW/h、0.08 mmol N原子/gDW/h。四二肽及液泡Gly在模型中缺少分子式，因此这只是名义C/N账，不能当成完整化学验证；未补写任何公式/电荷。完整边界变化和原始符号保留，正负含义以各交换方程为准。

证据：[边界通量比较](boundary_comparison.tsv)、[逐来源名义C/N](run/source_carbon_nitrogen.tsv)、[底物ID与缺失字段](run/dipeptide_identities.json)。

## 7. 验收、数值和声明边界

实际执行114次优化：15个能量/零控制、12个主生长、3个联合可行性、60个主情景pFBA/水解最大化、20个FVA、4个敏感性生长/pFBA。全部optimal、后处理完整；累计优化调用时间2.017067秒，诊断运行总墙钟220.118秒，两者不混同。预算为200次、累计1800秒、单次60秒、单线程；余86次未使用。没有将失败、不可行或未运行结果填成零。

3项构建无求解测试及6项保存行为/实际临时回滚测试均通过，共9项。行为测试审核的是本轮实际优化结果，并不额外重复求解。全部可行解均检查Sv、边界及实际自定义约束；最大记录违反6.83e-11，小于1e−7。默认关闭、重复应用、冲突原子性、XML重载、加载后八能量锁、人工源/自定义约束正常及异常退出恢复均已检查。

Gurobi模型复制在封闭副本的R1372少量系数产生约3.6e−11的序列化舍入；该反应在封闭测试中固定为零。实际求解矩阵和存储计量均被独立审核并保留差异，未把二者写成逐字节相同，也未放宽容差。

独立审核覆盖原始XML和完整求解向量、实际矩阵与账本；最优性仍依赖记录的Gurobi状态，没有另外运行第二求解器或给出独立对偶证明。有限主张覆盖见[AUDIT.md](AUDIT.md)，详细数值复核见[auditor_results.json](auditor_results.json)。原生酶/GPR、二肽内源产生、真实定位和生理容量仍未解决；本轮没有做基因KO、蛋白功能升级或正式模型接纳，也没有commit/push。
