# R608：推荐有界的 C 表示候选

**推荐 C7：六个核心物种采用阳离子表示，额外只修正一个脱羧 SAM 物种，并同步调整七条反应的质子项。** 本次静态推导覆盖15条直接反应、29个参与物种，13条内部反应全部元素及电荷守恒，2条交换反应按开放边界解释。这是可进入独立科学审阅的完整字段提案，尚未应用模型；现有工程接口需小幅扩展白名单。

选择 C 的依据是项目已声明的 Rhea/ChEBI pH 7.3 表示方向及精确化学结构。中性 N 加同样的必要修正也能全部配平，所以配平数量不能决定选择。C7仅迁移所选物种；外围仍保留已有、化学上可表示的中性物种，通过明确的质子项衔接，**不声称全模型或各实际隔室已统一到 pH 7.3**。数据库表示也不是胞内实测 pH 或离子占比。（PA2-C001、PA2-C008）

YALI1B15015g — YlODC／odc — 鸟氨酸脱羧酶，催化鸟氨酸生成腐胺和 CO₂（experimentally verified：历史论文实验蛋白；已审身份桥支持登记序列对应，当前 PO1f/SD-Leu 条件功能未另验）。模型将其指派给 R608；本提案不改 GPR，也不把化学配平解释为必需性验证。

**物种选择与身份边界。** 表内0表示形式电荷，不表示该物种在生理条件下占优势。

|---|---|---|---|

三个鸟氨酸原注释均为通用结构，不能凭相同分子式升级成 L 构型。[Rhea 22965](https://www.rhea-db.org/rhea/22965)确实使用 L-ornithinium(+1)，而 [CHEBI:46911](https://www.ebi.ac.uk/chebi/CHEBI:46911) 明列其属于通用 ornithinium(+1)。本候选只修正质子化与电荷，保留立体化学信息缺口，不声称 D/L 可被酶互换。这是对旧 C 案“同时采用 L 精确身份”假设的收窄。若后续要求精确 L 节点，最小补证是当前三节点原始整理依据中的 L 定义及其全反应映射审定；不需要重做本次电荷算术。（PA2-C002）

候选的名称、ChEBI、InChI及InChIKey相互一致。原来的中性／阳离子／通用／同位素等混合引用不再作为精确身份一起写入；原引用及新旧关系保留供复核。MetaNetX 的 [MNXM741174](https://www.metanetx.org/chem_info/MNXM741174)指向通用中性鸟氨酸，[MNXM118](https://www.metanetx.org/chem_info/MNXM118)则同时列出多种相似外部映射，不能用宽泛对应替代精确微观物种。（PA2-C002）

**R728 的根因是脱羧 SAM 漏记永久正电荷；R2183 的根因是只迁移腐胺时重复计算了质子。**

R728当前重原子和H已配平，电荷残差却为+1。[CHEBI:15625](https://www.ebi.ac.uk/chebi/CHEBI:15625)给出 C14H23N6O3S／+1，其硫鎓中心带正电；当前同式／0不能作为该结构的中性表示。推荐进一步采用 Rhea 使用的 C14H24N6O3S／+2。它只参与 R118、R728、R729，因此新增审查仅需原13条以外的 R118、R729及它们带入的 SAM、精胺，不修改后两种物质。（PA2-C003、PA2-C005）

[Rhea 12722](https://www.rhea-db.org/rhea/12722)的计量为：脱羧SAM²⁺＋腐胺²⁺ → 甲硫腺苷⁰＋亚精胺³⁺＋H⁺。模型保留的亚精胺是 C7H19N3／0，对应[中性亚精胺](https://www.ebi.ac.uk/chebi/CHEBI:16610)；将亚精胺³⁺展开为中性亚精胺＋3H⁺后，R728产物必须是 **4H⁺**。因此+1→+4是保留外围表示后的酸碱记账转换，不是随意补质子。甲硫腺苷仍为 C11H15N5O3S／0。（PA2-C003、PA2-C006）

R2183当前实际为：胍丁胺²⁺＋水 → 中性腐胺＋尿素＋2H⁺。胍丁胺已是 C5H16N4／+2，与[CHEBI:58145](https://www.ebi.ac.uk/chebi/CHEBI:58145)一致，无需再改。将腐胺迁移为+2后，去掉产物2H⁺，即与[Rhea 13930](https://www.rhea-db.org/rhea/13930)的水解式一致。旧式本身配平；旧六物种 C 案失衡是未同步调整这两个质子。（PA2-C004）

**完整的质子项提案如下；非质子计量全部保留。** 系数以产物为正、反应物为负，0表示移除该项。

|---|---|---:|---|
| R118，SAM脱羧 | m10[C_cy] | −1 → −2 | 保留 SAM 的 H22／0，以2H⁺衔接脱羧SAM的H24／+2 |
| R151，精氨酸水解 | m10[C_cy] | 0 → −1 | 保留中性精氨酸，生成+1鸟氨酸 |
| R609，乙酰基转移 | m28[C_mi] | 0 → −1 | 保留线粒体原有谷氨酸／乙酰谷氨酸表示，生成+1鸟氨酸 |
| R610，转氨 | m10[C_cy] | 0 → +1 | 保留原有2-氧戊二酸及谷氨酸表示 |

R607的产物H⁺仍为+1，R608的反应物H⁺仍为−1。R118保留的 SAM H22／0是可定位的[硫鎓内盐形式](https://www.ebi.ac.uk/chebi/CHEBI:67040)，不能把“总电荷0”一律理解为漏记硫电荷；它和脱羧 SAM 的情形不同。上述衔接与[Rhea 15982](https://www.rhea-db.org/rhea/15982)、[19974](https://www.rhea-db.org/rhea/19974)、[20569](https://www.rhea-db.org/rhea/20569)、[15349](https://www.rhea-db.org/rhea/15349)、[25161](https://www.rhea-db.org/rhea/25161)的相应反应及质子化差异交叉核对。（PA2-C006）

**为什么这些调整不是“为配平而配平”。** 先由来源选择结构及分子式／电荷，再固定重原子计量。令Δ为产物减反应物；增添系数δ的H⁺只能使ΔH和ΔQ同时增加δ。仅当其他元素残差为0且ΔH＝ΔQ时，才允许唯一的δ＝−ΔH。原 R728 的ΔH＝0、ΔQ＝+1不满足条件，必须先修正物种身份。本候选所有七个质子变化都满足这一约束。（PA2-C006）

在固定这七个物种、保留外围表示的条件下，这是只增加一个可修改物种的扩展。选择“脱羧SAM H23／+1”也能得到另一套完整配平式；两种已修正 C7 的区别严格满足 `S_H(+2) = S_H(+1) − S_dcSAM`。在稳态约束、相同边界和目标、无附加pH/电荷约束的前提下，这是可逆行变换，不能用生长结果区分。选择+2依照既定Rhea表示约定。此性质不表示 C7 与原模型或 N 等价。（PA2-C008、PA2-C009）

同一静态检查也验证了旧 N/C 案的残差及两个修正后的反例方案，没有用“多配平几条”替代科学选择。（PA2-C007、PA2-C008）

| 运输反应，按现存正向式 | H⁺耦合及现存方向边界 | N → C 的胞质净电荷变化 |
|---|---|---:|
| R909，鸟氨酸线粒体→胞质 | 一个H⁺胞质→线粒体；仅正向 | −1 → 0 |
| R910，鸟氨酸胞外→胞质 | 一个H⁺同向进入胞质；可逆 | +1 → +2 |
| R917，腐胺胞外→胞质 | 一个H⁺反向输出胞质；可逆 | −1 → +1 |
| R918，腐胺胞质→液泡 | 一个H⁺液泡→胞质；边界[0,0] | +1 → −1，仅假想正向式，实际保持关闭 |

以上是保存计量和形式电荷的推导，各反应另一隔室变化相反，不能当作实测电流。C7第一层只统一化学表示，**不增删运输的H⁺或改变边界**；运输的电荷解释仍会随货物电荷变化，非运输H⁺计量也确实进入S矩阵，不能保证生长或能量行为不变。第二层若要修改运输耦合，须有对应转运系统的同向／反向及H⁺:底物比例证据，再单独提案和归因。第一层的局部守恒可独立成立；生理正确性与后续能量解释仍依赖第二层的机制核验。（PA2-C010）

限定检索未获得三条运输在当前系统中的直接耦合比例证据。找到的[2018年精胺—质子泵研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5861359/)涉及精胺刺激H⁺-ATPase及质子外排，不能据此把 R917 改成某种腐胺/H⁺耦合。能区分当前方案与运输替代方案的最小证据，是已定位转运系统在受控梯度下同时测得底物与质子方向／比例；不以多胺补救生长替代。（PA2-C011）

**工程交接与阻止条件。** before/after已覆盖7个物种完整的 formula、charge、name、annotation，以及9条反应的完整计量（包含保持不变的R607、R608）。7个before身份与实际安装的读取器一致。现有窄接口只接受六物种、R607/R608及胞质H⁺，因此当前应拒绝这个扩展提案；最小接口差异是增加 m257、上述七条反应，且仅对R609允许线粒体H⁺ m28。其他字段结构、默认关闭及来源绑定沿用。不需要修改通用构建逻辑或开放运输修改。（PA2-C012）

后续静态应用必须满足：输入和所有旧字段匹配；直接影响集合恰为上述15条；13条内部反应均守恒，交换向量准确；仅七物种身份和七条指定H⁺项变化；运输、GPR、边界、目标、生物量与需求均保持；写出重读无额外差异。出现新增副本、非H/Q残差、ΔH与ΔQ不一致、额外字段变化或接口无法表达所需字段，应停止应用。若审阅要求所有邻接物种同时采用pH7.3优势形式，或要求所有鸟氨酸节点立即精确化为L，C7的“局部迁移”前提即不成立，需要新的明确范围，不能静默扩大。

旧20条主张及4条补正的最终审阅结论继续沿用；新判断单列PA2-C001–012并关联旧主张。新增12条独立审阅覆盖为0/12，均待审。已实施的是官方来源核验、参考读取及静态算术，没有生成候选模型或执行工程入口。使用科研治理、基因身份、ARS必要来源核验及Ponytail核查规则；AI辅助资料整理与推导不替代独立审阅。既有缺失／补救实验的条件限制继续有效，不能据此增加或拟合多胺 biomass、maintenance、demand 系数。
