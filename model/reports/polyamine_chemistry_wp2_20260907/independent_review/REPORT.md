# C7 独立来源审阅

**化学方案及行变换结论成立；完整字段提案仍有下述小修应纳入后续交付。** 本轮独立核验新增 PA2-C001–012：11 条 supported，1 条 partially_supported（C012 的工程改动描述不完整）。核验了七个物种的完整 before 身份、九条反应的 before 计量，以及三个目标化学身份的官方结构。自行读取指定参考并作精确算术，得到 **13/13 条内部反应守恒，两个交换向量正确**。没有应用候选、调用求解器或执行工程测试。

**交接前的最小修正。**

1. 七个 after.annotation 均应恢复 `sbo: SBO:0000247`。这是“小分子”类型分类，质子化变化不会使它失效；当前入口整项替换 annotation，确实会丢掉它。三个腐胺节点还可保留 MNXM118：其 Properties 中的 C4H14N2、+2、InChI 和 InChIKey 均与候选一致；该记录的相似映射列表不是精确身份集合。[SBO 原始定义](https://github.com/EBI-BioModels/SBO/blob/master/SBO_OBO.obo)、[MNXM118](https://www.metanetx.org/chem_info/MNXM118)
2. 补明 m257 的证据性质：原节点只有名称、式、电荷及 SBO，没有 InChI。新腺苷立体化学来自标准脱羧 SAM 身份，并与 R118 的 SAM、R728/R729 的甲硫腺苷上下文一致，属于**有来源的注释重建**，不是由配平证明或从原注释保留下来的信息；新结构的硫构型仍未指定。该依据足以支持当前限定的标准化提案，不构成原生条件下的实验确认。[CHEBI:57443](https://www.ebi.ac.uk/chebi/CHEBI:57443)、[Rhea 15982](https://www.rhea-db.org/rhea/15982)、[CHEBI:17509](https://www.ebi.ac.uk/chebi/CHEBI:17509)
3. C012 应把工程差异写完整：除增加一个物种和七条反应，**预检、质子差值计算和实际加质子三处必须共用逐反应的质子选择**，仅 R609 使用 m28[C_mi]，其余使用 m10[C_cy]。现有实现后两处写死胞质质子；只放宽白名单和预检仍会漏改 R609。这是静态代码发现，尚未实施或测试。

**哪些身份可以确认。** 鸟氨酸的三个原节点没有指定构型；C5H13N2O2/+1 对应通用 [CHEBI:46912](https://www.ebi.ac.uk/chebi/CHEBI:46912)。[L 型 CHEBI:46911](https://www.ebi.ac.uk/chebi/CHEBI:46911)是其子类，不能用相同分子式推定 L 身份。腐胺的 C4H14N2/+2 与 [CHEBI:326268](https://www.ebi.ac.uk/chebi/CHEBI:326268)完全一致。这支持项目已有的 pH 7.3 表示方向，限于所选节点，不证明实际隔室 pH 或全模型表示已经统一。

旧鸟氨酸的中性 CHEBI:18257/7784、阴离子 CHEBI:32964/11448/19370、二价阳离子 CHEBI:46913，以及中性的原 InChI/Key、MNXM741174，都不应继续作为候选的精确同一身份。旧腐胺的 CHEBI:17148 及其四个别名是中性实体；CHEBI:172953 是氘代实体。它们应从精确身份集合移出，候选保留的 CHEBI:326268 和原有二价 InChI/Key 则正确。其他命名空间没有在本轮逐项直开核验，不应把删除一概说成“已证实冲突”；可在原始来源记录中保留关联，待确认后选择性保留。[中性鸟氨酸](https://www.ebi.ac.uk/chebi/CHEBI:18257)、[鸟氨酸阴离子及别名](https://www.ebi.ac.uk/chebi/CHEBI:32964)、[二价鸟氨酸](https://www.ebi.ac.uk/chebi/CHEBI:46913)、[MNXM741174](https://www.metanetx.org/chem_info/MNXM741174)、[中性腐胺及别名](https://www.ebi.ac.uk/chebi/CHEBI:17148)、[氘代腐胺](https://www.ebi.ac.uk/chebi/CHEBI:172953)

**配平的因果链。** 现有 R728 的元素残差为零、电荷残差为 +1；m257 的 H23/0 与已登记的硫鎓结构不符，正确的同式物种是 H23/+1。采用 H24/+2，并保留中性亚精胺后，产物必须为 4H⁺。相反，R2183 原式已经守恒，胍丁胺 H16/+2 无须修正；腐胺改成二价后，移除原产物的 2H⁺ 即可。[CHEBI:15625](https://www.ebi.ac.uk/chebi/CHEBI:15625)、[中性亚精胺](https://www.ebi.ac.uk/chebi/CHEBI:16610)、[Rhea 12722](https://www.rhea-db.org/rhea/12722)、[Rhea 13930](https://www.rhea-db.org/rhea/13930)

设 Δ 为产物减反应物。改动一个 H⁺ 系数 δ 同时增加 δ 个 H 和 δ 个单位电荷，因此只有其他元素残差均为零、且 **ΔH=ΔQ** 时才存在唯一修正 **δ=−ΔH**。原 R728 的 (0,+1) 不满足这一条件，不能只补 H⁺ 掩盖身份错误。C7 固定身份后的七处变化全部满足该条件：

| 反应 | 当前 H⁺系数 → C7 | 固定 C7 身份、尚未改 H⁺时的 (ΔH, ΔQ) |
|---|---:|---:|
| R118 | −1 → −2 | (+1,+1) |
| R151 | 0 → −1 | (+1,+1) |
| R609，线粒体 H⁺ | 0 → −1 | (+1,+1) |
| R610 | 0 → +1 | (−1,−1) |
| R728 | +1 → +4 | (−3,−3) |
| R729 | +1 → +2 | (−1,−1) |
| R2183 | +2 → 0 | (+2,+2) |

R607、R608 的 H⁺系数分别仍为 +1、−1。m257 仅出现于 R118/R728/R729；在保留其他物种表示的前提下，一个额外修正物种足以闭合问题，范围确为 15 条反应、29 个参与物种，不是全模型最小性证明。R1282 的开放向量为 (C,H,N,O,Q)=(-5,-13,-2,-2,-1)，R1301 为 (C,H,N,Q)=(-4,-14,-2,-2)。保留的 SAM H22/0 本身有合法的[硫鎓内盐身份](https://www.ebi.ac.uk/chebi/CHEBI:67040)；其原注释仍混有 +1 形式，这限制“所有邻接物种完整字段已统一”的声明，不影响本轮固定 formula/charge 的算术，也不要求扩大修改范围。

**数学结论及边界。** 自行构造并配平的 N7 和 C7-dcSAM(+1) 同样获得 13/13 内部守恒，故配平数量不能选择 N/C 或供体的质子化态。对两种已修正的 C7，完整 dcSAM 行仅有 R118:+1、R728:−1、R729:−1；对应胞质 H⁺系数从 (−1,+3,+1) 变为 (−2,+4,+2)。逐列核对全部 2,313 列，满足

\[
S^{(2)}_H=S^{(1)}_H-S_d,\qquad S^{(2)}=T S^{(1)},\quad
T=I-e_H e_d^T,\quad T^{-1}=I+e_H e_d^T.
\]

因为 H 与 dcSAM 是不同的平衡行，\((e_H e_d^T)^2=0\)。在二者均施加齐次稳态约束、通量变量/边界/目标相同且没有额外表示相关约束时，两者可行通量集合及最优目标值相同。该证明没有建立与原参考或 N7 的等价性；C7 相对原参考确实改变七项 H⁺计量，不能据此保证原来的生长或能量结果不变。

**运输不改计量，电荷解释仍会改变。** 按保存的正向反应式，R909/R910/R917/R918 的 N→C 胞质形式电荷分别为 −1→0、+1→+2、−1→+1、+1→−1；另一隔室变化相反。R918 的保存边界确为 [0,0]，故最后一项只是关闭反应的假想正向记账。局部守恒可成立，但这些数字不是原生耦合比例或电流证据。已直开的 [2018 年论文摘要](https://pmc.ncbi.nlm.nih.gov/articles/PMC5861359/)研究精胺诱导的质子泵活性及 H⁺外排，不能给出这三条开放运输的 H⁺:底物比例；本轮未重演全部检索，也不作“文献中不存在机制证据”的全局结论。
