# Candida phangngensis 作为 CoQ 末端反应参照

核验日期：2026-10-02。按用户要求，以该物种补充前轮酿酒酵母参照。本轮结果加强了采用Q9近缘物种作比较的理由，但未补出已验证的羟化供体或独立前体氧化酶。

## 该物种实际提供了什么证据

Limtong等2008的物种描述直接报告主要泛醌为Q9，并将该物种放在Yarrowia分支。它因此适合用作本项目的Q9/近缘物种参照；但主要醌类型并不确定单个合成步骤的底物氧化态或电子供体。该来源本轮核验了原始论文摘要，未取得完整酶学方法，不声称读到了末端酶活实验。[原始研究，PMID18218960](https://pubmed.ncbi.nlm.nih.gov/18218960/)

检索同时采用Candida phangngensis、Candida phangngaensis、Yarrowia phangngensis和Yarrowia phangngaensis。NCBI taxon444778使用Yarrowia phangngaensis；2026分类原文也明确连接旧拼写和这一名称。不同年代的命名作者和模式保藏编号不完全一致，本轮不据此合并菌株文件。[NCBI](https://www.ncbi.nlm.nih.gov/Taxonomy/Browser/wwwtax.cgi?id=444778)、[2026原始分类，Validated taxa in Yarrowia](https://doi.org/10.65390/fdiv.2026.136006)

## 对两条反应的影响

|模型位置|此前可比较的Q9候选方程|Candida/Yarrowia phangngaensis新增证据及缺口|
|---|---|---|
|R695，末端羟化|DMQ9H2 + O2 + AH2 → DMeQ9H2 + H2O + A|Q9存在得到支持；本轮未取得该物种自由DMQ9H2底物、AH2身份或完整净反应的直接酶学证据。|
|R385，末端O甲基化|DMeQ9H2 + SAM → Q9H2 + SAH|仍可作比较候选；目前醌醇甲基化的反应依据来自此前酵母实验/酶分类，未升级为本物种实测。|

AH2/A是未指定的还原/氧化供体对，不是已经确定的NADH/NAD。DMQ为去甲氧基Q，DMeQ为去甲基Q，H2表示醌醇。质子项随具体微物种约定配平；上述不是已写入模型的反应。此前来源及物种外推限制见[酵母对照报告](../coq_yeast_redox_connections_20261002/REPORT.md)。

本轮未确认可直接赋予这两步的本物种实验验证基因位点，也没有查实独立DMQ9H2→DMQ9氧化酶。这里的“未确认”只覆盖本次有限搜索，不代表该物种缺少这些功能。参考基因组可以为后续同源比较提供序列输入，不能凭组装存在或自动注释填定电子供体。

具体参照组装已定位到CBS10407的GCA_900519005.1及NRRL Y-63743的GCA_030581735.1；本轮只核对目录/论文中的身份，没有下载全序列或将两者视为相同组装。UniProt 2026_03按taxon444778查询返回24条公开记录，未命中这两类末端酶；这不是完整蛋白组或基因缺失的证明。JGI、KEGG和BioCyc的部分入口未能完整访问，限制详见[独立记录](independent/NOTES.md)。
