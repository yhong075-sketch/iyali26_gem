# R2021、R2029、R2034、R2039 的底物供给审查

核验日期：2026-09-23。范围：9月21日已 screen 候选及其记录的 SD-Leu/PO1f 条件；本轮静态核验，没有运行新的优化、修改模型或培养基。审查方案见 [TASK.md](TASK.md)，逐物种计量、边界、输入完整 SHA 和检查代码身份见 [model_evidence.json](model_evidence.json)，独立审计见 [AUDIT.md](AUDIT.md)。

**生物上，不能说这些二肽必须由培养基直接提供；细胞自身的蛋白／肽加工是可能来源。但目前证据也不能确认这四种具体二肽在 PO1f 的 SD-Leu 条件下已形成足够的游离池，并持续供应液泡。当前模型没有连接这些内源来源，培养基又未供给，因此四条水解反应断供。**

## 底物是什么

以下按原始 XML 的物种、计量和区室核实，不以反应名称推定。

| 水解反应 | 二肽底物 | 水解产物 | 对应外部 exchange |
|---|---|---|---|
| R2021 | Gly-Asp，甘氨酰天冬氨酸 | 甘氨酸 + L-天冬氨酸 | R2018 |
| R2029 | Gly-Glu，甘氨酰谷氨酸 | 甘氨酸 + L-谷氨酸 | R2026 |
| R2034 | Ala-Gly，丙氨酰甘氨酸 | L-丙氨酸 + 甘氨酸 | R2031 |
| R2039 | Gly-Pro，甘氨酰脯氨酸 | 甘氨酸 + L-脯氨酸 | R2036 |

四条均在模型的液泡区室 C_va 消耗一分子二肽和一分子水。尽管反应名称含有“cytosol”，实际计量的底物和产物均在 C_va。R2029 物种原名为 `Gly_Glu`，表中仅规范显示为 Gly-Glu，未改原始记录。

## 培养基和当前模型：已核实

实际运行清单对应的 `sd_leu.csv` 没有上述四个 exchange；运行时摄入量均为 0，exchange 边界均为 [0,1000]，按其计量只允许外排。所参照的供应商 **CSM-Leu** 配方也未列出这四种二肽；其中的游离氨基酸不等于已连接的二肽。这是配方和模型的核查，不是对具体实验培养液的化学测量。[CSM-Leu 原始配方](https://sunrisescience.com/shop/growth-media/amino-acid-supplement-mixtures/csm-formulations/csm-leu-powder-10-grams/)

逐一核查四种二肽在胞外、胞质、液泡的全部 12 个物种，得到的连接只有：

```text
外部 exchange ↔ 胞外二肽 ↔ 胞质二肽 ↔ 液泡二肽 → 两种游离氨基酸
```

此图仅示连接拓扑；当前 exchange 只允许外排，不允许摄入。

没有其他反应向这些二肽池提供内源合成或蛋白降解产物。对任一种二肽，将三个区室的稳态守恒相加，内部转运抵消，得到：

```text
−v_exchange − v_hydrolysis = 0
v_exchange ≥ 0，v_hydrolysis ≥ 0
因此 v_hydrolysis = 0。
```

这是固定模型和当前边界下的结构性结论，不只是某一个最优解恰好为零。模型中存在代谢物节点不等于已经赋予初始库存；标准稳态 FBA 需要持续补给来平衡持续消耗。即使现实中存在有限库存，也不能据此假设无限期稳态供给。

水是另一个模型断点：液泡水的完整守恒为 `v_R1363 − v_R2021 − v_R2029 − v_R2034 − v_R2039 = 0`，当前 R1363 为 [0,0]。真实细胞含水，不意味着这个关闭的模型连接能自动供水；即便补入二肽，此断点仍需另行处理。

## 真实生物学：有可能的内源来源，具体四种仍待证实

解脂耶氏酵母的原始实验报告测到了细胞内氨肽酶、羧肽酶和二肽基氨肽酶活性，支持细胞内肽加工能力。研究中最高活性出现在含 peptone 培养基、稳定期；该条件不能直接等同于本项目 PO1f/SD-Leu。论文纯化的是氨肽酶，不能写成已纯化并验证了目标二肽释放酶。[Hernández-Montañez 等，2007，原始出版商摘要](https://academic.oup.com/femsle/article/268/2/178/656541)，DOI：10.1111/j.1574-6968.2006.00578.x；PMID：17227470。

由肽加工能力推断“自身蛋白／肽可能成为二肽来源”是合理候选机制；本轮读取的摘要未提供这四种游离二肽的生成量、形成速率或液泡定位证据。本轮只按成功读取的摘要范围使用该来源，不声称取得全文。限定检索也未取得四种精确二肽在目标菌株、培养和区室中持续可用的直接证据；未取得证据不等于证明它们不存在。既有序列／结构功能候选同样不能补足这些原位供给证据。

因此，对这四种具体底物的结论均为：**培养基不一定是唯一来源；当前培养下的内源持续供给尚未确认。**不能因细胞有相应游离氨基酸，或蛋白序列含有相邻残基，就认定这些游离二肽已形成并到达液泡。

## 之前人工 pool 的含义

9月14日诊断中的 `POOL_GlyAsp_cy`、`POOL_GlyGlu_cy`、`POOL_AlaGly_cy`、`POOL_GlyPro_cy` 各以 [0,1] 的边界直接产生胞质二肽，且不消耗上游底物。它们是人工连续供给，用来测试“若有底物，网络能否运行”；不是实测内源池、有限初始库存或原始培养基成分。当前9月21日候选不含这四个诊断源。

若将来表示内源回收，需有证据支持上游蛋白／肽来源、切割产物、区室和通量约束，并保持物质收支；若实验确实补充了二肽，则通过相应 exchange 表示外源供给。这两种情况的生物含义不同，不能用人工源替代证据。

## 核验范围与未决项

本轮已核实模型输入身份、4条水解计量、12个二肽物种的完整邻接和守恒、实际 medium/exchange、液泡水守恒及旧人工源身份；共零次求解。物种级肽加工证据与培养基原始配方已读取，精确四种二肽在 PO1f/SD-Leu 液泡中的持续可用性保持未决。没有据此调整模型、GPR、培养条件或必需性标签。独立审核的逐项状态和覆盖率以 [AUDIT.md](AUDIT.md) 为准。
