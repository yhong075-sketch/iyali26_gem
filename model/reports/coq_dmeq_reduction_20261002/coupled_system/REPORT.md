# 末端 COQ 耦联体系：DMeQ 还原过程的证据边界

核验日期：2026-10-02。范围：独立重读 Lu 2013、Poon 1999 缓存原文及 Nicoll 2024 原文／官方补充材料，判断这些实验能否把甲基化前的还原活动归给某个 COQ 蛋白。未重做蛋白身份、序列／结构计算，未改模型或 GPR。

**结论：可以把现有 COQ7 家族候选列为耦联机制的待检对象；现有证据不足以认定它催化游离 DMeQ9→DMeQ9H₂，更不足以赋予独立还原反应的 GPR。** 缺少一条模型连接不证明细胞需要一条由专用酶催化的独立反应；是否采用自由中间体、蛋白结合过程或耦联净反应，仍需判别。

至少需要区分三类可检验解释：①已有 COQ 蛋白的结合／催化过程内完成状态转换；②另一催化组分进行游离前体还原；③受测体外体系中的化学或再生体系贡献。它们在当前证据下均未被确认为 W29 机制。提出这些替代解释是本项目的推理，不是原文已报告的机制结论。

模型表示的最低验收区别是：要拆成独立还原反应，应能明确自由底物／产物、供体、净计量及催化归属；若仅有耦联端点证据，则只能研究耦联粒度候选，同时保留未解析的中间过程，不能用任意新 GPR 填空。当前不建议把 R695 改写成接通 R385 的形式。
