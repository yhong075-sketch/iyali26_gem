## 候选一：YALI1E11674g — PMR1/SCA1

**功能与身份。** 钙转运 P 型 ATPase 候选；原生基因干预与钙/锰稳态、分泌加工有关，直接转运计量未核实。旧 ID `YALI0E09471g`；S2 `YALI1 Genes!A5675:H5675`；[UniProt O43108](https://www.uniprot.org/uniprotkb/O43108/entry) 冻结 entry 168、sequence 1、928 aa，序列 SHA `0822550a905d87ca82f139229e598b2bfee06ffb89b4f35f5a5ca1dabb2cc7f0`。单一映射得到支持，但不是对目标实验菌株重新测序。数据库 reviewed 与其 protein existence “inferred from homology”不是同一个证据维度。

**分类：身份或区室尚不确定（具体未决为原生转运定位/方向/计量，非否定已核实的 ID 桥接）。** 广义生理功能已知，具体反应仍依赖注释；不是完全推测的无功能基因。

直接支持复用旧 MMF-C002–007：[Park 1998](https://pubmed.ncbi.nlm.nih.gov/9461422/) 摘要报告原生破坏株低 Ca/EGTA 生长受损及离子补充改善；[Sohn 1998](https://pmc.ncbi.nlm.nih.gov/articles/PMC107781/) 摘要/已索引片段报告蛋白依赖的分泌和加工效应。前者全文仍不可用，后者未完整读到全文；详细构建和重复不能据此补写。后者条件为 SMS397A/CS3、YPD/GPP，不能外推为 SD-Leu。

反证与限制：这些表型未排除间接稳态效应，补 Mn 改善也不能确定 Mn 是同一反应的直接底物。定点追踪到的直接 Ca 转运研究 [Okorokov & Lehle 1998](https://pubmed.ncbi.nlm.nih.gov/9595667/) 的物种是 **S. cerevisiae**，不能补上 Yarrowia 的直接证据缺口（D-C006）。本轮未找到所需原生计量，是有界检索结果，不是“文献不存在”。

**条件式反应与精确差异。** 参考中没有显式 Ca/Mn 代谢物命中；R794 是 Golgi 质子 V-ATPase。假设将来直接证据确认胞质向 Golgi 的 Ca 泵，可研究下式：

`n Ca²⁺_cy + ATP_cy + H₂O_cy + h H⁺_go → n Ca²⁺_go + ADP_cy + Pi_cy + h H⁺_cy`

`n`（Ca/ATP）与 `h`（反向质子耦联数）尚未确定；胞质 ATP 消耗侧和转运方向也须由证据约束。拟议 GPR 为单基因 `YALI1E11674g`，仅针对经确认的该转运活动。Mg 是数据库注释的功能辅因子，本轮不把它写成净消耗物；不并入 Mn 反应，也不发明同工酶 OR。

若以后成立，最小数据差异是增加 1 个 geneProduct、2 个 Ca 物种（`C_cy`/`C_go`，元素 Ca、电荷 +2）和 1 条转运反应，复用现有 ATP/ADP/Pi/H₂O/H⁺；反应 ID、`n/h`、边界均留空。R794 不作为替换靶点。这个设计尚无经过证据约束的 Ca 来源/去路，不增添交换、sink 或 biomass demand 以强迫其产生生长效应。

**计量检查。** 按参考中现存中性 ATP/ADP/磷酸分子式，例子 `(n,h)=(1,0)`、`(1,1)`、`(2,0)` 都元素/电荷配平，因此配平不能识别真实比例。机械搬入数据库反应的额外 `+H⁺` 会产生 H `+1`、charge `+1` 残差（产物减反应物；D-C005）。这些仅是代数例子，不是已验证的生化比例或全连接分量微物种审计。

**最小验证设计与接纳条件。** 以原生蛋白的 Golgi 富集膜制备，比较亲本、目标扰动和回补；同一比较中测量定向 Ca 转运与 ATP 消耗，并用膜方向、被动通量和非目标 ATPase 背景控制区分特异耦联。若净质子交换影响方程，也须测定或形成有依据的边界。只有得到可归因于该蛋白、可复现的方向和耦联计量，才选择上述方程的一个实例，并开展相同参考 SHA 下的区室/微物种核验及人类补丁审阅。这里是实验设计提纲，未安排或执行实验。

停止条件：仅有同源性、补充救援、定位预测或可配平的方程；来源物种/构建不能对应；耦联比例无从区分。遇到这些情况保持未成熟，不通过 essentiality 分数挑比例。**本候选的一个决定性缺口，就是原生 PMR1 特异的定向 Ca–ATP 耦联测量。**
