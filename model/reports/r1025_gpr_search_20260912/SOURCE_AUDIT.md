# R1025 GPR：独立核内定位来源审计

核验日期：2026-09-12（America/Los_Angeles）。本分支限定检索原生 Yarrowia 核内碳酸酐酶及 Nce103 跨物种定位证据；没有执行 LP、BLAST、结构预测或作业，也没有改变模型/GPR。主线程的序列检索不属于本分支已执行或已独立复现的结果。

**结论：YALI1F28274g 可以保留为 R1025 的待验证单基因候选，但本轮未取得足以把该 GPR 标为原生核内实验确认的证据。** 新找到的酿酒酵母原始 GFP 数据明确包含核定位；同时存在独立的线粒体膜间隙定位实验及 GFP 标记局限。应保留这些支持和限制，不能把候选描述为“只有胞质证据，所以不可能入核”，也不能把跨物种核定位直接转成 Yarrowia 核内催化确认。

候选身份：**YALI1F28274g / YALI1_F28274g**，正式基因名尚未核实；W29 历史 UniProt A0A1H6PNW2，对应 CLIB122 **YALI0_F21406g / Q6C0V4**；β-碳酸酐酶功能候选，支持可逆 CO₂ 水合的同源/数据库注释证据，原生区室与靶标专属酶学仍未确认。跨物种参照为 **S. cerevisiae YNL036W / NCE103 / P53615**，名称已确立、碳酸酐酶功能有实验支持；其定位证据必须按下表区分。

## 六组主要来源及读取位置

1. **Huh 等，2003，原始定位研究及其数据。** [论文](https://www.nature.com/articles/nature02026)，DOI [10.1038/nature02026](https://doi.org/10.1038/nature02026)；[原始数据库 YNL036W 条目](https://yeastgfp.yeastgenome.org/getOrf.php?orf=YNL036W)；[数据库提供的原论文 PDF](https://yeastgfp.yeastgenome.org/nature02026_r.pdf)。独立读取原文 p686：全长蛋白 C 端 GFP、内源启动子；p687：约 27 kDa GFP 可因位阻或干扰末端信号造成错定位；p690–691：在 SD−His 中长至对数期，以 GFP/DAPI/DIC 成像。补充方法 “Assignment of initial localization categories” 记载两名评分者独立盲评，DAPI 用于判定核位置。原始目标条目确有胞质和核两项，RFP 共定位栏没有具体记录，因此不能称该靶标已获 RFP 共定位复核。目标核定位图片的网页读取失败，本次核实的是原始分类记录及方法，未自行重判目标显微图像。原文 PDF 可得，未仅依赖 Nature 摘要或后续数据库摘要。

2. **Vögtle 等，2012，酿酒酵母膜间隙原始实验。** [Intermembrane Space Proteome of Yeast Mitochondria](https://pmc.ncbi.nlm.nih.gov/articles/PMC3518125/)，DOI [10.1074/mcp.M112.021105](https://doi.org/10.1074/mcp.M112.021105)，PMID22984289。独立读取原文 XML 的 “Validation of Novel IMS Protein Candidates”、Fig. 2B 图注、Antisera 与 Discussion。Nce103 在完整线粒体中受保护，外膜经低渗破裂后可被蛋白酶接触；这支持该样本中的膜间隙定位。Discussion 解释 GFP 融合可能妨碍膜间隙蛋白导入，也保留部分蛋白多区室分布的可能。Table I 的 NCE103 “cytosol, nucleus” 栏是已有 SGD 注释，不是该研究另做一次核定位实验。该文没有证明所有 Nce103 分子只在膜间隙，也没有测量 Yarrowia 核内定位。

3. **Dostál 等，2020，Candida 原始定位实验。** [Cellular Localization of Carbonic Anhydrase Nce103p in Candida albicans and Candida parapsilosis](https://pmc.ncbi.nlm.nih.gov/articles/PMC7036955/)，DOI [10.3390/ijms21030850](https://doi.org/10.3390/ijms21030850)。独立读取 XML 的 §2.1–2.3、§4 方法及 Discussion。体系为 C. albicans HE169 和 C. parapsilosis P69，在 YPD、30°C、摇瓶培养下以免疫金电镜、分馏、Western 和 MS 检测碳酸酐酶；支持细胞壁/质膜及胞质、线粒体组分中存在信号。研究对象分别为 NCE103 蛋白 CaNce103p/Q5AJ71 与 CpNce103p/G8B6R8，不能替换为 Yarrowia 靶标。该研究没有给核内定位提供直接阳性或经过充分验证的排除结论；分馏结果也不单独证明各区室均承担同等催化量。

4. **Zhao 等，2026，已有 Yarrowia 候选相关表达研究。** [原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13207147/)，DOI [10.3390/ijms27104224](https://doi.org/10.3390/ijms27104224)。复用前轮已获取的原文，本轮重新读取 Table 1 的 pCA/XP_505708.1、相关表达/活性段落和定位分析上下文。定位分析讨论的是 MmaCA 及其截短体预测，不能视为 pCA 的核定位实验。前轮对活性读数和 Fig. 1 的审核保持有效，本轮没有重新分析活性原始数据，亦不以总体 CA 活性推导核内定位。

5. **SGD NCE103，定位注释的追溯入口。** [NCE103 / YNL036W](https://www.yeastgenome.org/locus/NCE103)。独立打开页面的 Cellular Component 和 Summary：cytoplasm:HDA、nucleus:HDA、mitochondrial intermembrane space:IDA。它是人工整理数据库而非新的独立实验。上述核定位已继续追到 Huh 原始靶标数据，膜间隙定位追到 Vögtle 原文；不能把两者合并成未经条件限定的唯一定位。

6. **UniProt 原始记录与版本。** [P53615](https://www.uniprot.org/uniprotkb/P53615/entry) 的 [JSON](https://rest.uniprot.org/uniprotkb/P53615.json)，本次独立获取 v169（2026-09-02，序列 v1）：`comments/SUBCELLULAR LOCATION` 的 cytoplasm/nucleus 引 PMID14562095，膜间隙引 PMID22984289；GO nucleus 项明确 HDA:SGD。另读取主审新保存的 [Q6C0V4 JSON](https://rest.uniprot.org/uniprotkb/Q6C0V4.json)，v117（2026-09-02，序列 v1）仅列胞质 IBA 定位；并核对既有 A0A1H6PNW2 v32 历史定位记录。它们是版本明确的数据库证据，不新增原生定位实验。序列身份/范围由本轮主审另记，本审计不将数据库记录相同解释为区室功能已确认。

## 检索边界、反证与验收

限定检索覆盖物种加碳酸酐酶/核内/定位，`YALI1F28274g`、`YALI0_F21406g` 的核定位组合，以及 NCE103 核/胞质/Huh 原始出处追溯。检索结果中的 “nuclear-encoded” 只是核基因组编码，不是蛋白核内定位；其他物种复合体 I 的 γ-CA 也不据此归给本 β-CA 候选。检索到但未进入上述六组证据的泛化综述、其他蛋白和未映射转录组条目，不计作支持。

若要把 R1025 的候选升级为原生支持的酶促 GPR，至少需要可追溯的目标身份以及适用条件的核内存在/定位证据，并把核内反应归因到该蛋白；可结合经功能检验的标记、原生抗体或核分馏与污染控制，以及定位/基因扰动对核内 CA 活性或供给的影响。仅检测蛋白入核仍不证明足够容量。若把 R1025 解释为自发反应，则需另立条件化速率依据，不能把 GPR 留空当成容量测量。

审计覆盖：**6 条声明均检查；4 条支持、1 条部分支持、1 条未核实**。主要来源为 **6 组**（4 项原始研究及其关联原始数据/补充材料、2 组数据库记录）；本次新打开并读取 3 项定位原始研究的有关正文/方法或补充材料，复核 1 项已有 Yarrowia 研究的相关段落。原生 Yarrowia 核内定位/核内靶标催化直接来源数为 **0**。这不是全物种或全数据库的穷尽检索。原始获取文件、URL 和完整哈希由本目录 sources 留存；失败的网页/图像访问不计入已重判图像。无科学修改或新求解。
