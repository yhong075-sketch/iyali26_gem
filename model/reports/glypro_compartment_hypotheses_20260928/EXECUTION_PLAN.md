# 本轮固定比较口径

本轮是用户已授权的模型假设敏感性分析；请求原文保存在 REQUEST.txt。输入为明确指定、SHA核对的 E5_vacuole_open_chemistry.xml。保留既有八条能量保护、四连接边界和十三个化学表示保护。旧定位预测与酶活证据仅作假设来源，不重新提交预测或在线BLAST。

所有情景保持同一PO1f / SD-Leu / CRISPR质粒选择加载配置、biomass_C、NGAM=7.8625。胞质假设反应为空GPR，模板关闭。V_ONLY/C_ONLY目标水解容量各0.01；NONE两者关闭。人工Gly-Pro来源只临时进入O_CY或O_VA之一，0至0.01，不持久化到XML。

预先固定：q=0.01；仅若同一起点两路线无法共同达到该q，尝试独立较低q=0.001。优先共同无源REF最大生长作为生长下限；若不能共同达到，改用同q最大生长两者最小值减1e-6。最小泵之后的L1见证允许泵上限为最小值+1e-8；此松弛不改变FVA原始最小/最大值。求解容差保持1e-7。

执行顺序：静态全邻接审计及构建 → REF/V_ONLY/C_ONLY无源四种核苷酸耗散与零通量 → 四格、两种NONE及无源对照 → 固定q共同生长的R795最小/最大与完整见证 → R795关闭和必要运输隔离。无额外生长要求时仍保持正常培养与NGAM。默认不增加BOTH、胞外输入、其他二肽供给或大规模敲除。

所有实际优化通过同一持久预算：最多180次、累计求解1800秒、单次60秒、单线程。软件异常、超时、非有限值和不可行分别记录，不当作零值或死亡。输入/保护冲突立即停止相关执行；发现正封闭能量则保存风险见证，暂停候选接纳，不修改其他通路。保留已完成项及重跑命令，不为用完预算增加情景。
