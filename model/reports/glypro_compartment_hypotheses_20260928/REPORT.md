# Gly-L-Pro 水解区室假设：相同来源与处理量下的运输和泵依赖

核验日期：2026-09-28，America/Los_Angeles。本轮实际构建、导出、重载并计算了独立假设候选。

**四个组合均可处理 q=0.01 mmol/gDW/h，且能共同维持无源参考生长 1.429177892279 h⁻¹。泵耗取决于完整路线：胞质起点→胞质水解为0，胞质→液泡和液泡→胞质均为0.5，液泡→液泡为1 ATP/Gly-Pro。** 这回答的是当前计量、运输与培养约束下的模型问题，不判定蛋白原生定位。

输入是已核对实际路径、SHA和构建manifest的 `E5_vacuole_open_chemistry.xml`，不是仅能量修复的E5，也没有使用默认E0入口。保留八条E5能量修订、四连接有限开放及十三个目标池的化学字段和条件性表示说明。输入身份与既有dirty状态在[前态记录](before.json)，逐候选身份在[构建清单](candidates/manifest.json)。

源模型不存在等价胞质水解，故新增 `HYP_GLYPRO_HYD_CY`：

`Gly-L-Pro[cy] + H2O[cy] → Gly[cy] + L-Pro[cy]`

复用四个现有代谢物，元素和电荷均配平；单向、无ATP或H⁺附加成本，功能GPR为空。**TEMPLATE中该反应为[0,0]**。V_ONLY仅R2039为[0,0.01]，C_ONLY仅新增反应为[0,0.01]，NONE两者关闭。R2039原ID、计量与证据保留，C_ONLY/NONE的关闭只是诊断路线隔离。其他运输均保持共同基线；R1363/R795为[0,0.04]，R871/R876为[0,0.01]。

所有历史保护锁原文保持。化学锁包含旧邻接定义，因此用独立允许清单核对新增反应与R2039边界，再在副本撤回这两项差异，严格核验原锁和原数学定义；没有删锁或改写历史保护。四个XML均无人工来源、耗散测试列、强制q或生长约束。新列关闭后投影到原变量的可行域不变；模板和REF的实际生长、pFBA亦恢复一致。见[假设配置](hypothesis_definitions.json)、[数学差异](model_differences.tsv)。

## 运输如何改变质子和水的账本

R2038名称虽为antiport，实际是 `Gly-Pro[cy]+H+[cy] ↔ Gly-Pro[va]+H+[va]`。R2037也按实际共转运计量解释。R2030/R2040的存储正向是氨基酸与H⁺共同cy→va，所以产物回收的负通量表示AA与H⁺共同va→cy。R795仍是：

`ATP[cy]+H2O[cy]+2 H+[cy] → ADP[cy]+Pi[cy]+2 H+[va]`

| 起点 → 水解区室 | R2038 | R2030（Gly） | R2040（Pro） | R1363供水 | R795 |
|---|---:|---:|---:|---:|---:|
| 胞质 → 胞质 | 0 | 0 | 0 | 0 | 0 |
| 胞质 → 液泡 | +0.01 | −0.01 | −0.01 | +0.01 | +0.005 |
| 液泡 → 胞质 | −0.01 | 0 | 0 | 0 | +0.005 |
| 液泡 → 液泡 | 0 | −0.01 | −0.01 | +0.01 | +0.01 |

完整液泡质子检查是 `2v795 + v2038 + v2030 + v2040 + 其他实际S·v项 = 0`，没有把该式额外写成优化约束。保存见证中，其余液泡H⁺贡献逐项为0；其他三种二肽水解也为0。其原因可由各二肽三池总守恒及仅允许外排的交换、Ile液泡池的封闭去路等逐步推出，全部相关列仍在模型中，没有事后删掉代偿。

胞质起点的液泡路线先随完整二肽带入1H⁺/q，再随两种产物带出2H⁺/q，所以只需泵补1H⁺/q。液泡起点直接水解没有这次质子输入，需泵补2H⁺/q。液泡起点的胞质路线虽在胞质水解，完整二肽输出本身会带走1H⁺/q，所以仍需泵。

四个匹配见证的R2036外排和R2037通量均0；三个Gly-Pro池总账仅有指定来源+q和指定水解−q，没有第二来源或把未水解外排当作处理。已导出Gly/Pro两区室、全部H⁺/水、ATP/ADP/Pi的每项贡献，包含零通量邻接及全细胞背景。不能以稳态ATP净值0声称没有ATP消耗。

将实际路线列按通量加权相加，内部池和H⁺抵消，令a为上表的泵ATP/Gly-Pro，可统一写为：

`Gly-Pro[起点] + (1+a) H2O[cy] + a ATP[cy] → Gly[cy] + Pro[cy] + a ADP[cy] + a Pi[cy]`

这里不包含人工来源本身或下游全细胞代谢；水解本身耗1水/q，额外a水/q和aATP/q属于泵反应。逐组件区分了水解、完整二肽运输、氨基酸回收、供水和泵；不是只看局部示意图。见[完整有符号见证](run/route_flux_witnesses.json)、[全账本](run/proton_water_atp_ledger.tsv)、[分项与净反应](run/route_net_reactions.tsv)。2H⁺/ATP仅为模型约定，不用于推算pH、膜电位或原生耦联比。

## 关泵、运输隔离与替代解

只有胞质→胞质在R795=0时仍达到正q=0.01并满足共同生长；同一完整见证保存了固定来源、水解、零泵和全部约束。其余三格即使去掉额外生长下限、保留正常培养与NGAM，固定同q仍不可行，说明在当前网络中这些持续利用路线需要泵，而非仅为了更高生长才需要。

但供给可自由不用时，这三格关泵仍以约1.429177892279生长，目标最大水解为0；胞质→胞质关泵仍以约1.430849228生长、最大水解0.01。**固定处理任务不可行，不等于细胞死亡或基因必需。** 本轮没有基因KO。

跨区室两格各关闭R2038，以及液泡水解两格各关闭R2030或R2040，共六项运输隔离均使固定q不可行，未放宽其他连接恢复。见[泵依赖](run/vatpase_dependency.tsv)与[运输隔离](run/transport_isolation.tsv)。

当前互斥情景中没有另一条完整Gly-Pro水解路线，匹配q下泵范围为点值，未找到其他液泡H⁺补偿。但**全细胞最优通量并不唯一**：四格生长FBA与同生长pFBA各有96、98、90、104条反应的净通量差异大于1e−7（按胞质→胞质、胞质→液泡、液泡→胞质、液泡→液泡顺序）。这些背景差异不能当作原生代谢上调；也不能从泵的点范围推出全网络只有一个通量解。

## 能量、软件与可复现核验

REF、V_ONLY、C_ONLY各自无源封闭副本关闭全部单侧物料边界和biomass等汇，仅释放维护下界，保留全部稳态行，不带固定q或生长下限。三者的ATP/GTP/UTP/CTP最大耗散全部optimal、值0，三个精确零通量控制均可行。因此新增胞质候选未引入本轮四项封闭能量异常；不外推为全模型热力学完全正确。见[能量回归](run/closed_energy_results.tsv)。

实际86次优化：74 optimal、12次预期隔离infeasible，没有求解失败被填成0。单线程、每次60秒、既定1e−7容差；累计求解调用3.171秒，验证总墙钟521.139秒（含加载、精确复制、完整证据输出），与180次/1800秒预算分开记账。运行时净通量/约束记录最大违反4.45e−8，独立split变量边界核验最大5.22e−8，物料行最大残差9.11e−9，均小于原容差。未追加BOTH、胞外或低q情景。

构建预检发现普通COBRA/Gurobi复制会经LP文本舍入少量原系数，且部分notes为共享引用；两次失败均发生在导出/优化前。新脚本改用经完整数学核对的JSON求解器复制并隔离notes/annotation，没有放宽容差或改原模型。六项静态拒绝/隔离检查及两项输入SHA/拒绝覆盖检查通过，过程保存在[预检记录](candidates/build_preflight_failures.json)。

独立审核直接比较四份XML，并逐项重算86个保存问题、74份可行完整向量、5份路线见证与6,785条账本；核对原生稀疏矩阵、split变量、净通量、共同条件、路线净式、保护和来源。故意损坏的见证被拒绝。审核不使用第二求解器，也没有通过对偶/Farkas证书另行证明最优性或不可行性；范围详见[独立审核](numerical_audit/REPORT.md)。

实际输入、代码快照、求解参数、原生目标/边界/约束/稀疏矩阵及完整net/split解在[运行manifest](run/manifest.json)和逐解文件；[命令](commands.txt)给出新目录重建方式。未覆盖历史模型/报告，未提交或推送。项目默认入口与正式模型接纳状态保持。

## 生物学边界与下一项判别

**YALI1E16433g：原生正式名未核实；W29/PO1f 454 aa；基于序列及既有AlphaFold预测的M24B/X-Pro肽酶、prolidase-like功能候选。目标自身的游离Gly-L-Pro活性与原生功能区室均未实验确认。** 本轮既不赋R2039正式GPR，也不把该基因正式赋给新反应。

历史正式预测支持可溶胞内、胞质并保留细胞核候选，液泡类别未过阈值，SignalP/TargetP无所识别的经典前导信号，DeepTMHMM为GLOB/0TM。这些预测没有变成容量、丰度或分配比例。核候选保留在证据卡；本轮只授权比较胞质/液泡，未确认核内底物与运输机制，所以没有新造核池或核运输。旧在线BLAST仍未取回，本轮没有把它当作完成或前置条件。

最有区分力的下一项观察是：在原生表达条件下，同时分辨胞质、细胞核、液泡中的完整目标蛋白，并与同组分的目标依赖性游离Gly-L-Pro减少、Gly和L-Pro生成配对；设置组分纯度、空白/失活对照，液泡检出需区分完整活性蛋白与降解片段。目标蛋白自身的游离底物酶学仍须独立确认，不能以Gly-Pro-pNA或长肽加工代替。

本轮实际计算支持路线成本与依赖性；净式支持现有计量和边界下的条件性解释；原生催化及定位仍待验证。**较高生长、较低泵耗或路线可行，都不能反推出该蛋白一定在对应区室。**
