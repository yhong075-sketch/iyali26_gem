# R2202 / R1026 GPR 审查

核验日期：2026-09-11。**R2202 的单基因关联有碳酸酐酶注释依据，但整个步骤的基因依赖被两层无 GPR 供给绕过：胞质 R1026，以及核内 R1025 加运输。单独给 R1026 补同一 GPR，仍不足以让目标敲除限制当前模型的生长。**

本次以当前发布的 `model_metadata_trna.xml` 为参考，沿用已保存 SD-Leu／PO1f 有效条件。根目录旧模型、原始 iYli21/iYali26 输入和 V-ATPase 假设版的这两条局部计量、边界、GPR 均另外核对；局部一致不等于这些模型整体相同。新增优化、FVA、screen 求解均为 0。以下数值来自旧 WT 见证的本次代数重构与静态验证，不是重新求解。

**现有规则与化学步骤**

| 反应 | 当前 GPR | 按记录方向写出的计量 | 区室与有效边界 |
|---|---|---|---|
| R2202 | `YALI1F28274g` | HCO₃⁻ + H⁺ ⇌ CO₂ + H₂O | 胞质；[−1000, 1000] |
| R1026 | 空 | CO₂ + H₂O ⇌ HCO₃⁻ + H⁺ | 胞质；[−1000, 1000] |

完整、含区室的四个代谢物 ID 逐项对应，计量向量满足 (S_{1026}=-S_{2202})。因此名称或书写方向的差异没有把它们变成不同酶促步骤。目标单敲实际只把 R2202 边界置零，R1026 原样保留；没有发现“GPR 为假却漏关反应”的软件错误。这里也没有需要重排的 AND／OR：R2202 是单基因规则，问题在于同一化学能力未受一致约束。

R1026 在两个原始输入中已经无 GPR，notes 同时写有 `PROTEIN_CLASS: 4.2.1.1`。这既不能确认某个基因，也不能证明原作者有意表示自发水合。保留三个待核解释：漏注释的酶促记录、重复记录、刻意保留的非酶促过程。未找到可裁决历史意图的原始说明，不能只凭空 GPR 选择其中之一。

另外发现直接涉及该对应蛋白的 2026 年研究：Table 1 的 `pCA` 对应 XP_505708.1，§2.1 从 Po1h 基因组扩增后重组表达。但实际查看 Fig. 1B，pCA 与宿主对照总活性同处显著性组 CD；§4.7 测的是裂解液/上清酸化，未纯化该目标，也未做目标删除/回补。它证明有目标相关实验，尚不足以确认目标特异酶活或原生定位；没有显著增益也不等于蛋白无活性。[Zhao et al., 2026，Table 1、Fig. 1B、§2.1/4.7](https://pmc.ncbi.nlm.nih.gov/articles/PMC13207147/)。

**第一层：R1026 可以完整替代被敲除的 R2202**

旧 WT 记录中 R2202 = −14.12795132372213、R1026 = 0，生长目标为 1.8718823069403。构造：

\[
v'_{2202}=0,\qquad v'_{1026}=v_{1026}-v_{2202}=14.12795132372213,
\]

其余通量不变。因为两列互为反号，所有物种净平衡保持；转交后的数值仍在 R1026 边界内。实际核验全 2315 个反应边界、1877 个物种守恒及目标系数后，目标敲除状态下这一见证仍可行。

这已超出“发现重复”的层次：**R1026 足以在这个条件下承担原 WT 的这部分需求。** 但它不证明 R1026 是必要或唯一的补偿路径，也不代表生物学上确有如此大的自发容量。

**第二层：两条胞质反应都关闭，核内路径仍能替代**

完整 HCO₃⁻ 物种行还显示核内 R1025 无 GPR，且配有水、CO₂、H⁺和 HCO₃⁻运输。以下反应列恒等式经全部参与物种逐项核验：

\[
S_{1025}+S_{1361}-S_{1050}-S_{1161}-S_{1028}=S_{1026}.
\]

| 路径成员 | 必须使用的方向 | 完成的步骤 |
|---|---|---|
| R1361 | 正向 | 水：胞质 → 核内 |
| R1050 | 逆向 | CO₂：胞质 → 核内 |
| R1025 | 正向 | 核内 CO₂ + 水 → HCO₃⁻ + H⁺ |
| R1028 | 逆向 | HCO₃⁻：核内 → 胞质 |
| R1161 | 逆向 | H⁺：核内 → 胞质 |

五条均无 GPR，边界均为 [−1000, 1000]。将上述直接替代通量再转到这五条反应，绝对值均为 14.12795132372213，其他原 WT 通量保持，即可同时令 R2202 与 R1026 为零。该路径的净效果是胞质 CO₂ 水合，**不是净零循环**；其生物学合理性仍须分别核对核内酶/自发容量及运输表示。

| 本次静态核验的通量见证 | 生长目标值 | 最大守恒残差 | 最大边界违反 |
|---|---:|---:|---:|
| 旧 WT 原通量 | 1.8718823069403 | 8.06×10⁻¹⁵ | 0 |
| 目标 KO，转交 R1026 | 1.8718823069403 | 8.06×10⁻¹⁵ | 0 |
| 目标 KO 且 R1026 关闭，转交核内路径 | 1.8718823069403 | 8.06×10⁻¹⁵ | 0 |

基因 KO/额外关反应只缩小普通 FBA 的可行集合；若沿用旧 WT 的最优性记录，现有等目标值可行见证就足以说明这些约束仍允许达到旧 WT 最优生长。这里没有新求解或新对偶证书。旧全基因 screen 的目标 KO/WT = 0.99999999999997 与该机制一致；原表的实验正例/FN 保持历史口径，没有重计阈值或改标签。

四个 HCO₃⁻ 池的全部关联已记录。线粒体 R1024 也无 GPR，但当前网络没有将线粒体 HCO₃⁻直接运到胞质的对应连接，不能仅凭同名物种把它列作本次胞质见证的成员。外部水合 R1027 关闭，交换不允许 HCO₃⁻摄入。本次核内替代不依赖开放这些连接。

**生物学解释及候选处理**

酿酒酵母实验支持：自发水合确实存在，但在常压 CO₂、持续带走 CO₂ 的培养条件下，其速率可能不足以满足生物合成；提高 CO₂或补足相应代谢产物可以改变碳酸酐酶依赖。这是审查非酶促容量的依据，不能直接给 Yarrowia 指定一个边界值或认定其必需性。[Amoroso et al., 2005](https://pubmed.ncbi.nlm.nih.gov/15813743/)，[Aguilera et al., 2005](https://pmc.ncbi.nlm.nih.gov/articles/PMC1276929/)。当前 SD-Leu 配置只是交换通量约束，CO₂交换亦允许较大通量，不等同于已设定实验气相 CO₂分压、胞内浓度或 pH。

| 项目 | 当前审查建议 | 支持、反对与验收条件 |
|---|---|---|
| R2202 单基因 GPR | 保留为有注释依据的候选关联；不增加未经支持的 AND/OR 成员 | 化学和 β-CA 注释相符；原生目标特异功能、胞质定位仍有限。若要升格，应有纯化酶、目标缺失/回补或等价直接证据 |
| R1026 酶促解释 | 若历史来源确认是同一酶的重复表示，候选是合并酶促记录或统一同一基因依赖 | 保留原 ID 对应和来源，确认计量、方向及边界合并方式；不能把两个 ±1000 记录简单合并后声称全可行域不变 |
| R1026 自发解释 | 可保留无 GPR，但另设有证据的条件相关容量 | 当前没有实测速率或 CO₂/pH 条件支持 ±1000，也没有证据支持直接设零；应依据实际动力学和单位换算，不用 FN 命中率拟合 |
| 核内 R1025 与运输 | 与 R1026 一并审查可替代的供给范围 | 本次证明它可保留 WT 生长，因此只改 R1026 的方案不会达到预期基因耦联；尚无依据自动把胞质候选基因复制到核内，亦不能为“堵旁路”删除正常运输 |

后续若获准修改，应固定本次模型身份、培养、目标和原阈值，在独立候选版本检查 WT、目标 KO、目标 KO 加 R1026 关闭、再封闭已确认的核内替代供给等定向对照，并检查相关已知正确预测。数学验收是关闭范围真正切断对应供给且原有正确行为得到保留；生物学验收另需功能、定位和 CO₂条件证据。获得更好的匹配率不自动通过后者。相关实验正例已用于诊断，不能再称独立验证。
