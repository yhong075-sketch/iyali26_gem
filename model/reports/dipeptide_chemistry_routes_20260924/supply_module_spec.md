# 供给路线判定与默认禁用规格

本轮保留外源利用和内源回收两条候选路线；**两者均未达到作为正常 SD-Leu 条件下真实供给模块实施的证据条件**。这不等于二肽在细胞内不可能存在。化学身份标准化解决的是条目表示，不能替代摄取、前体、释放速率和定位证据。

本次实际加载原 B（有限开放、无来源 XML），使用上一轮相同的 PO1f/SD-Leu 加载器并核查所有目标池邻接；未优化、未修改 XML。逐步结果在 [supply_route_decision.tsv](supply_route_decision.tsv)，原始路径、SHA、有效培养和完整反应计量在 [network_inventory.json](routes/network_inventory.json)。B 的四条开放容量仍为 R1363/R795 各 0.04、R871/R876 各 0.01 mmol/gDW/h，属于诊断容量。

## 现有外源连接与缺口

| 精确顺序 | 外部交换 | 细胞摄取 ex→cy | 液泡进入 cy→va | 游离二肽水解 va | 氨基酸返回 cy |
|---|---|---|---|---|---|
| Gly-L-Asp | R2018 | R2019 | R2020 | R2021 | R871 正向；R2030 逆向 |
| Gly-L-Glu | R2026 | R2027 | R2028 | R2029 | R876 正向；R2030 逆向 |
| L-Ala-Gly | R2031 | R2032 | R2033 | R2034 | R2035、R2030 逆向 |
| Gly-L-Pro | R2036 | R2037 | R2038 | R2039 | R2040、R2030 逆向 |

四交换均以 `peptide[ex] → ∅` 书写，正常加载后边界为 [0,1000]：允许排出，禁止负方向摄入。细胞摄取和液泡进入是两步，现有边界均为 [-1000,1000]，但均无 GPR。GD、GE、GP 两步运输各带 1 个 H⁺ 同向移动，AG 两步没有该耦联；不能因结构相似就复制或更改耦联。四水解为 [0,1000]，无 GPR。Gly、Ala、Pro 的返回依赖上述可逆运输的负方向；Asp/Glu 使用单向出口。反应存在和边界允许并不验证蛋白底物范围或原生方向。

R871/R876 的模型关联基因为 **YALI1D14670g**（正式名称未核实；在本模型被赋予液泡 Asp/Glu 转运功能；这里仅为模型赋值证据，非原生底物/定位实验）。本轮保留该规则，没有据此确认转运机制。

原研究的质粒选择培养使用 0.67% 无氨基酸 YNB、0.069% CSM-Leu 和 2% 葡萄糖；非选择培养的 YPD 含蛋白胨，属于另一条件。[原始方法](https://www.nature.com/articles/s42003-023-04996-8) 当前厂家声明的 CSM-Leu 成分为游离氨基酸及碱基补充物，没有四种目标二肽。[厂家配方](https://sunrisescience.com/shop/growth-media/amino-acid-supplement-mixtures/csm-formulations/csm-leu-powder-10-grams/) 因此没有依据在当前培养中主动打开这些二肽摄入；配方未列出不等于经过分析证明无痕量杂质或接种残留。

下一轮可以设计**明确标为补充二肽条件**的外源情景，但先要区分胞外水解、完整二肽摄取和胞内水解。胞质水解若得到证据，应单独提出胞质反应候选，而不能为保留现有液泡图而强制绕行。直接液泡人工来源 G3 没有测试这些运输。

## 内源回收需要的实际来源

已有 20 条 `TRNA_BIOMASS_*` 为净生长提供残基和 tRNA 充电账本；它们不是有序列、丰度和降解率的成熟蛋白池。R859 表示糖原的胞质至液泡连接，不能改名为蛋白自噬。本次目标池的全部邻接均没有长肽或成熟蛋白释放二肽的步骤。

已有候选 **YALI1B04274g**（正式符号未核实；DPP-IV 类二肽基氨肽酶候选；序列同源及基于既有 AlphaFold 预测的功能推断）可能从合适的较长肽 N 端释放二肽。**YALI1B25603g**（正式符号未核实；DPP-III 类锌依赖二肽基肽酶候选；相同计算证据等级）也属于释放步骤候选。它们需要有来源的长肽，不是连接两个游离氨基酸的合成酶，也不等于游离二肽水解酶。[历史候选证据](../dipeptidyl_function_prediction_20260911/REPORT.md)

Gly-Pro 的第二位为 Pro，适合作为 DPP-IV 类释放的优先检验对象；Ala-Gly 的第二位是 Gly，不能因为含 Ala 而归为典型 X-Ala 底物。Gly-Asp/Gly-Glu 也不能从经典 X-Pro/X-Ala 偏好推出。四种实际释放量、原生区室和 SD-Leu 下活性仍未确认。

对前体 j，需分别给出成熟链序列、版本、末端/修饰、丰度 Pⱼ（mmol chain/gDW）、降解常数 kⱼ（h⁻¹）、液泡分配 fⱼ，以及有实验或明确推断等级的释放模式。若固定单位生物量丰度：

```
v_deg,j = k_j P_j
v_syn,j = μ P_j + v_deg,j
v_deg,va,j = f_j v_deg,j
q_i = Σ_j y_ij v_deg,va,j
```

`μP` 对应净生长合成；现有 biomass 已计入的部分不能再收费。替换合成 `v_deg` 的原料、tRNA 充电、聚合及运输加工成本须另外明确，不能无成本再生前体，也不能把现有 GAM 全部再加一次。其余 `(1−f) v_deg` 走其他降解路径，不强迫所有蛋白回收通过这四个产物。

四种二肽各含一个 Gly，必须共用同一 Gly 预算：

```
q_GD + q_GE + q_AG + q_GP ≤ r_Gly
q_GD ≤ r_Asp; q_GE ≤ r_Glu; q_AG ≤ r_Ala; q_GP ≤ r_Pro
```

还需逐序列的非重叠切割模式：例如 `AGD` 中 AG 和 GD 共用中间 Gly，不能在同一链的同次分配中同时产生。相邻序列只界定潜在产物，不证明释放。多种互斥模式可以按实测比例加权；每个模式的未分配残基、残余肽、修饰基团均有去向。不得把 TPM 当成蛋白丰度或降解速率。

在未修饰、中性线性肽且其余残基全部成为游离氨基酸的限定情形，一条长 L 的链释放 y 个目标二肽时，消耗水的计数为 `L−1−y`。该式只是残基账本模板；实际端基、修饰、带电形式和运输仍需独立元素/电荷核算，不能直接作为本模型已接纳的反应。

## 机器规格与参数检查

[默认禁用 JSON](routes/supply_module_spec.json) 的缺失参数保持 null 或空前体列表，不把未知值填成 0。正常培养下配置的二肽摄入为 0 表示未启用供给，并非检测到生物学浓度为零。

[参数检查器](routes/check_supply_spec.py) 不接收模型，不写 XML，也不提供激活函数。它核验数值/单位、固定序列 SHA、切割位点与顺序、非重叠分配、全部余项残基、共享 Gly/目标供给预算及非零替换成本；即使填写了全部字段，也不会自动接受生物学证据或启用模型。完整元素电荷配平和证据真实性需另行审查，字符串字段存在不代表审查通过。

本次已运行禁用规格检查，以及包括缺参激活、重叠、TPM 误用、免费替换、残余物缺失和供给超额的合成样例检查。样例不是科学前体或参数。命令与输出保存在 `routes/commands.txt`、`routes/parameter_check.json`、`routes/tests.log`。

目前最有判别力的下一步是围绕 **Gly-Pro** 做互相独立的释放与消耗验证：先验证自由 Gly-Pro 的候选水解活性，再检验由真实长肽释放 Gly-Pro 的候选步骤及定位。若获得完整二肽摄取率，外源补充情景比完整蛋白周转模块需要更少的新参数；但它不能解释原 SD-Leu 条件下的内源供应。
