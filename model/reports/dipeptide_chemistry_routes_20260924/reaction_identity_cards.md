# 四条水解反应的分轴身份裁决

核验日期：2026-09-24。化学字段接受的是明确L型、普通α肽键、游离二肽命名假设下的结构候选；不声称已恢复原始重建者未记录的立体意图。化学身份与原生出现、供给、酶活和定位分开。结构细节和原始数据库记录见 [化学身份表](dipeptide_identity.tsv)、[表示约定](chemical_representation.md)；蛋白原始来源和新增结果见 [酶增量审查](enzyme/REPORT.md)。本文件不接受或写入GPR。

## R2021 — Gly-L-Asp + H₂O → Gly + L-Asp

| 裁决轴 | 结论 |
|---|---|
| 化学身份 | 采用Gly在N端、L-Asp在C端、普通α肽键、无保护基/盐/水合物的游离结构候选；中性母体C6H10N2O5/电荷0，CHEBI:73804/PubChem97363；不能与Asp-Gly、β连接或相同式的异构体混同。 |
| 候选催化蛋白 | 尚无可接受的底物特异蛋白。YALI1F23706g（原生正式名未核实；DUG1-like/M20A Cys-Gly金属二肽酶候选，序列/同源/既有AlphaFold证据）只保留低优先级测定线索，不能预设为本步催化者。 |
| 底物范围 | 未检出该蛋白对精确游离Gly-L-Asp的原生直接证据；酿酒酵母DUG1表2未测，不属于阴性。Asp-X或isoAsp-X水解不支持Gly-Asp。 |
| 区室 | 模型实际C_va；名称历史上写cytosol。无新的W29/PO1f液泡腔证据、膜上朝向证据或当前培养活性；不据名称搬迁。 |
| GPR提案 | 无足够精确底物依据接受单基因或OR/AND提案。分级同源提案允许，但需实际序列关联、合理底物及区室链条；本轮保留空GPR。 |
| 下一项最有价值验证 | 用精确Gly-L-Asp筛选适当酶制备，确认底物消耗与Gly/Asp双产物；同时区分胞质与液泡组分。先确定有活性的蛋白，再定向同源比较，优于假设F23706统管。 |

## R2029 — Gly-L-Glu + H₂O → Gly + L-Glu

| 裁决轴 | 结论 |
|---|---|
| 化学身份 | Gly在N端、L-Glu在C端、普通α肽键的游离结构候选；中性C7H12N2O5/0，CHEBI:73801/PubChem99278。不是Glu-Gly、γ-Glu-Gly或循环二肽。 |
| 候选催化蛋白 | 尚无可接受的YALI1精确催化候选；不把YALI1F23706g（正式名未核实，DUG1-like/M20A Cys-Gly候选）自动赋入。 |
| 底物范围 | 本轮新核实Ito2003 *Actinomucor elegans* IFO6408的glycyl aminopeptidase对游离Gly-Glu释放Gly，ninhydrin/TLC方法p84、具体底物p85；该蛋白尚未映射至Yarrowia位点，不是假定F23706的同源活性。Cys-Gly、Glu-Gly证据不互换。 |
| 区室 | 模型C_va；该外种细胞提取酶也不证明Yarrowia液泡腔或跨膜催化面。 |
| GPR提案 | 新原始证据支持扩展筛选至N端Gly水解酶，尚不支持具体YALI1 GPR或反应迁移。 |
| 下一项最有价值验证 | 以精确Gly-L-Glu/Glu-Gly对照和双产物检测确认活性，鉴定蛋白；已表征外种酶可帮助建立检测阳性体系，但不转移速率、pH最适或定位。 |

## R2034 — L-Ala-Gly + H₂O → L-Ala + Gly

| 裁决轴 | 结论 |
|---|---|
| 化学身份 | L-Ala在N端、Gly在C端的普通α游离二肽结构候选；中性C5H10N2O3/0；精确结构标识见化学表。不是Gly-Ala。 |
| 候选催化蛋白 | 尚无可接受的YALI1底物特异蛋白；YALI1F23706g（正式名未核实；DUG1-like/M20A Cys-Gly候选）仅低优先级测定线索。 |
| 底物范围 | ScDUG1表2未测Ala-Gly；先前曲霉同源Ala-Gly阴性仅属跨种条件性反证，不能写成W29阴性。DPP-IV对第二位Ala的偏好不能用到第二位Gly的Ala-Gly。 |
| 区室 | 模型C_va；原生定位/拓扑/SD-Leu活性未确认。F23706自动胞质注释既不支持液泡，也不足以直接搬迁反应。 |
| GPR提案 | 不从家族注释接受GPR，不用DPP释放二肽的蛋白替代自由二肽水解酶。 |
| 下一项最有价值验证 | Ala-Gly与Gly-Ala分别测定并确认对应产物；Cys-Gly若用于F23706体系阳性只能证明体系有效，不能推广四目标。 |

## R2039 — Gly-L-Pro + H₂O → Gly + L-Pro

| 裁决轴 | 结论 |
|---|---|
| 化学身份 | Gly在N端、L-Pro在C端的游离普通肽键候选；Pro环内N参与酰胺，中性C7H12N2O3/0；不是Pro-Gly或Gly-Pro-pNA，精确结构标识见化学表。 |
| 候选催化蛋白 | 优先YALI1E16433g（原生正式名未核实；预测M24B prolidase-like候选）；W29 AOW05368.1/XP_503902.2与PO1f BKA90DRAFT_141684/KAE8169967.1同为454aa且全序列一致。 |
| 底物范围 | Xaa-Pro dipeptidase类别与精确自由Gly-Pro相容，具有域/位点支持，但尚无目标蛋白直接底物实测。ScYFR006W/P43590仍是未表征肽酶，不能把它当已实测Gly-Pro参考。DPP-IV切Gly-Pro-较长肽或-pNA不会证明切自由Gly–Pro键。 |
| 区室 | W29/PO1f定位和催化朝向未确认；同源P43590同时有胞质GFP高通量注释和预测TM8–24，不能转移为已证液泡腔。Q17K跨菌株变化位于N端域，不能据未碰催化位点断言定位相同。 |
| GPR提案 | 支持“优先的同源功能假设提案”，不足以接纳现有C_va反应GPR；允许后续依赖可靠同源特异性/定位等组合证据，不将W29原生实验设为唯一证据路径。此轮XML不写入。 |
| 下一项最有价值验证 | 版本明确的蛋白测自由Gly-L-Pro及Gly/Pro双产物，以Pro-Gly和Gly-Pro-较长肽作顺序/反应类型对照；定位需完整蛋白、区室纯度及必要的蛋白酶保护/朝向检查。 |

上述反应以当前命名假设表述。没有检测到活性前须先确认阳性体系、蛋白完整性、金属与适用条件；未测试或未检出单一条件活性不等于生物学不存在。更完整实验判别和供给路线参数由本轮路线规格单独给出。
