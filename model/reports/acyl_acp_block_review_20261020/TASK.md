## Corrections after the audit (2026-10-21)

- **Probe labels (acceptance 7):** the transports are written cytosol → mitochondrion, so a
  positive flux is import. "R2225 import" was wrong: min R2225 probes myristoyl-ACP export, and max
  R2231 / max R2216 probe import. None of them tests the cycle (the audit found min R2225 = 3.5e-15 on the baseline
  too; max R2231/R2216 were not run on the baseline). The closure rests on max R2230 and the static proof in REPORT.md §5.

  closes the C14 → C16:1 route (max R2233 8.992 → 0). The user accepted this consequence on
  2026-10-21: "keep P3 as built (b3b9fe22). R2216–R2241 blocked in every medium is acceptable."
- **LP count:** 12 LPs were run against the "about 10" authorized.
- **Not recorded in the build files:** seeds 0/1 (set on the command line). The FAS1/FAS2 KO was
  not run on the baseline; it is inferred lethal from the same GPR on R1392/R1393.

  after this fix gives the same control (`fdd00ac3`) and candidate (`b3b9fe22`) bytes.
