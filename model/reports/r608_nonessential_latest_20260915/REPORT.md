# R608 对应基因为何没有被预测为 essential

核查日期：2026-09-15。**主要原因是模型没有强制多胺随生长被消耗；当前约束允许多胺通量全部为零，仍保持 WT 生长。** 这是最新 R1931 单向模型的结论，本次核验保存结果和静态约束，新增求解为0。

**YALI1B15015g — YlODC/odc（沿用既有身份审查）— 鸟氨酸脱羧酶，将鸟氨酸转为腐胺和 CO₂。** 既有报告记载历史蛋白功能有实验支持；本轮只核对模型、GPR 和筛选结果，未重新验证 W29 蛋白身份桥接或当前 PO1f/SD-Leu 原生功能。

## 因果链

1. **敲除确实生效。** 当前 GPR 仅该基因；真实内存 gene KO 恰好把 R608 设为 `[0,0]`，其余反应边界不变，检查后完整恢复。
2. **生长可以不走这条通路。** 最新保存 WT 中 R608、腐胺/亚精胺/精胺及乙酰衍生物的全部20条邻接反应通量均为0。把这份完整2314反应通量代入基因KO后的全部稳态式和有效边界，最大守恒残差为5.423737630891323×10⁻¹⁴、边界违反为0。因此已经有一个接近正常 WT 生长的可行见证，无需另求一个解。
3. **多胺没有被强制用于增长。** `biomass_C` 没有多胺项，现有其他连接也没有产生必须随生长为正的净消耗。上述完整可行见证比只查看 biomass 名单更强：即使考虑间接连接，当前模型仍容许零多胺通量增长。
4. **当前条件没有提供替代净来源。** 三种多胺的外部交换 R1301/R1325/R1326 仅允许排出；液泡运输 R918/R925/R927 关闭。R2183 虽可将胍丁胺变成腐胺，但胍丁胺只有这一条消耗连接、没有生成或输入，稳态迫使其通量为0。

最新模型的12个多胺及乙酰衍生物稳态行精确求和仍为：

\[
v_{608}+v_{2183}-v_{262}-v_{2065}-v_{1301}-v_{1325}-v_{1326}=0.
\]

敲除后前两项为0，后五项均非负，因此它们全部为0。这排除了这些净来源/净损失支持补偿的解释，不意味着所有可能的内部循环必须为0；已有零通量生长见证已足以解释预测。

## 具体缺口在哪里

R262 虽名为 deoxyhypusine synthase，实际计量是水＋亚精胺＋Q9[mi]生成两个小分子胺类产物和Q9H2[mi]，**没有蛋白赖氨酸、修饰蛋白或生长相关的修饰需求**。仅存在这个反应名称，不能说明对应需求已经进入模型。

所以，当前“不必需”反映的是 **多胺功能与生长需求没有建立约束联系**。它不能证明真实细胞不需要这个基因或多胺。R608 的单基因GPR传导正常，改成AND/OR并不能补上这个需求缺口。

如果后续修模，应依据匹配菌株与培养条件的多胺池量/消耗或必需修饰证据来建立需求；不能为了得到essential而任意加一个系数。本轮未修改模型、GPR、培养条件或阈值。
