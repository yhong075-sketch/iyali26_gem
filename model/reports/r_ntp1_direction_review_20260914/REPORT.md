# R_NTP1 化学方向、能量与酶学审查

核查日期：2026-09-14。范围为截图对应的固定模型及其既有通量见证；模型身份与完整解析证据见 [LOCAL_EVIDENCE.json](LOCAL_EVIDENCE.json)。本次没有求解 LP、重跑 screen 或修改模型、GPR、培养、整理数据。

**审查结论：当前 R_NTP1 的无耦联 ATP 合成方向没有得到酶学和能量依据支持；同时，按模型实际分子式与电荷，该反应还存在一个 H 原子和一个正电荷的不平衡。候选修正必须一起处理化学表示与方向，不能只修改通量正负。** 实际胞内 ΔG、真实蛋白催化能力以及修改对必需性的影响仍未确定。

## 1. 实际化学表示：一个额外的胞质 H⁺

从原 SBML 直接读取，全部物种位于 `C_cy`，当前边界为 `[-1000,1000]`：

`ADP[cy] + Pi[cy] + H⁺[cy] ⇌ ATP[cy] + H₂O[cy]`

| 模型物种 | 实际 chemicalFormula | 实际 charge | 当前计量系数 |
|---|---|---:|---:|
| ADP，m143[C_cy] | C10H15N5O10P2 | 0 | −1 |
| Pi，m35[C_cy] | H3O4P | 0 | −1 |
| H⁺，m10[C_cy] | H | +1 | −1 |
| ATP，m141[C_cy] | C10H16N5O13P3 | 0 | +1 |
| H₂O，m32[C_cy] | H2O | 0 | +1 |

按“产物减反应物”求和，氢为 `16 + 2 − 15 − 3 − 1 = −1`，电荷为 `0 − 1 = −1`；C、N、O、P 守恒。这里核实的是**模型注释与计量之间的不一致**，没有把中性式假定为细胞中的主导离子状态。

含 H⁺ 的式子本身并非总是错误。例如 `ATP⁴⁻ + H₂O → ADP³⁻ + HPO₄²⁻ + H⁺` 可以平衡，但它采用另一套明确的离子种类。固定 pH/pMg 的生化变换式又是第三种表示，不能把这些约定混用。[IUBMB 热力学规范，页 6–7，式 2-3 至 2-6](https://iubmb.qmul.ac.uk/thermod2/BiochemThermodynamics.pdf)。当前 H⁺ 是显式、非边界物种；本轮未找到将本反应特殊解释为固定 pH 缓冲交换的来源。

## 2. 能量依据：胞质 H⁺不等于跨膜供能

`R_NTP1` 的完整计量没有另一侧膜的 H⁺，也没有其他高能供体或供能步骤。它因此没有表示 ATP synthase 的跨膜耦联机制。对于梯度驱动的合成，完整过程应满足：

\[
\Delta G_{\mathrm{total}}=\Delta G_{\mathrm{ATP\ synthesis}}+n\Delta\widetilde\mu_{\mathrm{H^+,transport}}<0,
\]

其中运输项按质子实际运输方向定义；顺电化学势下降的运输可提供负自由能。单一区室中的化学 H⁺不能替代该项。重构 ATP synthase 实验直接显示，改变跨膜 ΔpH 和 ATP/ADP/Pi 条件可以使同一酶在净合成与净水解之间切换。[Turina et al., 2003，页 419 式 1–4、页 421 图 2](https://www.biophysikalische-chemie.uni-freiburg.de/dokumente/publikationen/2003_turina_embo.pdf)。该实验为叶绿体蛋白脂质体，参数不能移植为 W29 实测值。

不能绝对断言“ATPase 不能反向”：分离 F₁ 的磁力扭矩实验可驱动 ATP 合成，但输入了机械功；它不支持本反应的无驱动净合成。[Itoh et al., 2004，出版社摘要](https://www.nature.com/articles/nature02212)。

本轮没有 W29/PO1f 的 ATP、ADP、Pi 活度、pH、游离 Mg²⁺和相应热力学参数，**不计算实际 ΔG，也不宣称所有浓度条件下逆反应均不可能**。固定 pH/pMg 时应使用一致的 `ΔG′ = ΔG°′ + RT ln Q′`；已变换的反应商不能重复计入同一化学 H⁺。[IUBMB 热力学规范，页 7–8、25](https://iubmb.qmul.ac.uk/thermod2/BiochemThermodynamics.pdf)。

## 3. 酶学依据与 GPR 的证据边界

[KEGG R00086](https://www.kegg.jp/entry/R00086) 的名称是 ATP phosphohydrolase，采用无区室总式 `ATP + H₂O ⇌ ADP + phosphate`，关联多个酶类。数据库双向箭头没有给定具体酶、条件或完整耦联，不能单独支持生理净 ATP 合成。

当前模型把以下两条记录以 OR 相连；固定 SBML 只有占位蛋白名，下列功能仅来自本地 gap-fill 的 EC 映射。

| 系统 ID | 已核实名称／简要功能 | 证据等级 | 模型角色与未决项 |
|---|---|---|---|
| YALI1A09766g | 正式名称本轮未核实；质子转运 ATPase 相关候选，来源 EC 7.1.2.2 | model/GPR assignment only | 被赋予独立维持 R_NTP1 的 OR 分支；未证明其单独催化能力、具体亚基或该胞质游离反应归属 |
| YALI1E41893g | 正式名称本轮未核实；酸性磷酸酶候选，来源 EC 3.1.3.2 | model/GPR assignment only | 另一 OR 分支；原生 ATP 底物活性与胞质定位未确认 |

[IUBMB EC 7.1.2.2](https://iubmb.qmul.ac.uk/enzyme/EC7/1/2/2.html) 明确描述多亚基、跨膜质子转运的两部分 ATPase；不能从该分类拆出无转运化学子式，再自动视作完整 ATP 合成酶功能。页面的通用质子计量也不是 W29 特异测量。

[IUBMB EC 3.1.3.2](https://iubmb.qmul.ac.uk/enzyme/EC3/1/3/2.html) 定义磷酸单酯水解，并注明宽底物谱与转磷酸活性。ATP→ADP 断开的是磷酸酐连接；泛化 EC 映射不证明目标蛋白的这项底物活性，更没有证明 ADP 加游离 Pi 可承担持续 ATP 合成。宽底物谱也不能反过来证明每个该类蛋白均无 ATP 活性。两条映射不足以确认实验同工酶关系；本轮未开展序列/结构鉴定，不修改 GPR。

## 4. 保存通量与版本来源分别说明什么

旧 22 份保存向量均使用当前书写方向，WT 为 `157.55576349404305`；这是当前计量与边界下的模型运行观察，并非 22 次独立酶学实验，也没有给出真实反应驱动力。本轮复读旧记录，没有重新优化或重新证明其最优性。

按原列精确相加，`S_R_NTP1 + S_xMAINTENANCE = −H⁺[cy]`。因此当前这两步**不是完整净零循环**。若只删去额外 H⁺却保留可逆边界，候选 ATP 合成列将与维护水解列精确相反；这个代数风险说明不能只补平衡、仍开放无耦联合成。未据此声称当前完整网络已经被证明构成封闭能量生成循环。

旧 active 方向整理要求水解；后续 metadata 选择明确将本反应改为当前计量和可逆边界，并保存 superseded notes。当前代码先做 gap-fill 方向整理，后应用 metadata 选择。因此这是**有记录的版本选择与科学依据问题**，不是仅凭差异即可认定的软件回归；版本选择也不构成新的化学验证。单改早期整理表可能被后续选择重新覆盖。

## 5. 具体候选及验收要求（未实施）

在保留当前中性物种注释的前提下，化学上自洽的水解候选为：

`ATP[cy] + H₂O[cy] → ADP[cy] + Pi[cy]`，按此书写边界 `[0,1000]`。

等价实现为：保留合成书写的四物种式、去除本列额外 H⁺，边界设 `[-1000,0]`。两种写法的化学方向相同。该候选支持的是 ATP 水解表示及排除未获依据的合成方向，**不表示两条 GPR 或真实胞质游离 ATPase 已验证**。若拟表示真实跨膜 ATPase，则需另一套明确区室、完整耦联计量及复合体证据。
