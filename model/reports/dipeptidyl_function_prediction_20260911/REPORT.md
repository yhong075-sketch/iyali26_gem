# W29 两个二肽基肽酶候选的蛋白功能预测

核验日期：2026-09-11。结论为**序列同源性和基于 AlphaFold 预测的功能候选**，尚无这两个 W29 蛋白的本次酶学实验验证。

## 主要结论

| W29 系统 ID／蛋白身份 | 本轮支持的功能 | 关键证据 |
|---|---|---|
| **YALI1B04274g**；正式基因符号未核实；NCBI 蛋白 AOW01140.1，887 aa | **DPP-IV 类二肽基氨肽酶候选**；可能从较长肽的游离 N 端释放二肽，具有催化活性的序列特征 | 与酿酒酵母 YHR028C／DAP2（Dap2，二肽基氨肽酶 B，已研究的参考蛋白）的序列一致率 **43.46%**，目标覆盖率 **90.64%**；候选催化三联体 **S749–D826–H859** 均保守；与人 DPP4 实验结构 1NU6 对齐 **703 个残基，RMSD 2.14 Å** |
| **YALI1B25603g**；正式基因符号未核实；NCBI 蛋白 AOW01944.1，707 aa | **M49 家族、DPP-III 类锌依赖二肽基肽酶候选**；可能参与寡肽降解并释放 N 端二肽 | 与酿酒酵母 YOL057W（正式符号未核实，DPP-III 蛋白，已有实验结构）的一致率 **48.17%**，目标覆盖率 **94.20%**；候选锌结合残基 **H460/H465/E519** 和推定催化碱 **E461** 保守；与该蛋白实验结构 3CSK 对齐 **668 个残基，RMSD 3.22 Å** |

两者的酶家族归属得到多项相互一致的计算证据支持。具体底物、天然活性、区室与生理作用仍不能从这些数值直接确定；一致率和 pLDDT 都不是“功能正确的概率”。

## 序列、催化位点与对照

本次实际完成两条固定目标序列对九条预选、经 Swiss-Prot 审阅的参考蛋白的本地 BLASTp 比较，共获得八个显著 HSP。**这是一组有限参考比较，不是完成了全 Swiss-Prot 检索，也不能称为全库最佳匹配。** 一致率是 HSP 中相同残基数除以含缺口的比对列数；覆盖率按覆盖到的目标残基并集计算。

对 YALI1B04274g，上述 DPP-IV 类候选还与黑曲霉蛋白 Q96VT7／dapB（该记录未给出系统基因座；DPP-IV 类参考，条目仍含同源推断证据）达到 47.41% 一致率、82.30% 目标覆盖率。与酿酒酵母 YOR219C／STE13（Ste13，前体加工相关二肽基氨肽酶 A，实验研究参考）为 34.58%／78.24%。这支持 DPP-IV 家族归属，不能把参考蛋白的液泡或 Golgi 定位直接转移到 W29 候选。

人 NCBI Gene 1803／DPP4（P27487，实验表征的二肽基肽酶 4）的催化三联体与候选 S749/D826/H859 对应；其 N 端识别相关 E205/E206 映射到候选 **E325/E326**。参考蛋白 E205/E206 的作用有突变研究支持，但作用随底物改变；这里只证明候选保留对应残基。原始位点提取表中这两行的“literature check pending”是提取时状态，本段及 `prediction_summary.json` 补充其后完成的文献核验，不回写独立审计已锁定的原始表。[Gnoth 等，2024](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0289239)

结构相似不足以单独证明活性：YALI1B04274g 与人 NCBI Gene 1804／DPP6（P42658，缺乏肽酶活性的 DPP-IV 样通道辅助蛋白）结构 1XFD 也能对齐 702 个残基、RMSD 2.61 Å。因此，本结论同时依赖催化位点保守性；仍需测定目标蛋白活性。[无活性 DPP 家族成员的结构研究](https://www.nature.com/articles/srep08769)

对 YALI1B25603g，候选 H460/H465/E519 对应酵母参考结构中的锌配位残基；E461 对应提出的催化碱。AlphaFold 单体结构本身不测量锌结合，也不证明酶反应。原论文中的部分机理是基于结构提出的，不能把建模的底物复合物当作实验复合物。[Baral 等，2008；3CSK](https://www.rcsb.org/structure/3CSK)

YALI1B04274g 的历史自动注释包含 92–113 位跨膜区候选，但此区平均 pLDDT 仅 68.81；膜结合与具体区室均未通过本次分析确认。YALI1B25603g 的历史胞质定位也是自动注释，不是本次定位实验结果。

实际完成八对全可用 CA 链的 US-align 比较，包含活性参考、无活性同族及异类对照。表中的 RMSD 是对工具选定的对应残基重新做最小二乘拟合的结果，不能直接当作全长每个残基都重合，也不能等同于导出的 TM 最优化变换下的 RMSD。独立复算已确认八对匹配长度和 RMSD。

参考构建体限制已保留：3CSK 有 C130S 工程突变及靠近催化区域的 G458D 数据库序列冲突；后者在 PDB 中标作 CONFLICT，不能称工程突变。辅助参考 5E33 含催化碱 E451A 等工程突变，只用于构象比较；异类对照 3DDU 也含工程突变。完整记录见原始 PDB 与独立数值审计。

## 对四种二肽的意义

拟议的反应类型是：

**较长肽的 NH₂–X–Y–其余肽链 + H₂O → 游离二肽 X–Y + 其余肽链。**

它需要合适的上游肽底物，不是把两个游离氨基酸连接起来。将这种候选功能写进模型，还必须明确并守恒地表示上游肽来源、产物与区室。

| 目标二肽 | 本轮能支持的判断 |
|---|---|
| **Gly-Pro**（甘氨酰脯氨酸） | 四者中最符合 DPP-IV 类候选的经典底物偏好：第二位是 Pro。但还需要合适的 Gly-Pro 开头的较长肽，并实验确认 YALI1B04274g 能切割它。 |
| **Ala-Gly**（丙氨酰甘氨酸） | 第二位是 **Gly，不是 Ala**，不能因含 Ala 就判为典型 DPP-IV 底物；本轮未确认，也不作绝对排除。 |
| **Gly-Asp**（甘氨酰天冬氨酸） | 第二位为酸性 Asp，不能从典型 DPP-IV 的 Pro/Ala 偏好推出可生成。 |
| **Gly-Glu**（甘氨酰谷氨酸） | 第二位为酸性 Glu，同样缺少目标蛋白的直接底物证据。 |

上述优先级是从已研究 DPP4 的底物偏好向候选作出的推断，不是目标蛋白的实测结论。[DPP4 底物与催化研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0289239) YALI1B25603g 的 DPP-III 类归属也不能自动证明它生成全部四种二肽。

最有判别力的后续验证是用明确 N 端序列的较长肽测定目标蛋白切割，并直接鉴定释放的二肽；细胞内区室和生理来源须另行验证。本轮未进行这些实验，也未据此赋予液泡来源、R795 耦联或 essentiality。
