# CoQ 文献修订：R19 与 R18 的醌醇形式

已根据用户“根据文献的修改”指令，生成解脂耶氏酵母（*Yarrowia lipolytica*）iYali26 项目的[新候选模型](coq_quinol_partial_candidate_v2.xml)。**R19、R18 的化学与 R19 GPR 已修改；后续氧化还原连接仍不完整。这个文件是明确保留缺口的局部修订候选，不能当作已经闭合的 CoQ 生物合成通路或新的正式基线。** 原先 CoQ v2、项目默认模型及 E5 均未覆盖。

## 实际修改

所有下列反应均在线粒体区室。式中的 NAD、NADH、SAM、SAH 使用输入模型的实际中性微观物种表达；没有修改全局辅因子分子式或电荷。

| 反应 | 修改前 | 修改后 |
|---|---|---|
| R19，C1 羟化 | 酚前体 + O2 → DDMQ9（醌）+ H2O；GPR 空缺 | 酚前体 + O2 + NADH → **DDMQ9H2（醌醇）** + NAD + H2O；加入下面的三成员供电子链候选 GPR |
| R18，C-甲基化 | DDMQ9（醌）+ SAM → DMQ9（醌）+ SAH | **DDMQ9H2 + SAM → DMQ9H2 + SAH**；原有单基因 GPR 保留 |

R19 对应 [EC 1.14.15.46](https://iubmb.qmul.ac.uk/enzyme/EC1/14/15/46.html) 的羟化部分，文献酶反应使用还原型铁氧还蛋白并生成醌醇；本候选把连续供电子过程合并为 NADH 净消耗。R18 的醌醇底物/产物得到 [Nicoll 等，2024，Fig.4/5 与 Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC7615680/)及 [EC 2.1.1.201](https://iubmb.qmul.ac.uk/enzyme/EC2/1/1/201.html)支持。Nicoll 的酶为重构四足动物祖先蛋白，底物为短链类似物；转移到解脂耶氏酵母 CoQ9 是有证据的候选推断，非本物种酶活实测。

新增两个独立代谢物：`coq_ddmq9h2[C_mi]`（C52H80O3，电荷0）与 `coq_dmq9h2[C_mi]`（C53H82O3，电荷0）。旧 m59、m61 等醌型物种的身份、分子式、注释全部保留，避免把不同氧化态混用一个编号。旧 R19/R18 说明保留为历史字段，当前说明、名称和 EC 与新表示一致。未新增自由电子、虚构氧化酶、额外氧化反应或人工汇。

## GPR 与证据等级

R19 新规则为 `YALI1A08781g and YALI1B03314g and YALI1B19490g`。AND 表示合并反应中的连续供电子依赖，不证明三者构成原生稳定复合体。

| 系统ID／版本化蛋白 | 名称和简要功能 | 本轮模型作用与证据等级 |
|---|---|---|
| YALI1A08781g／XP_499891.1 | COQ6 家族候选；FAD 依赖芳环羟化酶 | 新关联 R19；跨物种精确化学、同源及已有预测支持。原生 C1 活性/唯一性未验证。 |
| YALI1B03314g／XP_500417.1 | YAH1 样候选；2Fe–2S 铁氧还蛋白 | 新关联 R19 的电子传递；同源、酵母功能参照及既有定位预测，原生配对未验证。 |
| YALI1B19490g／XP_500902.3 | ARH1 样候选；铁氧还蛋白还原酶 | 新关联 R19 的供体再生；NADH 作为允许供体的候选，不声称原生偏好。 |
| YALI1C25352g／XP_501966.1 | COQ5 家族候选；CoQ 环 C-甲基转移酶 | 保留 R18 单基因规则；已有注释/同源与跨物种酶学支持，原生活性未验证。 |

上表名称均为候选/家族标记，原生正式符号未独立确认。复用先前已核对的版本化序列、比对、TargetP 与同序列 **AlphaFold 预测**；本轮没有新比对、结构或定位预测。结构证据仍是“基于 AlphaFold 预测的功能候选”，不证明底物特异性或定位。相关输入和来源完整指纹保存在核验记录中。NADPH 同样可能参与；原模型 NADP/NADPH 的化学身份问题未在本轮扩展修订。

## 明确保留的缺口及其含义

**DMQ9H2 如何进入 R695 尚未得到足以写成完整反应的证据。** 原 R695 使用氧化态 DMQ9、NADH 和 O2。2013 人源酶的结合态醌传电子机制，以及2024的联合重构，均不能直接证明自由 DMQ9H2 可以按同一净式替换它的底物。最新 [EC 1.14.13.253](https://iubmb.qmul.ac.uk/enzyme/EC1/14/13/253.html)也将真核醌型步骤与原核醌醇型步骤分开。具体实验、反证与测定限制见[独立来源审核](source_audit/AUDIT.md)。

本候选中 DMQ9H2 只有 R18 生成而没有消耗；DDMQ9H2 连接 R19 和 R18。因此稳态守恒直接给出：

`DMQ9H2：v_R18 = 0；DDMQ9H2：v_R19 − v_R18 = 0。`

所以两条修订反应在当前完整模型的稳态条件下仍不能产生净通量。氧化态 DMQ9 只剩 R695 消耗，也迫使 `v_R695 = 0`。这是本轮静态守恒推导，没有运行 FBA，不能解释成真实生物学不活跃、酶无功能或基因必需。

另一个已知限制是 R385 当前仍使用醌，而文献末端 O-甲基化使用醌醇；该步骤及其还原供给未在本轮改写。原模型中成熟 Q9 + Q9H2 池只有 R385 净生成、没有净稀释/周转需求的限制也保持。后续完整修订必须一起解决这些具体氧化还原连接；仅修改名称或复制呼吸链 GPR 不足以解决。

## 本次验证与复现

- 最终 v2 候选导出、保存重读及再次应用幂等通过。模型仍为2314条反应、1073个基因；物种从1877增至1879。初次 v1 在文件级审核中发现保存工具将20个缺失电荷自动填为0，已判验收失败并保留文件与日志；v2 在本候选导出过程中保留原字段缺省状态，没有修改共享保存工具。
- R19/R18 以及原样保留的 R39/R695/R385 均按实际物种逐元素、逐电荷精确配平。新反应没有相同、反向或成比例的重复反应。
- 完整 XML 白名单核对通过：只允许 R19/R18、两个新代谢物、模型状态说明及两个相应分组成员显示名变化。其余反应、旧物种全部字段（包括缺失值）、基因身份、目标、反应边界和分组成员保持。
- 六个相关基因的布尔 GPR 检查表明：三条供电子链成员各自失活时，新增关闭的反应只有 R19。没有求解敲除后的生长。
- 主核验10类冲突拒绝且无部分写入；独立实现审核14类冲突检查通过，包括 GPR 被替成 OR、R18 GPR 被换、错误目标边界、混合修改状态和暗加醌醇汇。
- 10项相关既有软件测试全部通过。构建/核验的优化和网络调用计数均为0；文献检索另行留有来源记录。

来源审核覆盖8/8条声明：4支持、3未决、1反证、0未核；反证针对原 R385 与文献化学定义相同的过强声明，不表示原生酶不可能接受醌。

复现入口为本目录 `build_verify.py`：默认核验已有候选，`--build` 从固定输入创建新候选并拒绝覆盖输出。科学修改由 `data/reference_build/curation/coq_literature_revision.json` 管理，调用现有 CoQ curation 模块及标准候选导出函数；项目普通构建默认行为不变。见[机器核验](verification.json)、[独立实现审核](implementation_audit/AUDIT.md)及[独立来源审核](source_audit/AUDIT.md)。本轮未运行培养/菌株覆盖、表型阈值判断、全基因筛选或集群作业。
