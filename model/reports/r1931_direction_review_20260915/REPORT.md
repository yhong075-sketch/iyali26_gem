# R1931逆向能力的生物学审查

## 结论

**现有证据不支持把R1931作为具有±1000对称容量的生理可逆反应。建议候选修改为[0,1000]，保留“谷氨酸-5-半醛氧化为谷氨酸”的正向，关闭直接还原游离谷氨酸的逆向。** 这是基于酶学的建模建议；本次未修改模型，也未预测修改后两个目标是否转为必需。

## 1. 是哪一种酶

当前模型R1931对应 **EC1.2.1.88，L-glutamate γ-semialdehyde dehydrogenase / P5C dehydrogenase**，胞质，NAD依赖。按当前模型物种写作：

谷氨酸-5-半醛 + NAD + 水 → 谷氨酸 + NADH。

它与R332的 **EC1.2.1.41，γ-glutamyl phosphate reductase**不是同一化学步骤：后者还原的是经ATP活化的γ-谷氨酰磷酸，并使用NADPH。R327负责ATP依赖的磷酸化。两个EC的相似名称、数据库反应的等号，均不能证明R1931能承担逆向生物合成。[IUBMB 1.2.1.88](https://iubmb.qmul.ac.uk/enzyme/EC1/2/1/88.html)、[1.2.1.41](https://iubmb.qmul.ac.uk/enzyme/EC1/2/1/41.html)、[2.7.2.11](https://iubmb.qmul.ac.uk/enzyme/EC2/7/2/11.html)。

当前模型采用中性物种，R1931元素和电荷检查通过；官方反应的质子数因物种表示不同，不能直接复制质子系数。本次只审查方向，不提出化学式补丁。

## 2. 支持方向限制的证据

| 证据 | 直接支持什么 | 不能推导什么 |
|---|---|---|
| IUBMB EC1.2.1.88官方说明 | 将该酶描述为脯氨酸分解途径中半醛至谷氨酸的不可逆氧化 | 不是W29的独立体内实验 |
| Moxley等2014，E. coli PutA原始酶学 | 作者用NADH和谷氨酸测试逆向，未检测到P5CDH活性，因此动力学建模将化学步作为不可逆 | 不能直接量化Yarrowia蛋白的逆向上限 |
| Isobe等1987，B. sphaericus纯化酶 | 直接试验含谷氨酸及NAD(P)H等，未观察到逆向合成P5C；全文p.1950 | 辅因子偏好不同，不能量化Yarrowia逆向界限 |
| 大鼠肝纯化酶1990 | 专门检查逆向但未检出P5C；正文给出若存在，至少比正向慢15000倍的限制，非测得的逆向活性 | 不能把该比例设成Yarrowia模型边界，也不能声称绝对零活性 |
| 酿酒酵母纯化蛋白2014 | 原始动力学测得NAD依赖的P5C/GSA氧化，支持真菌中同类分解功能 | 不等于Yarrowia原生蛋白身份/定位和逆向活性直接验证 |

来源：[Isobe等，1987原文](https://www.jstage.jst.go.jp/article/bbb1961/51/7/51_7_1947/_pdf)；[Moxley等，2014](https://doi.org/10.1074/jbc.M113.523704)；[大鼠肝酶，1990](https://doi.org/10.1016/S0021-9258(17)44804-6)；[酿酒酵母酶，2014](https://doi.org/10.1021/bi500048b)。独立来源提取与可访问范围见[BIOCHEMISTRY.md](BIOCHEMISTRY.md)。

## 3. 机制判断与证据强度

模型逆向直接用NADH将游离谷氨酸变成半醛，省去R327/R332对应的ATP活化和磷酸化底物还原步骤。最新模型已保存WT见证实际用了这条路径，而两步原路线通量为零。因此当前方向确实提供了可绕过原路线的供给。这是模型事实与计量推论，不是单凭必需性标签做修正。

依据酶类定义、原始酶学和合成途径区别，**把这条逆向作为常规脯氨酸合成供给缺乏支持，方向限制有强依据**。但未取得W29该反应的体内浓度、pH和NAD/NADH比值，未计算适用条件的ΔG；所以不把结论写为“所有条件下热力学绝不可能”。“未检出、若存在也极慢”的检测限制不能写成测得逆向活性，更不能据此开放足以支持细胞生长的对称通量。

## 4. 原生蛋白身份与区室

**YALI1B12993g — 正式原生基因名未核实 — 推定P5C/谷氨酸-5-半醛脱氢酶（模型/GPR赋值；数据库自动注释，非原生实验验证）**。本次取得的官方RefSeq XP_500688.1、GenBank AOW01471.1及保存的W29蛋白序列完全一致（572 aa）；因此模型所指蛋白的序列身份得到核对。UniProt A0A1H6PIK2当前条目因不再属于reference proteome而停用，历史功能和定位仍只是自动注释，停用不等于功能被否定。完整版本与序列SHA见[IDENTITY.md](IDENTITY.md)和identity_checks.json。

已复用与目标完全同序列的既有 **AlphaFold预测** AF-A0A1H6PIK2-F1 v6，非本次预测：API平均pLDDT94.25，但前30残基平均约35.3，且PAE可用。它不能确认催化方向、底物特异性或区室，因此不把结构预测当作逆向能力证据。

同一模型还把该基因赋给线粒体的R9；R1931在胞质。其他酵母同类蛋白的线粒体定位和目标自动定位注释提示应单独审查胞质赋值，但不足以本次直接移动或删除反应。方向问题与区室问题分开处理，结构预测不能替代逆向活性或反应平衡测量。

## 5. 候选修改与验收标准

- 原边界：R1931=[-1000,1000]；建议候选：[0,1000]。上限1000为保留的建模容量，并非测得的酶容量。
- 本次仅建议；获准后通过整理数据和构建管线实施为新版本，保留原模型与旧结果，不直接覆盖。
- 同一SD-Leu/PO1f、目标和15%阈值下，比较原/候选WT及两个目标单敲，保存全部数值和通量，确认无逆向R1931，同时检查此前正确结果是否受损。
- 若目标仍非必需，检查已知R610等实际供给与转运；不为了命中标签继续任意删除旁路。未执行这些新对照，不能声称已修复预测。
